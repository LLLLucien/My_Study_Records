### 系统调用

- 核心系统调用：`open` / `read` / `write` / `lseek` / `close`
- 标识方式：用 **int fd（文件描述符）** 标识文件，`stdin=0`，`stdout=1`，`stderr=2`

#### 示例代码

```c
// 1. 向 stdout(1) 写入，从 stdin(0) 读取
char buf[16] = "hello POSIX";
if (write(1, buf, strlen(buf)) != strlen(buf))
    write(2, "write error\n", 11);
write(2, "\n", 1);

char buf2[16];
memset(buf2, 0, sizeof(buf2));
int n = read(0, buf2, sizeof(buf2));
write(1, buf2, n);
```

```c
// 2. 打开文件并写入
int fd = open("test4.txt", O_WRONLY | O_CREAT, 0660);
printf("fd=%d\n", fd);       // 新 fd 一般从 3 开始

char buf[] = "hello POSIX";
int len = write(fd, buf, sizeof(buf));
printf("len=%d\n", len);
close(fd);
```

#### 数据流向（核心区别）

**C 标准库 IO（`fopen` / `fwrite`）：有用户态缓冲**

```
用户空间：buf → fwrite → 用户空间缓冲区 → 系统调用
内核空间：               write → 内核空间缓冲区 → 磁盘
```

**系统调用 IO（`open` / `write`）：直接走内核**

```
用户空间：buf → write ─────────────────┐
内核空间：          write → 内核空间缓冲区 → 磁盘
```

> **关键**：C 标准库在用户空间多了一层缓冲区，可减少系统调用次数；而系统调用 IO 直接与内核交互，无额外缓冲。

#### 要点速记

- `open` 失败返回 `-1`，创建文件时权限用八进制如 `0660`
- `write` 返回值可能小于期望字节数，实际编程需校验
- `read` 返回 `0` = EOF，`-1` = 出错；读取前 `memset` 清零缓冲区
- 文件用完必须 `close`，防止文件描述符泄漏

### sendfile

- 零拷贝复制：直接从内核缓冲区复制到网络缓冲区，避免了用户空间和内核空间的多次拷贝
- ssize_t sendfile(int out_fd, int in_fd, off_t \*offset, size_t count);
  - out_fd: 输出文件描述符（如 1 = stdout）
  - in_fd: 输入文件描述符（如 0 = stdin）
  - offset: 输入文件偏移量（可选）
  - count: 拷贝字节数（可选）

- **发送端**

```c
    off_t offset = 0;
    ssize_t send_len;
    long sent = 0;
    while(sent<total_size)
    {
        send_len = sendfile(sock_fd, file_fd, &offset,BUF_SIZE);
        if(send_len<=0)
        {
            perror("sendfile error");
            break;
        }
        //这里不需要offset+=send_len，因为sendfile会自动更新offset
        sent += send_len;
        printf("sent: %ld\n", sent);
    }
```
