# C++ OpenCV

## 概述

**OpenCV**：Intel 公司开发的计算机视觉库，用于处理、分析、识别图像和视频。

### 应用场景

- 图形图像处理：编辑、滤镜
- 特征检测与目标识别
- 视频处理
- 工业视觉
- 自动驾驶

## 开发流程

### 环境搭建（Ubuntu）

- `sudo apt install libopencv-dev`：安装 OpenCV
- `sudo apt install cmake`：安装 CMake（构建工具）
- `sudo apt install build-essential`：安装编译工具链

> 调用显卡进行计算时用到的技术：
>
> - **OpenCL**：并行计算相关，用 `sudo apt search opencl` 搜索相关包
> - **OpenGL**：3D 图形渲染相关

### 开发步骤

1. `mkdir 0826`：创建工程
2. 创建 `CMakeLists.txt` 文件，生成 makefile 文件
3. 创建程序
4. 执行构建 `build`：预处理、编译、链接

## 基础示例

### 程序结构

程序需要引入头文件并使用 `cv` 命名空间：

```cpp
#include <iostream>
#include <opencv2/opencv.hpp>

using namespace std;
using namespace cv;
```

### 读取并显示图像

```cpp
int main()
{
    // 读取图像
    Mat img = imread("./lena.jpg");
    if (img.empty())
    {
        cout << "error\n";
        return -1;
    }
    // 窗口显示
    imshow("app", img);
    // 等待键盘事件
    waitKey(0);
    // 销毁窗口
    destroyAllWindows();
    return 0;
}
```

### 常用函数

- `imread("路径")`：读取图像，返回 `Mat`
- `imwrite("路径", 图像)`：写入图像
- `imshow("窗口名", 图像)`：窗口显示图像
- `waitKey(0)`：等待键盘事件
- `destroyAllWindows()`：销毁所有窗口
- `img.empty()`：判断图像是否读取成功

## Mat 图像容器

`Mat` 是 OpenCV 中存储图像的基本数据类型，每个像素由多个通道（channel）组成。

### 色彩空间

- OpenCV 默认色彩空间是 **BGR**，不是 RGB
- 三通道的一个点是 3 个 8 位整数，范围 0-255

### 三通道图像（CV_8UC3）

一个点是 3 个 8 位整数，范围 0-255。

```cpp
// 400x400 三通道图像，颜色 (0, 0, 100)
Mat m1(400, 400, CV_8UC3, Scalar(0, 0, 100));
imshow("app", m1);
imwrite("m1.jpg", m1);
```

### 单通道图像（CV_32FC1）

一个点是 1 个 32 位浮点数，范围 0-1。

```cpp
// 3x3 单位矩阵
Mat m1 = Mat::eye(3, 3, CV_32FC1);
cout << m1 << endl; //输出矩阵
```

### 特殊矩阵

- `Mat::eye(rows, cols, type)`：单位矩阵，对角线为 1，其余为 0
- `Mat::ones(rows, cols, type)`：全 1 矩阵
- `Mat::zeros(rows, cols, type)`：全 0 矩阵

```cpp
// 3x3 全 1 矩阵
Mat m2 = Mat::ones(3, 3, CV_32FC1);
// 3x3 全 0 矩阵
Mat m3 = Mat::zeros(3, 3, CV_32FC1);
```

### 四通道图像（CV_8UC4）

一个点是 4 个 8 位整数，范围 0-255，第 4 个通道为透明度。

```cpp
// 400x400 四通道图像，透明度 255（不透明）
Mat m1(400, 400, CV_8UC4, Scalar(0, 0, 100, 255));
```

### Mat 常用属性

```cpp
Mat m2 = imread("./lena.jpg");
cout << m2.channels() << endl; // 通道数
cout << m2.rows << endl;       // 行数（高）
cout << m2.cols << endl;       // 列数（宽）
cout << m2.type() << endl;     // 数据类型
cout << m2.size() << endl;     // 尺寸
cout << m2.total() << endl;    // 总像素数
waitKey(0);
destroyAllWindows();
```

- `channels()`：通道数
- `rows`：图像行数（高）
- `cols`：图像列数（宽）
- `type()`：数据类型
- `size()`：尺寸
- `total()`：总像素数

## 图像操作

### 读取模式 imread

`imread` 的第二个参数是可选的，默认是 `IMREAD_COLOR`（彩色图像）。

- `IMREAD_COLOR`：彩色图像（默认）
- `IMREAD_GRAYSCALE`：灰度图像
- `IMREAD_REDUCED_COLOR_2`：彩色图像，缩小 1/2
- `IMREAD_REDUCED_COLOR_4`：彩色图像，缩小 1/4

```cpp
Mat m1 = imread("./lena.jpg", IMREAD_COLOR);
Mat m2 = imread("./lena.jpg", IMREAD_GRAYSCALE);
Mat m3 = imread("./lena.jpg", IMREAD_REDUCED_COLOR_2);
Mat m4 = imread("./lena.jpg", IMREAD_REDUCED_COLOR_4);
```

### 图像缩放 resize

- `resize(输入, 输出, Size(宽, 高))`：缩放到指定尺寸
- `resize(输入, 输出, Size(), fx, fy)`：按比例缩放，`fx`、`fy` 分别是宽、高的缩放倍数

```cpp
Mat m5;
resize(m1, m5, Size(1800, 150)); // 缩放到 1800x150

Mat m2;
resize(m1, m2, Size(), 2, 0.5);  // 宽放大 2 倍，高缩小 0.5 倍
```

### 矩形裁剪 Rect

- `Rect(x, y, 宽, 高)`：定义一个矩形区域，起点为 `(x, y)`
- `Mat m = m1(rect)`：裁剪出该矩形区域

```cpp
Rect r(200, 200, 100, 100); // 起点 (200,200)，宽高 100
Mat m6 = m1(r);             // 裁剪出该区域
```

### 绘制矩形 rectangle

- 参数：图像、矩形、颜色、线宽
- 线宽为 -1 时表示填充矩形

```cpp
rectangle(m1, Rect(100, 100, 100, 100), Scalar(0, 0, 255), 5);
```

### 绘制圆形 circle

- 参数：图像、圆心、半径、颜色、线宽

```cpp
circle(m1, Point(100, 100), 50, Scalar(0, 255, 0), 5);
```

### 绘制文字 putText

- 参数：图像、文字、位置、字体、字号、颜色、线宽
- `putText` 的锚点是文字左下角

```cpp
putText(m1, "hello", Point(0, 90), FONT_HERSHEY_PLAIN, 10, Scalar(255, 255, 255), 5);
```

### 创建同规格图像 setTo

- `Mat m(m1.size(), m1.type())`：创建与 `m1` 尺寸、类型相同的图像
- `m.setTo(Scalar(50, 50, 50))`：将整幅图像设为指定颜色

```cpp
Mat m7(m1.size(), m1.type()); // 创建同尺寸、同类型图像
m7.setTo(Scalar(50, 50, 50)); // 整幅图设为 (50, 50, 50)
```

### 像素运算 add / subtract

- `add(a, b, dst)`：两图逐像素相加，图像变亮
- `subtract(a, b, dst)`：两图逐像素相减，图像变暗

```cpp
Mat light, dark;
add(m1, m7, light);      // 变亮
subtract(m1, m7, dark);  // 变暗
```

## 滤波降噪

- 图像噪声：曝光、信号干扰、传输衰减等图像中出现一些与内容无关的像素

- 滤波降噪：通过卷积操作可以消除部分图像噪声

### 卷积核

- 卷积核一般是奇数边长（如 3x3、5x5、7x7）的矩阵
- 用于与图像进行卷积运算，取运算后的值作为中心像素的新值
- 卷积核越大，处理效果越明显

### 均值滤波 blur

- `blur(输入, 输出, Size(k, k))`：整体模糊，所有像素权重相同

```cpp
blur(m1, m3, Size(3, 3));
blur(m1, m5, Size(5, 5));
```

### 高斯滤波 GaussianBlur

- `GaussianBlur(输入, 输出, Size(k, k), sigmaX, sigmaY)`：整体模糊，中心像素权重更大
- 参数：卷积核大小、x 方向标准差、y 方向标准差

```cpp
GaussianBlur(m1, m5, Size(9, 9), 0, 0);
```

### 中值滤波 medianBlur

- `medianBlur(输入, 输出, k)`：取卷积核区域像素的中值
- 效果：细节模糊，轮廓不变

```cpp
medianBlur(m1, m5, 5);
```

### 双边滤波 bilateralFilter

- `bilateralFilter(输入, 输出, d, sigmaColor, sigmaSpace)`：保留细节，边缘模糊
- 参数：卷积核大小、x 方向标准差、y 方向标准差

```cpp
bilateralFilter(m1, m5, 20, 100, 100);
```

### 灰度转换 cvtColor

- `cvtColor(输入, 输出, COLOR_BGR2GRAY)`：将图像转换为灰度图

```cpp
Mat gray;
cvtColor(m1, gray, COLOR_BGR2GRAY);
```

### 二值化 threshold

- `threshold(输入, 输出, 阈值, 最大值, 阈值类型)`：将图像二值化
- 低于阈值设为 0，高于阈值设为最大值
- `THRESH_BINARY`：标准二值化
- `THRESH_BINARY_INV`：反色二值化
- `THRESH_BINARY | THRESH_OTSU`：OTSU 自适应阈值

```cpp
Mat binary1, binary2, binary3;
threshold(gray, binary1, 127, 255, THRESH_BINARY);              // 标准二值化
threshold(gray, binary2, 127, 255, THRESH_BINARY_INV);          // 反色
threshold(gray, binary3, 0, 255, THRESH_BINARY | THRESH_OTSU);  // 自适应阈值
```

### 边缘检测 Canny

- `Canny(输入, 输出, 阈值1, 阈值2, Sobel算子大小)`：检测图像边缘
- 阈值越小，检测出的边缘越多

```cpp
Mat can1, can2;
Canny(gray, can1, 90, 90);
Canny(gray, can2, 190, 190);
```
