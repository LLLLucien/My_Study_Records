# OpenCV 视频处理

## 图像基础

### 图形与图像

**图形**：工具绘制的画面。

**图像**：设备采集并进行数字编码后存储到计算机的画面。

### 图像格式与压缩

**BMP**：无损压缩，位图，存储每个像素的原始信息，与颜色丰富度无关。

有损压缩与颜色丰富度有关，常见格式如下：

- **PNG**：32 位四通道，多一个 alpha 通道（透明度），便于网络传输
- **JPEG**：24 位三通道
- **GIF**：8 位三通道，动图
- **webP**：压缩比例极致

### 位深

- 24 位：一个像素 3 个字节
- 32 位：一个像素 4 个字节
- 8 位：一个像素 1 个字节

## 工具下载

- `vlc`：播放器
- `ffmpeg`：解码器

## 视频采集

### 打开视频与摄像头

`VideoCapture` 用于采集视频，可以打开摄像头或视频文件：

- `capture.open(0, CAP_ANY)`：打开摄像头，第一个参数是摄像头编号
- `capture.open("./video1.avi")`：打开视频文件

```cpp
VideoCapture capture;
if (!capture.open(0, CAP_ANY))
{
    cout << "打开视频文件失败" << endl;
    return -1;
}
```

### 循环读取帧

`capture.read(frame)` 每次读取一帧，读到视频结尾返回 `false`，可用来控制循环：

```cpp
Mat frame;
while (capture.read(frame))
{
    // 处理每一帧
}
```

### 帧处理注意事项

- `threshold` 只接受单通道（灰度）图像，三通道的 RGB 图像直接使用会崩溃
- 要做阈值分割，必须先转灰度：`cvtColor(frame, frame, COLOR_BGR2GRAY)`
- `bilateralFilter` 不支持原地操作，需要单独的 `Mat` 作为输出

```cpp
Mat gray, filtered;
cvtColor(frame, gray, COLOR_BGR2GRAY);
threshold(gray, gray, 127, 255, THRESH_BINARY | THRESH_OTSU);
bilateralFilter(frame, filtered, 201, 100, 100);
```

### 计时器与播放控制

- 视频约 30 帧/秒，每 1 帧约 0.01 秒
- 计时逻辑：每 1 帧秒针走 1 格，满 60 秒进分、满 60 分进时
- 用 `sprintf` 把时分秒格式化为字符串，再用 `putText` 显示到画面上
- `waitKey(10)` 延时控制播放速度；返回值为 27 时表示按下了 ESC 键

```cpp
if (++n == 60)
{
    n = 0;
    if (++s == 60)
    {
        s = 0;
        if (++m == 60)
        {
            m = 0;
            h++;
        }
    }
}
sprintf(str, "%02d:%02d:%02d:%02d", h, m, s, n);
putText(frame, str, Point(0, 60), FONT_HERSHEY_PLAIN, 5, Scalar(255, 255, 255), 5);
if (waitKey(10) == 27)
{
    break;
}
```

### 视频采集完整示例

```cpp
#include "opencv2/opencv.hpp"
#include <iostream>

using namespace std;
using namespace cv;

int main()
{
    // 视频采集：打开摄像头
    VideoCapture capture;
    if (!capture.open(0, CAP_ANY))
    {
        cout << "打开视频文件失败" << endl;
        return -1;
    }

    Mat frame;
    Mat filtered; // 滤波输出
    int n = 0, s = 0, m = 0, h = 0;
    char str[100];

    // 循环读取每一帧并显示，直到视频播放结束
    while (capture.read(frame))
    {
        medianBlur(frame, filtered, 21);

        // 计时器：每 1 帧秒针走 1 格，满 60 秒进分、满 60 分进时
        if (++n == 60)
        {
            n = 0;
            if (++s == 60)
            {
                s = 0;
                if (++m == 60)
                {
                    m = 0;
                    h++;
                }
            }
        }
        sprintf(str, "%02d:%02d:%02d:%02d", h, m, s, n);
        putText(filtered, str, Point(0, 60), FONT_HERSHEY_PLAIN, 5,
                Scalar(255, 255, 255), 5);
        imshow("video", filtered);

        // 按 ESC 键退出
        if (waitKey(10) == 27)
        {
            break;
        }
    }

    // 播放结束，释放资源
    capture.release();
    destroyAllWindows();
    return 0;
}
```

## 视频录制

### 视频格式（容器）

容器格式负责把视频流、音频流等打包在一起，常见的有：

- `mp4`：常见格式，编码方案有 `mp4v`、`h264`、`h265`
- `avi`：老式格式
- `mov`：苹果（Apple）格式
- `mtk`
- `ogg`
- `webM`

### 编码处理

容器是"箱子"，编码是"箱子里的货物"，同一个 `.mp4` 容器可以装不同的视频编码。编码标识由 4 个字符组成：

- `mp4v`（`m` `p` `4` `v`）：MPEG-4 编码，常见
- `avc1`（`a` `v` `c` `1`）：H.264 编码，主流、体积小、工业标准
- `hev1`（`h` `e` `v` `1`）：H.265 编码，支持 4K、占 CPU、最新
- `xvid`（`x` `v` `i` `d`）：Xvid 编码，用于 `.avi` 格式

### VideoWriter 保存视频

`VideoWriter` 用于把帧写入视频文件，`out.open()` 的五个参数：

1. 输出文件名：保存路径，如 `"xvid.avi"`
2. 编码格式：`VideoWriter::fourcc(...)` 指定，4 个字符对应上面的编码标识
3. 帧率：如 30
4. 分辨率：`Size(宽, 高)`
5. 是否彩色：`true` 彩色，`false` 灰度

保存不同格式的视频需要对应的编码格式：

```cpp
VideoWriter out;
string path = "xvid.avi";
int fourcc = VideoWriter::fourcc('x', 'v', 'i', 'd');
int fps = 30;
int w = capture.get(CAP_PROP_FRAME_WIDTH);
int h = capture.get(CAP_PROP_FRAME_HEIGHT);
Size size(w, h);

if (!out.open(path, fourcc, fps, size, true))
{
    cout << "创建视频写入对象失败" << endl;
    return -1;
}
```

- `capture.get(CAP_PROP_FRAME_WIDTH)`：获取摄像头采集画面的宽
- `capture.get(CAP_PROP_FRAME_HEIGHT)`：获取摄像头采集画面的高
- `resize(frame, frame, size)`：写入前把帧缩放到指定尺寸
- `out.write(frame)`：把一帧写入视频文件

### 视频录制完整示例

```cpp
#include "opencv2/highgui.hpp"
#include "opencv2/imgproc.hpp"
#include "opencv2/opencv.hpp"
#include <cstdio>
#include <iostream>

using namespace std;
using namespace cv;

int n = 0, h = 0, m = 0, s = 0;
char str[100];

void get_time(Mat filtered)
{
    n += 2;
    if (n == 60)
    {
        n = 0;
        if (++s == 60)
        {
            s = 0;
            if (++m == 60)
            {
                m = 0;
                h++; // 小时进位（视频不够长时用不到，可留）
            }
        }
    }
    sprintf(str, "%02d:%02d:%02d:%02d", h, m, s, n);
    putText(filtered, str, Point(0, 60), FONT_HERSHEY_PLAIN, 5,
            Scalar(255, 255, 255), 5);
}

int main()
{
    // 视频采集：打开摄像头
    VideoCapture capture;
    // 视频保存：创建视频写入对象
    VideoWriter out;
    if (!capture.open(0, CAP_ANY))
    {
        cout << "打开视频文件失败" << endl;
        return -1;
    }

    Mat frame;
    // 输出文件路径
    string path = "xvid.avi";
    // 视频编码格式
    int fourcc = VideoWriter::fourcc('x', 'v', 'i', 'd');
    // 视频帧率
    int fps = 30;
    // 视频分辨率
    int w = capture.get(CAP_PROP_FRAME_WIDTH);
    int h = capture.get(CAP_PROP_FRAME_HEIGHT);
    Size size(w, h);
    if (!out.open(path, fourcc, fps, size, true))
    {
        cout << "创建视频写入对象失败" << endl;
        return -1;
    }

    for (int j = 0; j < 300; j++)
    {
        capture.read(frame);
        // 写入前把帧缩放到 out.open 指定的 size
        resize(frame, frame, size);
        get_time(frame);
        imshow("frame", frame);
        out.write(frame);
        if (waitKey(10) == 27)
        {
            break;
        }
    }

    capture.release();
    out.release();
    destroyAllWindows();
    return 0;
}
```
