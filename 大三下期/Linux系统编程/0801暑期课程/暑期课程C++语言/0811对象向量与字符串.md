# C++ 面向对象

## 字符串与vector

- 需要头文件 `#include <string>`

```c++
#include <iostream>
#include <string>

using namespace std;

int main(int argc, char const *argv[])
{
    string s1;           // 长度为0的空字符串
    string s2 = "hello"; // 拷贝字面量
    string s3("hello");  // 直接初始化
    string s4(6, 'a');   // 6个a

    cout << s1 << endl;
    cout << s2 << endl;
    cout << s3 << endl;
    cout << s4 << endl;
}
```

### 赋值操作

```c++
cin >> s1;
```

`cin >>` 读取到空格或换行就结束。

读取一整行使用 `getline`：

```c++
getline(cin, s1);
```

### 循环输入与判断

```c++
while (getline(cin, s1))
{
    if (s1.empty())
        break;
    cout << s1 << endl;

    auto len = s1.size();
    cout << "size:" << len << endl;
}
```

### 字符串拼接

```c++
cout << s2 + " 123" + s3 << endl;
string s5 = s2 + "0 000" + s3;
cout << s5 << endl;
```

使用 `append()` 拼接：

```c++
string s7 = "cpp";
s7.append("okok");
```

> 注意：不能直接拼接两个字面量 `string s6 = "hello" + "world";` 是错误的。

### 比较与遍历

字符串可以直接用 `==` 比较：

```c++
string s8 = "abcddd";
string s9 = "dacdds";
if (s8 == s9)
{
    cout << "相同" << endl;
}
```

遍历字符串，`[]` 不做越界检查，`at()` 会做越界检查：

```c++
string s10 = "hello";
for (size_t i = 0; i < s10.size(); i++)
{
    cout << s10[i] << endl;     // 不检查越界
    cout << s10.at(i) << endl;  // 检查越界，更安全
}
```

### 范围 for 遍历

四种 `for` 遍历方式：

```c++
// 拷贝每个字符，修改 r 不影响原字符串
for (auto r : s10)
{
    r++;
}

// 引用每个字符，修改 r 等同于修改原字符串
for (auto &r : s10)
{
    r -= 32;
}

// 只读引用，不可修改，性能好（避免拷贝）
for (const auto &r : s10)
{
}

// 万能引用，可修改临时变量
for (auto &&r : s10)
{
}
```

引用可以层层传递：

```c++
auto &w = s1;
auto &t = w;
auto &g = t;
```

### 字符串函数

- `size()`：返回字符串包含的字符数量
  - `s1.size();`
- `capacity()`：返回分配的数组总大小（容量）
  - `s1.capacity();`
- `at(n)`：访问下标 n 的字符，会做越界检查
  - `s1.at(1);`
- `insert(pos, str)`：在 pos 位置插入字符串
  - `s1.insert(2, "2026");`
- `clear()`：清空内容，但容量不变
  - `s1.clear();`
- `resize(n)`：重新指定字符数量（改的是 size，不是 capacity）
  - `s1.resize(10);`
- `append(str)`：在末尾拼接字符串
  - `s1.append("okok");`
- `shrink_to_fit()`：缩容，使 capacity 与 size 匹配
  - `s1.shrink_to_fit();`
- `replace(pos, len, str)`：从 pos 开始替换 len 个字符为 str
  - `s1.replace(3, 5, str);`
- `replace(pos, len, str, s, n)`：替换 [pos, len] 为 str 的 [s, n] 子串
  - `s1.replace(3, 5, str, 7, 8);`

参考手册：<https://en.cppreference.com/w/cpp/string/basic_string>

## vector

vector 是动态数组容器（模板类型），需引入 `<vector>` 头文件。

### 初始化

```c++
#include <iostream>
#include <vector>

using namespace std;

int main(int argc, char const *argv[])
{
    vector<int> v1;                 // size=0
    vector<int> v2(10);             // size=10，10个0
    vector<int> v3(10, 1);          // size=10，10个1
    vector<int> v4{10, 1};          // size=2，含有10和1
    vector<string> v5(10, "hello"); // 存了10个hello，size=10

    for (auto &&i : v5)
    {
        cout << i << ",";
    }
    cout << v5.size() << "," << endl;
}
```

- `vector<int> v1;`：size=0 的空容器
- `vector<int> v2(10);`：10 个元素，初值 0
- `vector<int> v3(10, 1);`：10 个元素，初值 1
- `vector<int> v4{10, 1};`：2 个元素，分别是 10 和 1
- `vector<string> v5(10, "hello");`：10 个 `"hello"`

### 容量与增长

```c++
v1.reserve(17); // 预分配 17 个空间（capacity=17，size 不变）
cout << v1.size() << "," << v1.capacity() << endl;

for (int i = 0; i < 17; i++)
{
    v1.push_back(i);  // 从末尾插入
    cout << v1.size() << "," << v1.capacity() << endl;
}
```

`push_back()` 从末尾插入元素，`size` 随之增加。当 `size > capacity` 时，vector 自动扩容（通常是翻倍）。

`reserve(n)` 只预分配容量，不改变 size。

### 增删与访问

```c++
v1.pop_back();  // 删除末尾元素（无返回值）
```

```c++
vector<int> v6 = {100, 200, 300};
v6.front();  // 取得第一个元素 → 100
v6.back();   // 取得最后一个元素 → 300
int *p = v6.data();  // 获取底层数组指针
```

### 拷贝

```c++
vector<int> v7;
v7 = v6;   // 深拷贝，v7 是 v6 的独立副本
```

### 迭代器与插入

迭代器相当于指向容器内元素的指针。

```c++
auto it = v6.begin();    // 指向第一个元素
v6.insert(it, 666);      // 在第一个位置插入 666
```

用迭代器遍历：

```c++
for (auto i = v6.begin(); i != v6.end(); i++)
{
    // *i 即当前元素
}
```
