# 数据库

## 基本概念

**数据库管理系统（DBMS / 数据库服务器）**：通常指数据库是一个软件，核心功能包括创建数据库、存储数据、管理数据、查询数据。

**数据库**：实际上的数据库是磁盘上的一组文件（数据文件、日志文件、配置文件）。

**数据库实例**：一个数据库实例对应一个数据库文件夹，一个数据库实例可以有多个数据库。

> 类比：通过 Excel 软件操作 Excel 文件。

## 数据库类型

- 关系数据库
  - MySQL _开源，使用C++_
  - PostgreSQL _开源，使用C，目前前景好_
  - Oracle _生产环境需要付费_
  - Db2 _生产环境需要付费_
  - SQLite _嵌入式，可内嵌_
  - ...
- 对象数据库
- NoSQL 不使用SQL语言数据库，Not Only SQL
  - 文档数据库：mongoDB
  - 键值数据库：redis（哈希表）
  - 行数据库：hbase，clickHouse
  - 图数据库：neo4J
  - 时序数据库

## MySQL

- `sudo apt install mysql-server`：安装
- `sudo systemctl status mysql`：查看服务状态
- `sudo service mysql status`：查看服务状态
- `sudo netstat -tpnl | grep mysql`：查看监听端口
- `sudo service mysql start`：启动服务
- `sudo service mysql stop`：停止服务
- `sudo service mysql restart`：重启服务

## 连接

- `mysql`：命令行客户端
- MySQL GUI：图形化客户端（如 Navicat、DBeaver 等）

### 命令行连接

```bash
sudo mysql
```

### MySQL基本操作

- `\s`：查看当前连接状态信息
- `\c`：取消当前输入（中断语句）
- `\q`：退出 MySQL 客户端
- `\G`：查询结果竖向显示（替代分号结尾）

```sql
-- 查看所有数据库
show databases;
-- 创建数据库 abc
create database abc;
-- 删除数据库 abc
drop database abc;
-- 切换/使用数据库 abc
use abc;
-- 查看当前库下所有表
show tables;
-- 查看表结构(字段、类型等)
desc table_name;
-- 查询表中所有数据(横向表格)
select * from table_name;
-- 查询表中所有数据(竖向显示,每行一个字段)
select * from table_name\G;

-- 查询用户表信息
select host,user from user;
```

## SQL 结构化查询语言

SQL 是一套技术规范，用于操作关系型数据库。

#### DDL（数据定义语言）

| 命令       | 作用                     |
| ---------- | ------------------------ |
| `create`   | 创建（库、表）           |
| `drop`     | 删除（库、表）           |
| `alter`    | 修改（表结构）           |
| `truncate` | 清空（表数据，保留结构） |

#### DML（数据操作语言）

即 CRUD：Create（增）、Read（查）、Update（改）、Delete（删）。

| 命令     | 作用     |
| -------- | -------- |
| `insert` | 插入数据 |
| `select` | 查询数据 |
| `update` | 更新数据 |
| `delete` | 删除数据 |

#### TCL 事务控制语言

- `begin` 开始事务
- `commit` 提交事务
- `rollback` 回滚事务

#### 基础用法示例

```sql
create table person
(
    name varchar(16) NOT NULL,
    age int default 18,
    gender enum('male','female')default 'male',
    tel char(11)
);

insert person values('tom',20,'male','13812345678');

insert person(name) values('jack');

insert person(name,age) values('jack',20),('tom',20);
```

### 常用内置函数

- `sysdate()`：系统日期时间
- `curtime()`：当前时间
- `curdate()`：当前日期
- `now()`：当前日期时间

#### 预览效果

```sql
select now(), sysdate(), curtime(), curdate() from dual;
```

```
+---------------------+---------------------+-----------+------------+
| now()               | sysdate()           | curtime() | curdate()  |
+---------------------+---------------------+-----------+------------+
| 2026-08-03 14:42:58 | 2026-08-03 14:42:58 | 14:42:58  | 2026-08-03 |
+---------------------+---------------------+-----------+------------+
```

### 其他常用函数

- `adddate()`：日期加天数
- `datediff()`：两个日期相差天数

```sql
-- 今天 + 30 天（如 8.3 → 9.2）
select adddate(curdate(), 30);
-- 距 2000-1-1 过了多少天
select datediff(curdate(), "2000-1-1");
-- 距 2027-4-13 还有多少天
select datediff("2027-4-13", curdate());
```

### 字符串

- `char(255)`：定长字符串，最大 255 字符
- `varchar(n)`：可变长度，实际占用 n+1 字节

### JSON

JSON（JavaScript Object Notation，JavaScript 对象表示法）是一种轻量级数据交换格式。

- `{}`：对象（键值对）
- `[]`：列表

#### JSON 对象示例

```js
{
    "x":2,
    "y":3,
    "z":8.9,
    "n":[1,2,3,4],
    "m":{
        "a":"ok",
        "b":600
    }
}
```

#### JSON 列表示例

```js
[2, 3, 4, 5][({ x: 1, y: 2 }, { x: 1, y: 2 }, { x: 1, y: 2 }, { x: 1, y: 2 })];
```

#### JSON 示例

```sql
create table t3
(
    x int,
    y int,
    z int
);
-- 不确定列数及列格式时，可直接用 JSON
create table t3
(
    c1 JSON
);

insert t3 values('{"x":1,"y":200,"z":[100,200]}'),('{"n":"ok"}');

+-------------------------------------+
| c1                                  |
+-------------------------------------+
| {"x": 1, "y": 200, "z": [100, 200]} |
| {"x": 1, "y": 200, "z": [100, 200]} |
| {"n": "ok"}                         |
+-------------------------------------+
```

## 关系建模

- 表存储
  - 实体或概念的属性
  - 实体和实体之间的关系

- 关系范式
  - 1NF：列不可再分，每列都是原子值（无重复组、无嵌套表）
  - 2NF：满足1NF + 非主键列必须完全依赖于**整个主键/复合主键**（消除部分依赖）
  - 3NF：满足2NF + 非主键列不能传递依赖于主键（消除传递依赖）

```sql
    create table t5
    (
        id int auto_increment primary key, --主键
        name char(16),
        gender enum("M","F"),
        birthday date,
        tel char(11),
        mother int  --FK外键
    )
```
