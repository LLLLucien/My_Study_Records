# 数据库

## SQL优化

**索引**：B+Tree（3~4 层）、叶子节点为双向链表（支持范围查询）、Hash。

- 自动建索引：主键、唯一约束、外键
- 手动创建：`where`、`order by`、`group by`、`join`、`limit`、`offset`、`having`、`union`、`distinct`
- 优点：避免全表扫描
- 缺点：回表问题；影响插入、删除、更新、查询速度

**SQL语句优化**：

- 禁用 `select *`
- 避免子查询和临时表（基于执行计划再次优化）
- `join` 优化：小表驱动大表、`where` 条件优化、索引优化
- 批量写
  - `insert into t1 values (1,2,3),(4,5,6);`
  - 并入事务中
- 执行计划 `explain`：`explain select * from staff where id = 1;`

**缓存**：`redis`

**分表**：

- 分表策略：数值范围、值、Hash
- 分表类型：水平分表、垂直分表
  - 水平：`create table t1_p0 as select * from t1 where year < 1990;`
  - 垂直：`create table t1_p0 as select id, year from t1;`

```sql
create table t1(
    id int primary key,
    year int

)

PARTITION BY RANGE(year) (
    PARTITION p0 VALUES LESS THAN (1990),
    PARTITION p1 VALUES LESS THAN (2000),
    PARTITION p2 VALUES LESS THAN (2010)
    );
```

创建一个和 t1 结构相同的表 t1_p0：

```sql
CREATE TABLE t1_p0
AS
SELECT * FROM t1 WHERE 1=2;
```

**分库**：

- 读写分离：主从架构、分库分表、分库分表 + 读写分离

## Redis

**Redis**：基于内存的 Key-Value 缓存服务，数据结构丰富，读写速度极快（微秒级）。

### 数据类型

| 类型         | 用途                   |
| ------------ | ---------------------- |
| `string`     | 普通缓存、计数器       |
| `list`       | 队列、栈               |
| `set`        | 无重复元素集合         |
| `sorted set` | 有序集合（带分数排序） |
| `hash`       | 键值对集合（类似对象） |

### 不适合场景

- 大规模冷数据
- 不支持事务
- 大规模检索

### 安装

- `sudo apt install redis`：安装 Redis
- `sudo service redis status`：查看服务状态
- `sudo netstat -tpnl | grep redis`：查看端口占用
- 默认端口：6379

### 使用

- `redis-cli`：启动 Redis 客户端

**String 操作**：

```bash
set key value nx     # nx 表示 key 不存在时才设置
set count 0          # 设置计数器
```

**List 操作**：

```bash
lpush list 1 a b c   # 左侧插入（栈）
rpush list 1 a b c   # 右侧插入（队列）
lrange list 0 -1     # 获取全部元素
```

**Set 操作**：

```bash
sadd s1 a b c d e f  # 添加元素
sadd s2 a b c d e f
sunion s1 s2         # 并集
sdiff s1 s2          # 差集
sinter s1 s2         # 交集
smembers s1          # 获取集合全部元素
srandmember s1 10    # 随机获取 10 个元素
spop s1 10           # 随机删除 10 个元素
```

**Hash 操作**：

```bash
hset u:123 name xxx age 18   # 设置哈希
hget u:123 name              # 获取指定字段
hgetall u:123                # 获取所有字段
```

**Sorted Set 操作**：

```bash
zadd top10 9 alice 8 bob 7 charlie 6   # 添加带分数元素
zrange top10 0 -1                       # 按分数升序获取
zrangebyscore top10 -inf +inf withscores  # 带分数查询
zrevrange top10 0 -1                    # 按分数降序获取
zincrby top10 10 alice                  # 增加分数
```

> Key 命名建议：使用 `:` 分隔层级，如 `user:1001:name`、`dept:001`。

## 进程

**进程**：运行中的程序，是操作系统资源分配的最小单位。

**线程**：进程中独立的执行单元，是 CPU 调度和分派的基本单位。

### 多进程

- `fork()`：创建子进程
- `exec()`：执行程序
- `getpid`：获取当前进程 ID
- `getppid`：获取父进程 ID

### 进程类型

- 孤儿进程：父进程退出，子进程被 init 进程接管
- 僵尸进程：子进程退出，父进程未调用 `wait` 或 `waitpid` 获取子进程状态
- 守护进程：后台运行，不受终端控制

- waitpid

```c
// p1.c

#include <stdio.h>
#include <stdlib.h>
#include <sys/wait.h>
#include <unistd.h>
#define N 8
// unix std - POSIX 规范定义的标准 API
int main(void)
{
    //  __PID_T_TYPE pid = fork();
    for (int i = 0; i < N; i++)
    {
        __PID_T_TYPE pid = fork();
        if (pid == 0)
        {
            printf("我是子进程,worker=%d,master=%d\n", getpid(), getppid());
            sleep(5);
            int val = i + 40;
            exit(val);
        }
    }

    for (int i = 0; i < N; i++)
    {
        int status;
        waitpid(-1, &status, WUNTRACED);
        if (WIFEXITED(status))
        {
            int val = WEXITSTATUS(status);
            printf("val=%d\n", val);
        }
    }
    printf("master :end\n");
    return 0;
}
```

### exec 函数族

**exec**：Execute，用新程序替换当前进程的代码段，PID 不变，但执行的内容全部替换。exec 调用成功后不会返回（原程序被覆盖），失败时返回 -1。

| 函数名   | 参数形式         | 路径查找方式         |
| -------- | ---------------- | -------------------- |
| `execl`  | list（逗号分隔） | 完整路径             |
| `execv`  | array（数组）    | 完整路径             |
| `execlp` | list（逗号分隔） | 用 PATH 环境变量查找 |
| `execvp` | array（数组）    | 用 PATH 环境变量查找 |

**`execl` — 完整路径 + 参数列表**：

```c
      // execl(路径, 程序名, arg1, arg2, ..., NULL)
      // 路径:   可执行文件的完整路径
      // 程序名: 传给进程的 argv[0]（通常是程序名本身）
      // argN:   逐个传入的命令行参数
      // NULL:   参数结束标记（必须）

      execl("/bin/ls", "ls", "-l", "-a", NULL);
      //      路径        程序名  参数1 参数2  结束
```

**`execv` — 完整路径 + 参数数组**：

```c
    // execv(路径, 参数数组)
    // 数组最后一个元素必须是 NULL

    char *args[] = {"ls", "-l", "-a", NULL};
    execv("/bin/ls", args);
    //      路径      参数数组
```

**`execlp` — 用 PATH 查找 + 参数列表**：

```c
      // execlp(文件名, 程序名, arg1, ..., NULL)
      // 文件名: 只需文件名，系统从 PATH 环境变量中搜索
      // 其余参数同 execl

      execlp("ls", "ls", "-l", NULL);
      //      文件名 程序名 参数  结束

      execlp("./abc2", "abc2", NULL);
      //     相对路径也算"路径"，不依赖 PATH
```

**`execvp` — 用 PATH 查找 + 参数数组**：

```c
      // execvp(文件名, 参数数组)

      char *args[] = {"ls", "-l", "-a", NULL};
      execvp("ls", args);
```

### 完整示例

```c
// p1.c — fork + execlp 父子进程通信

#include <stdio.h>
#include <stdlib.h>
#include <sys/wait.h>
#include <unistd.h>

int main(void)
{
    __PID_T_TYPE pid = fork();
    printf("pid=%d\n", pid);
    if (pid == -1)
    {
        perror("创建失败\n");
        return EXIT_FAILURE;
    }

    if (pid == 0)
    {
        // 子进程
        printf("我是p1子进程,worker=%d,master=%d\n", getpid(), getppid());

        // 用 abc2 程序替换当前子进程
        // 参数依次为：文件名、程序名、NULL（结束标记）
        execlp("./abc2", "abc2", NULL);

        // 若 execlp 失败才会执行到此处
        exit(42);
    }
    else
    {
        // 父进程：等待子进程结束并获取退出状态
        printf("我是p1父进程,worker=%d,master=%d\n", getpid(), getppid());
        sleep(15);
        int status;
        waitpid(pid, &status, WUNTRACED);
        if (WIFEXITED(status))
        {
            int val = WEXITSTATUS(status);
            printf("val=%d", val);
        }
    }
    return 0;
}
```
