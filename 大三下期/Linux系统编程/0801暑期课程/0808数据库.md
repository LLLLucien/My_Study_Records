# 数据库

## SQL优化

**索引**：B+Tree（3~4 层）、叶子节点为双向链表（支持范围查询）、Hash。

- 自动建索引：主键、唯一约束、外键
- 手动创建：`where`、`order by`、`group by`、`join`、`limit`、`offset`、`having`、`union`、`distinct`
- 优点：避免全表扫描
- 缺点：回表问题；影响插入、删除、更新、查询速度

**SQL语句优化**：

- 禁用 `select *`
- 避免子查询和临时表（基于执行计划再次优化）
- `join` 优化：小表驱动大表、`where` 条件优化、索引优化
- 批量写
  - `insert into t1 values (1,2,3),(4,5,6);`
  - 并入事务中
- 执行计划 `explain`：`explain select * from staff where id = 1;`

**缓存**：`redis`

**分表**：

- 分表策略：数值范围、值、Hash
- 分表类型：水平分表、垂直分表
  - 水平：`create table t1_p0 as select * from t1 where year < 1990;`
  - 垂直：`create table t1_p0 as select id, year from t1;`

```sql
create table t1(
    id int primary key,
    year int

)

PARTITION BY RANGE(year) (
    PARTITION p0 VALUES LESS THAN (1990),
    PARTITION p1 VALUES LESS THAN (2000),
    PARTITION p2 VALUES LESS THAN (2010)
    );
```

创建一个和 t1 结构相同的表 t1_p0：

```sql
CREATE TABLE t1_p0
AS
SELECT * FROM t1 WHERE 1=2;
```

**分库**：

- 读写分离：主从架构、分库分表、分库分表 + 读写分离

## Redis

**Redis**：基于内存的 Key-Value 缓存服务，数据结构丰富，读写速度极快（微秒级）。

### 数据类型

| 类型         | 用途                   |
| ------------ | ---------------------- |
| `string`     | 普通缓存、计数器       |
| `list`       | 队列、栈               |
| `set`        | 无重复元素集合         |
| `sorted set` | 有序集合（带分数排序） |
| `hash`       | 键值对集合（类似对象） |

### 不适合场景

- 大规模冷数据
- 不支持事务
- 大规模检索

### 安装

- `sudo apt install redis`：安装 Redis
- `sudo service redis status`：查看服务状态
- `sudo netstat -tpnl | grep redis`：查看端口占用
- 默认端口：6379

## 进程

**进程**：运行中的程序，是操作系统资源分配的最小单位。

**线程**：进程中独立的执行单元，是 CPU 调度和分派的基本单位。

### 多进程

- `fork()`：创建子进程
- `exec()`：执行程序
- `getpid`：获取当前进程 ID
- `getppid`：获取父进程 ID

### 进程类型

- 孤儿进程：父进程退出，子进程被 init 进程接管
- 僵尸进程：子进程退出，父进程未调用 `wait` 或 `waitpid` 获取子进程状态
- 守护进程：后台运行，不受终端控制

- waitpid

```c
// p1.c

#include <stdio.h>
#include <stdlib.h>
#include <sys/wait.h>
#include <unistd.h>
#define N 8
// unix std - POSIX 规范定义的标准 API
int main(void)
{
    //  __PID_T_TYPE pid = fork();
    for (int i = 0; i < N; i++)
    {
        __PID_T_TYPE pid = fork();
        if (pid == 0)
        {
            printf("我是子进程,worker=%d,master=%d\n", getpid(), getppid());
            sleep(5);
            int val = i + 40;
            exit(val);
        }
    }

    for (int i = 0; i < N; i++)
    {
        int status;
        waitpid(-1, &status, WUNTRACED);
        if (WIFEXITED(status))
        {
            int val = WEXITSTATUS(status);
            printf("val=%d\n", val);
        }
    }
    printf("master :end\n");
    return 0;
}
```

### exec 函数族

**exec**：Execute，用新程序替换当前进程的代码段，PID 不变，但执行的内容全部替换。exec 调用成功后不会返回（原程序被覆盖），失败时返回 -1。

| 函数名   | 参数形式         | 路径查找方式         |
| -------- | ---------------- | -------------------- |
| `execl`  | list（逗号分隔） | 完整路径             |
| `execv`  | array（数组）    | 完整路径             |
| `execlp` | list（逗号分隔） | 用 PATH 环境变量查找 |
| `execvp` | array（数组）    | 用 PATH 环境变量查找 |

**`execl` — 完整路径 + 参数列表**：

```c
      // execl(路径, 程序名, arg1, arg2, ..., NULL)
      // 路径:   可执行文件的完整路径
      // 程序名: 传给进程的 argv[0]（通常是程序名本身）
      // argN:   逐个传入的命令行参数
      // NULL:   参数结束标记（必须）

      execl("/bin/ls", "ls", "-l", "-a", NULL);
      //      路径        程序名  参数1 参数2  结束
```

**`execv` — 完整路径 + 参数数组**：

```c
    // execv(路径, 参数数组)
    // 数组最后一个元素必须是 NULL

    char *args[] = {"ls", "-l", "-a", NULL};
    execv("/bin/ls", args);
    //      路径      参数数组
```

**`execlp` — 用 PATH 查找 + 参数列表**：

```c
      // execlp(文件名, 程序名, arg1, ..., NULL)
      // 文件名: 只需文件名，系统从 PATH 环境变量中搜索
      // 其余参数同 execl

      execlp("ls", "ls", "-l", NULL);
      //      文件名 程序名 参数  结束

      execlp("./abc2", "abc2", NULL);
      //     相对路径也算"路径"，不依赖 PATH
```

**`execvp` — 用 PATH 查找 + 参数数组**：

```c
      // execvp(文件名, 参数数组)

      char *args[] = {"ls", "-l", "-a", NULL};
      execvp("ls", args);
```

### 完整示例

```c
// p1.c — fork + execlp 父子进程通信

#include <stdio.h>
#include <stdlib.h>
#include <sys/wait.h>
#include <unistd.h>

int main(void)
{
    __PID_T_TYPE pid = fork();
    printf("pid=%d\n", pid);
    if (pid == -1)
    {
        perror("创建失败\n");
        return EXIT_FAILURE;
    }

    if (pid == 0)
    {
        // 子进程
        printf("我是p1子进程,worker=%d,master=%d\n", getpid(), getppid());

        // 用 abc2 程序替换当前子进程
        // 参数依次为：文件名、程序名、NULL（结束标记）
        execlp("./abc2", "abc2", NULL);

        // 若 execlp 失败才会执行到此处
        exit(42);
    }
    else
    {
        // 父进程：等待子进程结束并获取退出状态
        printf("我是p1父进程,worker=%d,master=%d\n", getpid(), getppid());
        sleep(15);
        int status;
        waitpid(pid, &status, WUNTRACED);
        if (WIFEXITED(status))
        {
            int val = WEXITSTATUS(status);
            printf("val=%d", val);
        }
    }
    return 0;
}
```

### 守护进程

守护进程（Daemon）是脱离终端、在后台长期运行的进程，通常在系统启动时运行、关机时结束。

**核心要求：脱离控制终端、脱离原会话、不受终端信号影响。**

#### 创建步骤

| 步骤 | 函数/操作 | 目的 |
|------|----------|------|
| 1 | `fork()`，父进程退出 | shell 返回提示符；子进程不再是进程组首 |
| 2 | `setsid()` | 创建新会话，脱离原控制终端 |
| 3 | `fork()`，父进程退出 | 最终进程不是会话首，防止后续打开终端设备变成控制终端 |
| 4 | `umask(0)` | 清除文件权限掩码 |
| 5 | `chdir("/")` | 避免占用启动目录所在文件系统 |
| 6 | 关闭所有文件描述符 | 清理从父进程继承的终端连接 |
| 7 | fd 0/1/2 重定向到 `/dev/null` | 保证标准 I/O 不报错、不串线 |

#### 完整代码

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <fcntl.h>
#include <sys/stat.h>
#include <sys/types.h>

void daemonize()
{
    pid_t pid;

    // 步骤 1：第一次 fork，父进程退出
    pid = fork();
    if (pid < 0) {
        perror("fork 1");
        exit(EXIT_FAILURE);
    }
    if (pid > 0) {
        // 父进程退出 → shell 立刻收到提示符
        exit(EXIT_SUCCESS);
    }

    // 步骤 2：子进程创建新会话，成为会话首
    // 效果：脱离原控制终端
    if (setsid() == -1) {
        perror("setsid");
        exit(EXIT_FAILURE);
    }

    // 步骤 3：第二次 fork，父进程(会话首)退出
    pid = fork();
    if (pid < 0) {
        perror("fork 2");
        exit(EXIT_FAILURE);
    }
    if (pid > 0) {
        // 会话首退出 → 最终进程不再是会话首
        exit(EXIT_SUCCESS);
    }

    // 步骤 4：清除 umask
    umask(0);

    // 步骤 5：切换工作目录到根目录
    // 防止守护进程所在目录（如 U盘）无法卸载
    if (chdir("/") == -1) {
        perror("chdir");
        exit(EXIT_FAILURE);
    }

    // 步骤 6：关闭所有从父进程继承的文件描述符
    long max_fd = sysconf(_SC_OPEN_MAX);
    for (int fd = 3; fd < max_fd; fd++) {
        close(fd);
    }

    // 步骤 7：将 0/1/2 重定向到 /dev/null
    // /dev/null：写入即丢弃，读取即 EOF
    int fd0 = open("/dev/null", O_RDWR);
    if (fd0 != -1) {
        dup2(fd0, STDIN_FILENO);   // fd 0 → /dev/null
        dup2(fd0, STDOUT_FILENO);  // fd 1 → /dev/null
        dup2(fd0, STDERR_FILENO);  // fd 2 → /dev/null
        if (fd0 > 2) {
            close(fd0);
        }
    }
}

int main()
{
    // 调用守护进程化函数
    daemonize();

    // ====== 守护进程的实际工作代码 ======
    while (1) {
        // 你的业务逻辑，比如写日志、监听端口等
        sleep(10);
    }

    return 0;
}
```

#### 各步骤详解

**步骤 1 — 第一次 fork**：子进程的 PID ≠ 继承的 PGID，所以子进程**不是进程组首**。这是调用 `setsid()` 的前提条件（进程组首调用 `setsid()` 会失败）。

**步骤 2 — `setsid()`**：做三件事：
- 创建一个新会话；
- 调用者成为会话首 + 新进程组首；
- 断开与原控制终端的关联。

**步骤 3 — 第二次 fork**：会话首 fork 产生孙子进程，会话首退出。孙子进程**不是会话首**，后续打开任何终端设备都不会自动获得控制终端，彻底避免意外接管终端。

**步骤 6 — 关闭描述符**：为什么从 fd 3 开始关？
- fd 0、1、2 在步骤 7 中会被重定向，无需单独关闭。如果先关闭 0、1、2，`open("/dev/null")` 可能占用 0、1、2 中的某个，但因为我们立即 `dup2`，所以没有实质问题。

**步骤 7 — 重定向到 `/dev/null`**：用 `dup2()` 而不是 `close()` + `open()` 一步一个，确保 0、1、2 **必定指向** `/dev/null`，不会因为某个 `open` 返回意外 fd 而导致错乱。
