# 数据库 - 视图、函数、存储过程、C API

## 回顾

- 关系范式：1NF、2NF、3NF
- 表之间的关系：
  - 一对一：共享主键，插入时可以用到 `LAST_INSERT_ID()`、序列 `currval('seq_name')`、`nextval('seq_name')`
    - `LAST_INSERT_ID()`（MySQL）：获取当前会话最后一次自增生成的 ID，先插入主表拿到 ID，再用同一个 ID 插入从表
    - `nextval('seq')`（PostgreSQL）：取序列下一个值，用于生成主键
    - `currval('seq')`（PostgreSQL）：取当前会话已获取的序列值，先 `nextval` 插入主表，再 `currval` 拿到同一个值插入从表，保证两表主键一致
  - 一对多：一个父记录关联多个子记录
  - 多对多：通过中间表建立
- 表连接
  - 内连接：只返回匹配的行
  - 外连接：保留左表或右表全部行，无匹配填 NULL
- 事务
  - 概念：一组操作要么全部成功要么全部回滚
  - 四大特性：原子性、一致性、隔离性、持久性 ACID（Atomicity、Consistency、Isolation、Durability）
  - 隔离级别：读未提交、读已提交、可重复读、串行化
- 索引
  - 概念：数据结构，用于快速查找数据的数据结构
  - 分类：唯一索引、主键索引、全文索引，普通索引、空间（GIS）索引，位图索引；低基数列
  - 实现方法：B+Tree、Hash
  - 要建索引的场景：主键、外键、where、order by、group by、distinct等

## 视图

- 是虚表，不是物理表，是逻辑表，是基于 SQL 语句的结果集
- 表：物理存储，视图：逻辑存储
- 视图的创建和删除：`CREATE VIEW`、`DROP VIEW`
- 具体业务中视图的数量可能比表的数量还多，视图的创建和删除对性能影响不大，但视图的使用会影响性能

```sql
create view v1
as
select * from staff
left join dept
on staff.dept_id = dept.id
order by staff.id;
```

各个部门的人数：

```sql
create view v_dept_count
as
select d.id, d.name, count(s.id) n
from dept d
left join staff s
on s.dept_id = d.id
group by d.id, d.name
order by d.id;
```

- 一个基于一张表的视图，可以通过视图被修改
- 一个基于多张表的视图，不能被修改

## 函数

- 内置函数
  - `ifnull(a, b)`：若 a 为 NULL 则返回 b，否则返回 a
- 自定义函数
  - 需要在 root 用户下设置
  - `set global log_bin_trust_function_creators = ON;`

```sql
create definer = `tom`@`%` function `f1`(a int, b int)
returns integer
BEGIN
    return ifnull(a, 0);
END
```

## 存储过程

- 存储过程：一段可编程的 SQL 语句
- 调用者，通过存储过程，可以实现一些复杂的业务逻辑

```sql
CREATE PROCEDURE `reg` (
    name varchar(16),
    passwd varchar(8)
)
BEGIN
    insert into user(`name`) values (name);
    insert into login values(last_insert_id(), name, sha2(passwd, 256));
    commit;
END
```

调用：

```sql
CALL AAA.new_procedure('tom', '123456');
```

## C API

- 核心数据结构
  - `MYSQL`：数据库连接句柄
  - `MYSQL_RES`：执行 SQL 获得的结果集
  - `MYSQL_ROW`：从结果集获得的一行数据（字符串数组）
  - `MYSQL_FIELD`：列的元数据（列名、大小、类型等）
- 常用函数
  - `mysql_init()`：初始化一个 `MYSQL` 对象
  - `mysql_real_connect()`：连接数据库
  - `mysql_close()`：关闭数据库连接
  - `mysql_query()`：执行 SQL 语句
  - `mysql_store_result()`：将结果集存储到 `MYSQL_RES` 对象中
  - `mysql_fetch_row()`：从结果集中获取一行数据
  - `mysql_num_fields()`：获取结果集中列的数量
  - `mysql_fetch_field()`：获取结果集中某一列的元信息
  - `mysql_free_result()`：释放结果集

#### 初始化与连接

- 编译时需要 -lmysqlclient
- gcc my.c -o my -lmysqlclient

```c
#include <mysql/mysql.h>
#include <stdio.h>
#include <stdlib.h>

#define HOST "127.0.0.1"
#define USER "tom"
#define PASSWD "123456"
#define DB "hr"
#define PORT 3306

int main(void)
{
    // 1.创建结构体,初始化
    MYSQL *conn = mysql_init(NULL);
    if (conn == NULL)
    {
        perror("mysql_init error\n");
        return EXIT_FAILURE;
    }
    printf("初始化成功\n");

    // 2.连接数据库
    if (!mysql_real_connect(conn, HOST, USER, PASSWD, DB, PORT, NULL, 0))
    {
        fprintf(stderr, "连接失败：%d ,%s\n", mysql_errno(conn), mysql_error(conn));
        mysql_close(conn);
        return EXIT_FAILURE;
    }
    printf("连接成功\n");

    return 0;
}
```

#### 获取结果集

```c
    // 4.获取结果集
    MYSQL_RES *res = mysql_store_result(conn);
    if (res == NULL)
    {
        fprintf(stderr, "获取结果集失败：%d ,%s\n", mysql_errno(conn), mysql_error(conn));
        mysql_close(conn);
        return EXIT_FAILURE;
    }
    printf("获取结果集成功\n");
    printf("行数:%ld,列数:%d\n", res->row_count, res->field_count);

    // 5.遍历结果集
    // MYSQL_ROW 本质上是链表的一个节点，存储一行数据

    // 5.1 获取列数
    MYSQL_ROW row;
    // 5.2 获取行数
    int cols = res->field_count;
    // 5.3 当行不为空时，获取行数据
    while ((row = mysql_fetch_row(res)) != NULL)
    {
        for (int i = 0; i < cols; i++)
        {
            printf("%s\t", row[i]);
        }
        printf("\n");
    }
    mysql_free_result(res);
    return 0;
```

- `MYSQL_ROWS`：链表的节点，存储一行数据
- `MYSQL_ROW`：本质是 `char **`（字符串数组），相当于 `int *a[]`，每个 `a[i]` 存储一个字符串地址

> 原理通俗理解：

```c
    int a[10] = {1,2,3};    // MySQL 内部固定的数组
    int *b;
    b = a;                   // 第1次 fetch → b 指向 {1,2,3}
    // 内部把 a 的值改了
    a[0]=4; a[1]=5; a[2]=6;
    b = a;                   // 第2次 fetch → b 还是指向同一个 a，但值变了

```

## 避免SQL注入

- 使用预编译语句
- 优点：
  - 语句在数据库端编译好了，每次调用直接执行
  - 避免SQL注入

```c
    char *sql = "SELECT id,name,city FROM dept WHERE name = ?";
    char *sql="INSERT INTO dept VALUES(NULL,?,?)"
```

- 相关函数
  - `MYSQL_STMT`：预编译语句对象
  - `MYSQL_BIND`：绑定参数对象
  - `mysql_stmt_init()`：初始化预编译语句对象
  - `mysql_stmt_prepare()`：准备 SQL 语句
  - `mysql_stmt_bind_param()`：绑定参数
  - `mysql_stmt_execute()`：执行预编译语句
  - `mysql_stmt_bind_result()`：绑定结果缓冲区（SELECT 查询用）
  - `mysql_stmt_store_result()`：将结果集缓存到客户端
  - `mysql_stmt_fetch()`：逐行获取结果
  - `mysql_stmt_num_rows()`：获取结果行数
  - `mysql_stmt_result_metadata()`：获取结果集元数据（字段信息）
  - `mysql_stmt_close()`：关闭预编译语句对象

### 使用步骤

#### 1. INSERT 预编译流程

```c
MYSQL_STMT *stmt;
MYSQL_BIND bind[2];        // 假设有 2 个参数（不含 NULL 自增列）
char name[32];
char city[32];

// 步骤 1：初始化预编译语句对象
stmt = mysql_stmt_init(conn);
if (!stmt) {
    fprintf(stderr, "mysql_stmt_init() failed\n");
    exit(1);
}

// 步骤 2：准备 SQL 语句（用 ? 占位）
char *sql = "INSERT INTO dept VALUES(NULL, ?, ?)";
if (mysql_stmt_prepare(stmt, sql, strlen(sql))) {
    fprintf(stderr, "mysql_stmt_prepare() failed: %s\n", mysql_stmt_error(stmt));
    exit(1);
}

// 步骤 3：准备用户数据
strcpy(name, "研发部");
strcpy(city, "深圳");

// 步骤 4：配置 MYSQL_BIND 绑定参数
memset(bind, 0, sizeof(bind));

// 参数1：name（第二个 ?）
bind[0].buffer_type = MYSQL_TYPE_STRING;
bind[0].buffer = (char *)name;
bind[0].buffer_length = sizeof(name);
bind[0].is_null = 0;

// 参数2：city（第三个 ?）
bind[1].buffer_type = MYSQL_TYPE_STRING;
bind[1].buffer = (char *)city;
bind[1].buffer_length = sizeof(city);
bind[1].is_null = 0;

// 步骤 5：绑定参数到预编译语句
if (mysql_stmt_bind_param(stmt, bind)) {
    fprintf(stderr, "mysql_stmt_bind_param() failed: %s\n", mysql_stmt_error(stmt));
    exit(1);
}

// 步骤 6：执行预编译语句
if (mysql_stmt_execute(stmt)) {
    fprintf(stderr, "mysql_stmt_execute() failed: %s\n", mysql_stmt_error(stmt));
    exit(1);
}

printf("插入成功，影响行数: %ld\n", (long)mysql_stmt_affected_rows(stmt));

// 步骤 7：关闭预编译语句
mysql_stmt_close(stmt);
```

#### 2. SELECT 预编译流程

```c
MYSQL_STMT *stmt;
MYSQL_BIND bind_param[1];   // 绑定条件参数（WHERE 的 ?）
MYSQL_BIND bind_result[3];  // 绑定结果列（id, name, city）
int   id;
char  name[32];
char  city[32];
long  length[3];            // 字段实际长度
my_bool is_null[3];         // 字段是否 NULL
char  search_name[32] = "研发部";  // 用户输入的查询条件（可能含恶意代码）

// 步骤 1：初始化预编译语句
stmt = mysql_stmt_init(conn);

// 步骤 2：准备 SQL 语句
char *sql = "SELECT id, name, city FROM dept WHERE name = ?";
if (mysql_stmt_prepare(stmt, sql, strlen(sql))) {
    fprintf(stderr, "prepare failed: %s\n", mysql_stmt_error(stmt));
    exit(1);
}

// 步骤 3：绑定条件参数（WHERE 子句中的 ?）
memset(bind_param, 0, sizeof(bind_param));
bind_param[0].buffer_type = MYSQL_TYPE_STRING;
bind_param[0].buffer = search_name;
bind_param[0].buffer_length = strlen(search_name);
bind_param[0].is_null = 0;

if (mysql_stmt_bind_param(stmt, bind_param)) {
    fprintf(stderr, "bind param failed: %s\n", mysql_stmt_error(stmt));
    exit(1);
}

// 步骤 4：执行
if (mysql_stmt_execute(stmt)) {
    fprintf(stderr, "execute failed: %s\n", mysql_stmt_error(stmt));
    exit(1);
}

// 步骤 5：绑定结果列（SELECT 后面的字段，按顺序对应）
memset(bind_result, 0, sizeof(bind_result));

bind_result[0].buffer_type = MYSQL_TYPE_LONG;
bind_result[0].buffer = (char *)&id;
bind_result[0].is_null = &is_null[0];
bind_result[0].length = &length[0];

bind_result[1].buffer_type = MYSQL_TYPE_STRING;
bind_result[1].buffer = name;
bind_result[1].buffer_length = sizeof(name);
bind_result[1].is_null = &is_null[1];
bind_result[1].length = &length[1];

bind_result[2].buffer_type = MYSQL_TYPE_STRING;
bind_result[2].buffer = city;
bind_result[2].buffer_length = sizeof(city);
bind_result[2].is_null = &is_null[2];
bind_result[2].length = &length[2];

if (mysql_stmt_bind_result(stmt, bind_result)) {
    fprintf(stderr, "bind result failed: %s\n", mysql_stmt_error(stmt));
    exit(1);
}

// 步骤 6：缓存结果集（必须，否则 mysql_stmt_num_rows 返回 0）
if (mysql_stmt_store_result(stmt)) {
    fprintf(stderr, "store result failed: %s\n", mysql_stmt_error(stmt));
    exit(1);
}

// 步骤 7：逐行获取结果
printf("查询到 %lld 条记录:\n", mysql_stmt_num_rows(stmt));
while (!mysql_stmt_fetch(stmt)) {
    printf("id=%d, name=%s, city=%s\n", id, name, city);
}

// 步骤 8：关闭
mysql_stmt_close(stmt);
```

#### 3. 完整过程总结

| 步骤 | INSERT / UPDATE / DELETE | SELECT |
|------|------------------------|--------|
| 1 | `mysql_stmt_init()` | `mysql_stmt_init()` |
| 2 | `mysql_stmt_prepare()` | `mysql_stmt_prepare()` |
| 3 | `mysql_stmt_bind_param()` | `mysql_stmt_bind_param()` |
| 4 | `mysql_stmt_execute()` | `mysql_stmt_execute()` |
| 5 | | `mysql_stmt_bind_result()` |
| 6 | | `mysql_stmt_store_result()` |
| 7 | | `while(mysql_stmt_fetch())` 遍历 |
| 8 | `mysql_stmt_close()` | `mysql_stmt_close()` |

> **核心原理**：预编译先将 SQL 模板发送给数据库编译，参数只作为"纯数据"传入，不会被当作 SQL 代码执行。无论用户输入的 `search_name` 是 `"1' OR '1'='1"` 还是其他恶意内容，都只会被当作字符串字面值去匹配，而不会被拼接成新的 SQL 逻辑，从而彻底杜绝 SQL 注入。
