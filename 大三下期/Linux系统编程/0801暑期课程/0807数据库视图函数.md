# 数据库 - 视图、函数、存储过程、C API

## 回顾

- 关系范式：1NF、2NF、3NF
- 表之间的关系：
  - 一对一：共享主键，插入时可以用到 `LAST_INSERT_ID()`、序列 `currval('seq_name')`、`nextval('seq_name')`
    - `LAST_INSERT_ID()`（MySQL）：获取当前会话最后一次自增生成的 ID，先插入主表拿到 ID，再用同一个 ID 插入从表
    - `nextval('seq')`（PostgreSQL）：取序列下一个值，用于生成主键
    - `currval('seq')`（PostgreSQL）：取当前会话已获取的序列值，先 `nextval` 插入主表，再 `currval` 拿到同一个值插入从表，保证两表主键一致
  - 一对多：一个父记录关联多个子记录
  - 多对多：通过中间表建立
- 表连接
  - 内连接：只返回匹配的行
  - 外连接：保留左表或右表全部行，无匹配填 NULL
- 事务
  - 概念：一组操作要么全部成功要么全部回滚
  - 四大特性：原子性、一致性、隔离性、持久性 ACID（Atomicity、Consistency、Isolation、Durability）
  - 隔离级别：读未提交、读已提交、可重复读、串行化
- 索引
  - 概念：数据结构，用于快速查找数据的数据结构
  - 分类：唯一索引、主键索引、全文索引，普通索引、空间（GIS）索引，位图索引；低基数列
  - 实现方法：B+Tree、Hash
  - 要建索引的场景：主键、外键、where、order by、group by、distinct等

## 视图

- 是虚表，不是物理表，是逻辑表，是基于 SQL 语句的结果集
- 表：物理存储，视图：逻辑存储
- 视图的创建和删除：`CREATE VIEW`、`DROP VIEW`
- 具体业务中视图的数量可能比表的数量还多，视图的创建和删除对性能影响不大，但视图的使用会影响性能

```sql
create view v1
as
select * from staff
left join dept
on staff.dept_id = dept.id
order by staff.id;
```

各个部门的人数：

```sql
create view v_dept_count
as
select d.id, d.name, count(s.id) n
from dept d
left join staff s
on s.dept_id = d.id
group by d.id, d.name
order by d.id;
```

- 一个基于一张表的视图，可以通过视图被修改
- 一个基于多张表的视图，不能被修改

## 函数

- 内置函数
  - `ifnull(a, b)`：若 a 为 NULL 则返回 b，否则返回 a
- 自定义函数
  - 需要在 root 用户下设置
  - `set global log_bin_trust_function_creators = ON;`

```sql
create definer = `tom`@`%` function `f1`(a int, b int)
returns integer
BEGIN
    return ifnull(a, 0);
END
```

## 存储过程

- 存储过程：一段可编程的 SQL 语句
- 调用者，通过存储过程，可以实现一些复杂的业务逻辑

```sql
CREATE PROCEDURE `reg` (
    name varchar(16),
    passwd varchar(8)
)
BEGIN
    insert into user(`name`) values (name);
    insert into login values(last_insert_id(), name, sha2(passwd, 256));
    commit;
END
```

调用：

```sql
CALL AAA.new_procedure('tom', '123456');
```

## C API

- 核心数据结构
  - `MYSQL`：数据库连接句柄
  - `MYSQL_RES`：执行 SQL 获得的结果集
  - `MYSQL_ROW`：从结果集获得的一行数据（字符串数组）
  - `MYSQL_FIELD`：列的元数据（列名、大小、类型等）
- 常用函数
  - `mysql_init()`：初始化一个 `MYSQL` 对象
  - `mysql_real_connect()`：连接数据库
  - `mysql_close()`：关闭数据库连接
  - `mysql_query()`：执行 SQL 语句
  - `mysql_store_result()`：将结果集存储到 `MYSQL_RES` 对象中
  - `mysql_fetch_row()`：从结果集中获取一行数据
  - `mysql_num_fields()`：获取结果集中列的数量
  - `mysql_fetch_field()`：获取结果集中某一列的元信息
  - `mysql_free_result()`：释放结果集

#### 初始化与连接

- 编译时需要 -lmysqlclient
- gcc my.c -o my -lmysqlclient

```c
#include <mysql/mysql.h>
#include <stdio.h>
#include <stdlib.h>

#define HOST "127.0.0.1"
#define USER "tom"
#define PASSWD "123456"
#define DB "hr"
#define PORT 3306

int main(void)
{
    // 1.创建结构体,初始化
    MYSQL *conn = mysql_init(NULL);
    if (conn == NULL)
    {
        perror("mysql_init error\n");
        return EXIT_FAILURE;
    }
    printf("初始化成功\n");

    // 2.连接数据库
    if (!mysql_real_connect(conn, HOST, USER, PASSWD, DB, PORT, NULL, 0))
    {
        fprintf(stderr, "连接失败：%d ,%s\n", mysql_errno(conn), mysql_error(conn));
        mysql_close(conn);
        return EXIT_FAILURE;
    }
    printf("连接成功\n");

    return 0;
}
```

#### 获取结果集

```c
    // 4.获取结果集
    MYSQL_RES *res = mysql_store_result(conn);
    if (res == NULL)
    {
        fprintf(stderr, "获取结果集失败：%d ,%s\n", mysql_errno(conn), mysql_error(conn));
        mysql_close(conn);
        return EXIT_FAILURE;
    }
    printf("获取结果集成功\n");
    printf("行数:%ld,列数:%d\n", res->row_count, res->field_count);

    // 5.遍历结果集
    // MYSQL_ROW 本质上是链表的一个节点，存储一行数据

    // 5.1 获取列数
    MYSQL_ROW row;
    // 5.2 获取行数
    int cols = res->field_count;
    // 5.3 当行不为空时，获取行数据
    while ((row = mysql_fetch_row(res)) != NULL)
    {
        for (int i = 0; i < cols; i++)
        {
            printf("%s\t", row[i]);
        }
        printf("\n");
    }
    mysql_free_result(res);
    return 0;
```

- `MYSQL_ROWS`：链表的节点，存储一行数据
- `MYSQL_ROW`：本质是 `char **`（字符串数组），相当于 `int *a[]`，每个 `a[i]` 存储一个字符串地址

> 原理通俗理解：

```c
    int a[10] = {1,2,3};    // MySQL 内部固定的数组
    int *b;
    b = a;                   // 第1次 fetch → b 指向 {1,2,3}
    // 内部把 a 的值改了
    a[0]=4; a[1]=5; a[2]=6;
    b = a;                   // 第2次 fetch → b 还是指向同一个 a，但值变了

```

## 避免SQL注入

- 使用预编译语句
- 优点：
  - 语句在数据库端编译好了，每次调用直接执行
  - 避免SQL注入

```c
    char *sql = "SELECT id,name,city FROM dept WHERE name = ?";
    char *sql="INSERT INTO dept VALUES(NULL,?,?)"
```

- 相关函数
  - `MYSQL_STMT`：预编译语句对象
  - `MYSQL_BIND`：绑定参数对象
  - `mysql_stmt_init()`：初始化预编译语句对象
  - `mysql_stmt_close()`：关闭预编译语句对象
  - `mysql_stmt_prepare()`：准备 SQL 语句
  - `mysql_stmt_bind_param()`：绑定参数
  - `mysql_stmt_execute()`：执行预编译语句
