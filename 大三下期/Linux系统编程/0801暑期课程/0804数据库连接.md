# 数据库 SQL

## DDL（Data Definition Language，数据定义语言）

| 命令       | 作用                         |
| ---------- | ---------------------------- |
| `CREATE`   | 创建数据库或表               |
| `DROP`     | 删除数据库或表               |
| `ALTER`    | 修改表结构                   |
| `TRUNCATE` | 截断表（保留结构，清空数据） |
| `GRANT`    | 授权                         |

### 创建数据库和表

```sql
create database udb;
use udb;
show tables;
```

```sql
create table t1
(
    id int auto_increment primary key,
    c2 char(4),
    c3 decimal(7, 2)
);
```

### 修改表结构

```sql
ALTER TABLE `t1` ADD COLUMN `c4` varchar(16);
ALTER TABLE `t1` ADD COLUMN `c5` varchar(16) DEFAULT 'ok';
ALTER TABLE `t1` CHANGE COLUMN `c2` `title` varchar(4);
ALTER TABLE `t1` DROP COLUMN `c3`;
```

### 插入数据

```sql
INSERT INTO `t1` (`title`) VALUES ('abcd');
INSERT INTO `t1` (`title`) VALUES ('xyz');
INSERT INTO `t1` (`title`) VALUES ('中文');
```

### 删除操作对比

| 命令          | 删除数据 | 删除表结构 | 重置自增列 | 释放空间 |
| ------------- | -------- | ---------- | ---------- | -------- |
| `TRUNCATE`    | 是       | 否         | 是         | 是       |
| `DROP TABLE`  | 是       | 是         | —          | —        |
| `DELETE FROM` | 是       | 否         | 否         | 否       |

```sql
TRUNCATE TABLE `t1`;
DROP TABLE `t1`;
DELETE FROM `t1`;
```

### 远程连接用户管理

```sql
CREATE USER 'abc'@'%' IDENTIFIED BY '123456';
GRANT ALL ON udb.* TO 'abc'@'%';
SELECT * FROM mysql.user\G;
```

连接方式：

```bash
mysql -u abc -p
```

### 修改 MySQL 允许远程连接

- `cd /etc/mysql/mysql.conf.d/`：进入 MySQL 配置目录
- `sudo vim mysqld.cnf`：编辑配置文件
- 将 `bind-address = 127.0.0.1` 改为 `bind-address = 0.0.0.0`
- `sudo service mysql restart`：重启 MySQL 服务
