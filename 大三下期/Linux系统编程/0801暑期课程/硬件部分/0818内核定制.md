# 0818 内核定制

## 内核定制

- 官网下载内核
  - <www.kernel.org>
- 目录结构
  - arch：根据CPU架构，如arm64，x86_64等不同而区分的代码
  - crypto：加密算法，压缩算法等
  - documentation：内核文档
  - drivers：设备驱动程序源代码，自己定制的设备驱动可以放到该目录的特定分类中
  - fs：和文件系统相关的代码
  - include：内核头文件。自己实现驱动时，需要使用该目录下的头文件（不能使用C库）
  - kernel：内核核心代码，完成操作系统的核心功能的代码
  - lib：库文件相关代码？
  - mm：内存管理相关代码，和硬件体系结构无关的部分（相关的代码在arch/arm64/mm/）
  - net：网络相关代码，网络协议栈
  - scripts：内核编译脚本
  - usr：用户相关的文件，例如gen_init_cpio.c是cpio命令的实现

- Linux内核配置编译
  为了简化内核源代码的编译，一般采用以下机制
  Makefile：根据配置的情况，构造出需要编译的源文件列表，然后分别编译，并将目标代码链接到一起，最终形成linux内核的二进制文件。因为内核源代码按照功能组织的树形结构，所以Makefile文件也是分布在各个目录中，每个目录中都有一个Makefile文件
  Kconfig：为用户提供配置内核编译选项的界面。在make menuconfig中，可以通过菜单选择编译选项，然后保存到.config文件中
  .config：内核配置文件，用于保存内核编译选项

- 内核配置
  - y、m、n键
  - make clean
  - make menuconfig
  - make config
    make -j4 # 编译内核镜像
    make modules_install # 安装模块（需要 sudo）
    make install # 安装内核

- 编译流程
  - 解压内核源码
  - 进入内核源码目录
  - 执行make menuconfig
  - 根据需要配置内核编译选项
  - 保存配置文件.config
  - 执行make -j4

  - make clean 清理编译产物
  - make

## 驱动程序基本介绍

- 驱动程序
  - 驱动程序是一个存在于应用程序和实际设备间的中间层，用于处理应用程序和设备之间的通信
- 主要功能
  - 对设备进行初始化和释放
  - 把数据从内核传送到硬件和从硬件传送到内核
  - 读取应用程序传送给设备文件的数据和回送应用请求的数据
  - 检测和处理设备出现的错误
- 驱动程序的分类
  - 字符设备驱动程序
  - 块设备驱动程序
  - 网络设备驱动程序
  - 其他

- 设备文件的属性组成
  - 第一部分：设备类型，例如c/b
  - 第二部分：主设备号
  - 第三部分：次设备号

- sys文件系统是Linux内核中设计较新的文件系统，它是Linux内核中最新的文件系统，用于存储系统的核心数据和配置信息，如内核映像、设备驱动程序、系统配置文件等。

编写驱动程序

- 编译生成.ko模块
  在使用的时候需要使用insmod命令加载模块
  卸载使用rmmod命令卸载模块
- lsmod 查看模块

- 使用insmod时候，会调用代码中的init_module函数指定的函数，函数里的printf会打印到dmesg日志中
  - 通过dmesg查看日志
