# STM32 中断与定时器

## 一、回顾：轮询方式及其缺点

通过连接在PB6上的按键，控制PC端口的LED流水灯的启动和停止。轮询方式的核心代码结构如下：

```c
while(1)
{
    // 按键1
    if(ReadDataBits(GPIOB, Pin_6) == 0)
    {
        Delay(20);  // 消抖
        if(ReadDataBits(GPIOB, Pin_6) == 0)
        {
            // 处理
        }
    }
    // 按键2、按键3 ... 同理
}
```

轮询就是依次一个一个地判定每个输入状态。它有三个缺点：

1. 在处理一种状态的过程中，如果其他状态发生改变，是不能响应的
2. 必须是程序运行到该状态监测的时候，正好状态满足条件才会响应，否则一直等待
3. 不能根据事件的轻重缓急来确定事件的响应顺序

## 二、中断的概念

中断是指中止（暂停）当前正在执行的任务，转去处理别的事务的过程。中断处理完成后，程序会自动回到原来的执行流程继续执行。

中断与函数调用的区别：函数调用通过LR寄存器返回，是程序主动发起的；中断是硬件触发的，由CPU自动响应。

## 三、中断响应流程

中断响应分为三个阶段：

### 1. 中断源触发中断

外部或内部的中断源发出中断请求信号。

### 2. CPU响应中断

**保护现场**：硬件自动将当前程序的关键寄存器压栈，包括程序计数器（PC）、程序状态寄存器（XPSR）、链接寄存器（LR）和R0～R3、R12等寄存器。这些信息保证了中断处理完成后能恢复原来的执行状态。

**中断响应**：将中断处理函数的入口地址赋值给PC，对于向量中断，根据中断号直接计算中断向量表中中断服务程序的入口地址，然后跳转执行中断服务程序（ISR）。

在Dbus（数据总线）保存处理器状态的同时，处理器通过Ibus（指令总线）从一个可重新定位的向量表中识别出异常向量，并获取ISR函数的地址。也就是说，保护现场与取异常向量是并行处理的。一旦压栈和取指令完成，中断服务程序就开始执行。

### 3. 恢复现场

执行完ISR后，硬件自动进行出栈操作，将之前压栈的寄存器值恢复，中断前的程序恢复正常执行。

## 四、STM32中断系统概览

Cortex-M3内核支持256个中断，其中包含16个内核中断和240个外部中断，具有256级可编程中断设置。

但STM32并没有使用CM3内核的全部能力，而是只用了它的一部分：

- STM32共有84个中断，包括16个内核中断和68个可屏蔽中断，具有16级可编程的中断优先级
- 在STM32F103系列上，只有60个可屏蔽中断（107系列才有68个）

我们常用的就是这60个可屏蔽中断。

### 外部中断/事件请求

STM32的每个IO都可以作为外部中断的中断输入口。STM32F103的中断控制器支持19个外部中断/事件请求，每个中断设有状态位，每个中断/事件都有独立的触发和屏蔽设置：

- 线0～15：对应外部IO口的输入中断
- 线16：连接到PVD输出
- 线17：连接到RTC闹钟事件
- 线18：连接到USB唤醒事件

### 中断线与GPIO的映射关系

GPIO的管脚GPIOx.0～GPIOx.15（x=A,B,C,D,E,F,G）分别对应中断线15～0。每个中断线最多对应7个IO口。以线0为例，它对应GPIOA.0、GPIOB.0、GPIOC.0、GPIOD.0、GPIOE.0、GPIOF.0、GPIOG.0。

中断线每次只能连接到1个IO口上，需要通过配置外部中断配置寄存器EXTICR来决定中断线对应哪个GPIO端口。

### 中断响应函数的分组

- EXTI0～EXTI4：这5个外部中断各有自己单独的中断响应函数
- EXTI5～9：共用一个中断响应函数（EXTI9_5_IRQHandler）
- EXTI10～15：共用一个中断响应函数（EXTI15_10_IRQHandler）

中断服务函数的名称在启动文件的中断向量表中定义，实现一般在stm32f10x_it.c中，也可以在其他地方实现（但需要把it.c中的同名函数注释掉）。中断服务程序没有返回值，处理流程一般都尽量简单。

## 五、NVIC嵌套向量中断控制器

NVIC是Cortex-M3内核中管理中断的核心模块。在MDK中，NVIC相关的寄存器被定义为如下结构体：

```c
typedef struct
{
    vu32 ISER[2];        // 中断使能寄存器
    u32  RESERVED0[30];
    vu32 ICER[2];        // 中断除能寄存器
    u32  RESERVED1[30];
    vu32 ISPR[2];        // 中断挂起控制寄存器
    u32  RESERVED2[30];
    vu32 ICPR[2];        // 中断解挂控制寄存器
    u32  RESERVED3[30];
    vu32 IABR[2];        // 中断活动状态寄存器
    u32  RESERVED4[62];
    vu32 IPR[15];        // 中断优先级控制寄存器
} NVIC_TypeDef;
```

### 各寄存器的作用

**ISER（Interrupt Set-Enable Registers）**——中断使能寄存器组。STM32F103的可屏蔽中断有60个，用2个32位寄存器共64位来表示。ISER[0]的bit0～bit31对应中断0～31，ISER[1]的bit0～27对应中断32～59。要使能某个中断，必须将相应位置1。注意这里仅仅是使能，还需要配合中断分组、屏蔽、IO口映射等设置才算完整的配置。

**ICER（Interrupt Clear-Enable Registers）**——中断除能寄存器组，与ISER作用恰好相反，用来清除某个中断的使能。

**ISPR（Interrupt Set-Pending Registers）**——中断挂起控制寄存器组。通过置1可以将正在执行的中断挂起，转去执行同级或更高级别的中断。写0无效。

**ICPR（Interrupt Clear-Pending Registers）**——中断解挂控制寄存器组，用来解除中断的挂起状态。

**IPR（Interrupt Priority Registers）**——中断优先级控制寄存器组。由15个32位寄存器组成，每个可屏蔽中断占用8位，总共可表示15×4=60个可屏蔽中断。这个寄存器组与STM32的中断分组密切相关。

## 六、中断优先级与分组

### 优先级的概念

STM32的中断优先级分为两种：

- **抢占优先级（Preemption Priority）**：高抢占优先级的中断可以打断正在执行的低抢占优先级中断，实现中断嵌套
- **响应优先级（Sub Priority）**：当两个中断的抢占优先级相同时，响应优先级高的不能打断响应优先级低的中断，但可以决定谁先执行

数值越小，代表的优先级越高。

### 中断分组

STM32将中断分为5个组（组0～4），由SCB->AIRCR寄存器的bit10～8来定义：

- 组0：抢占优先级0位，响应优先级4位
- 组1：抢占优先级1位，响应优先级3位
- 组2：抢占优先级2位，响应优先级2位
- 组3：抢占优先级3位，响应优先级1位
- 组4：抢占优先级4位，响应优先级0位

### 优先级判定规则

1. 如果两个中断的抢占优先级和响应优先级都相同，则看哪个中断先发生就先执行
2. 高抢占优先级可以打断正在进行的低抢占优先级中断
3. 抢占优先级相同的中断之间，高响应优先级不能打断低响应优先级的中断

## 七、外部中断配置流程

### 第1步：初始化IO口为输入

设置要作为外部中断输入的IO口，可以配置为上拉输入、下拉输入或浮空输入。浮空输入时外部一定要带上拉或下拉电阻，否则可能导致中断不停触发。在干扰较大的地方，建议使用外部上拉/下拉电阻以防止干扰。

### 第2步：开启IO口复用时钟，设置IO口与中断线的映射关系

STM32的IO口与中断线的对应关系需要配置外部中断配置寄存器EXTICR，因此要先开启复用时钟，然后配置映射关系：

```c
RCC->APB2ENR |= 0x01;  // 使能IO复用时钟，APB2ENR的bit0置位
```

### 第3步：开启线上中断/事件，设置触发条件

配置中断产生的条件。STM32可以配置成上升沿触发、下降沿触发或任意电平变化触发，但不能配置成高电平或低平触发。

注意：如果使用外部中断并设置了EMR位，会引起软件仿真无法跳到中断，但硬件上是可以的。建议不要配置EMR位。

### 第4步：配置中断分组（NVIC），并使能中断

配置中断的分组和使能。只有配置了NVIC设置并开启，中断才能被执行，否则不会进入中断服务函数。

### 第5步：编写中断处理函数

中断处理函数是中断发生以后的处理逻辑，由CPU自动响应调用。

## 八、固件库函数

### NVIC相关函数

**NVIC_PriorityGroupConfig**——设置优先级分组：

```c
void NVIC_PriorityGroupConfig(uint32_t NVIC_PriorityGroup);
```

参数取值：NVIC_PriorityGroup_0/1/2/3/4

**NVIC_Init**——根据参数初始化NVIC寄存器：

```c
void NVIC_Init(NVIC_InitTypeDef* NVIC_InitStruct);
```

NVIC_InitTypeDef结构体定义：

```c
typedef struct
{
    uint8_t  NVIC_IRQChannel;                   // 中断通道（中断源），定义在IRQn_Type中
    uint8_t  NVIC_IRQChannelPreemptionPriority;  // 抢占优先级
    uint8_t  NVIC_IRQChannelSubPriority;         // 响应优先级
    FunctionalState NVIC_IRQChannelCmd;          // 中断使能或失能
} NVIC_InitTypeDef;
```

NVIC_IRQChannel常用值：EXTI0_IRQn / EXTI1_IRQn / EXTI2_IRQn / EXTI3_IRQn / EXTI4_IRQn / EXTI9_5_IRQn / EXTI15_10_IRQn

### EXTI相关函数

**EXTI_Init**——初始化外部中断线：

```c
void EXTI_Init(EXTI_InitTypeDef* EXTI_InitStruct);
```

EXTI_InitTypeDef结构体定义：

```c
typedef struct
{
    uint32_t             EXTI_Line;     // 中断线，如 EXTI_Line6
    EXTIMode_TypeDef     EXTI_Mode;     // 模式：EXTI_Mode_Interrupt（中断模式）
    EXTITrigger_TypeDef  EXTI_Trigger;  // 触发方式
    FunctionalState      EXTI_LineCmd;  // 使能或失能
} EXTI_InitTypeDef;
```

EXTI_Trigger取值：EXTI_Trigger_Falling（下降沿）/ EXTI_Trigger_Rising（上升沿）/ EXTI_Trigger_Rising_Falling（任意电平变化）

配置示例：

```c
EXTI_InitTypeDef EXTI_InitStructure;
EXTI_InitStructure.EXTI_Line    = EXTI_Line12 | EXTI_Line14;
EXTI_InitStructure.EXTI_Mode    = EXTI_Mode_Interrupt;
EXTI_InitStructure.EXTI_Trigger = EXTI_Trigger_Falling;
EXTI_InitStructure.EXTI_LineCmd = ENABLE;
EXTI_Init(&EXTI_InitStructure);
```

**GPIO_EXTILineConfig**——选择GPIO管脚用作外部中断线路：

```c
void GPIO_EXTILineConfig(uint8_t GPIO_PortSource, uint8_t GPIO_PinSource);
```

GPIO_PortSource选择端口（如GPIO_PortSourceGPIOB），GPIO_PinSource选择引脚（如GPIO_PinSource6，取值0～15）。

**EXTI_GetITStatus**——检查指定的EXTI线路是否触发了中断请求：

```c
ITStatus EXTI_GetITStatus(uint32_t EXTI_Line);
```

**EXTI_ClearITPendingBit**——清除EXTI线路的挂起位：

```c
void EXTI_ClearITPendingBit(u32 EXTI_Line);
```

中断处理完成后，一定要清除该中断的挂起位，否则会反复触发。

## 九、完整代码示例

功能：通过PB6按键的外部中断，翻转PC13 LED的状态。

### GPIO与中断配置

```c
#include "stm32f10x.h"
#include "Delay.h"

void Key_Configure(void)
{
    GPIO_InitTypeDef GPIO_Initstructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);
    GPIO_Initstructure.GPIO_Pin   = GPIO_Pin_6;
    GPIO_Initstructure.GPIO_Mode  = GPIO_Mode_IPU;   // 上拉输入
    GPIO_Initstructure.GPIO_Speed = GPIO_Speed_10MHz;

    GPIO_Init(GPIOB, &GPIO_Initstructure);
}

void NVIC_Configure(void)
{
    NVIC_InitTypeDef NVIC_Initstructure;

    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_1);   // 设置分组为组1
    NVIC_Initstructure.NVIC_IRQChannel                   = EXTI9_5_IRQn;  // PB6对应EXTI线6，属于EXTI9_5组
    NVIC_Initstructure.NVIC_IRQChannelPreemptionPriority = 0;  // 抢占优先级0
    NVIC_Initstructure.NVIC_IRQChannelSubPriority         = 0;  // 响应优先级0
    NVIC_Initstructure.NVIC_IRQChannelCmd                 = ENABLE;

    NVIC_Init(&NVIC_Initstructure);
}

void EXTI_PB6_Configure(void)
{
    GPIO_InitTypeDef   GPIO_Initstructure;
    EXTI_InitTypeDef   EXTI_InitStructure;

    // 开启GPIOB和AFIO复用时钟
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB | RCC_APB2Periph_AFIO, ENABLE);

    // NVIC配置
    NVIC_Configure();

    // GPIO配置：PB6上拉输入
    GPIO_Initstructure.GPIO_Pin  = GPIO_Pin_6;
    GPIO_Initstructure.GPIO_Mode = GPIO_Mode_IPU;
    GPIO_Init(GPIOB, &GPIO_Initstructure);

    // EXTI配置：将PB6映射到EXTI线6，下降沿触发
    GPIO_EXTILineConfig(GPIO_PortSourceGPIOB, GPIO_PinSource6);
    EXTI_InitStructure.EXTI_Line    = EXTI_Line6;
    EXTI_InitStructure.EXTI_Mode    = EXTI_Mode_Interrupt;
    EXTI_InitStructure.EXTI_Trigger = EXTI_Trigger_Falling;
    EXTI_InitStructure.EXTI_LineCmd = ENABLE;
    EXTI_Init(&EXTI_InitStructure);
}
```

## 十、中断配置总结

STM32中断的配置和使用共四步：

1. **配置GPIO引脚**——开启端口时钟和复用时钟，将引脚配置为输入（上拉输入）
2. **配置NVIC**——配置中断优先级分组，配置中断通道，配置抢占优先级和响应优先级，使能通道中断
3. **配置EXTI**——将中断线和某个引脚关联，设置中断模式、触发方式，使能中断
4. **实现中断处理函数**——函数名在启动文件中定义（startup_stm32f10x_xx.s的中断向量表），实现一般在stm32f10x_it.c中，也可以在别处定义（需要把it.c中的同名实现注释掉）

## 十一、定时器系统

### 软件延时的问题

我们常用的软件延时函数如下：

```c
void mydelay(int n)
{
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < 100000; j++)
        {
            ;
        }
    }
}
```

这种方式的缺点是不精确，受编译器优化和主频影响。因此需要硬件定时器来实现精确的延时和定时。

### STM32的定时器分类

- **高级定时器**：TIM1和TIM8——能够产生三对PWM互补输出，常用于三相电机驱动，时钟由APB2输出产生
- **基本定时器**：TIM6和TIM7——主要用于产生DAC触发信号
- **通用定时器**：TIM2～TIM5——每个定时器有4个独立通道，可作输入捕获/输出比较/PWM/脉冲计数
- **系统时基定时器**：SysTick——常用于产生us级/ms级延时
- **看门狗定时器**：用于系统复位保护

定时器的时钟不是直接来自APB1或APB2，而是来自输入为APB1或APB2的一个倍频器。

## 十二、SysTick定时器

### SysTick简介

SysTick是一个24位的向下计数定时器，即一次最多可以计数2^24个时钟脉冲。

**时钟来源**：STM32中SysTick以HCLK（AHB时钟）或HCLK/8作为运行时钟。

**工作原理**：计数值保存在当前计数值寄存器STK_VAL中，每接收到一个时钟脉冲，STK_VAL向下减1，直至0。当STK_VAL减至0时，硬件自动把重载寄存器STK_LOAD中保存的数据加载到STK_VAL（自动重装），同时可以触发中断。

### SysTick控制寄存器STK_CRL

SysTick的配置只有三个控制位和一个标志位，都位于寄存器STK_CRL中：

- **ENABLE**：使能位。为1时开始计数，为0时关闭
- **TICKINT**：中断触发使能位。为1且STK_VAL倒计至0时触发中断，为0时不触发
- **CLKSOURCE**：时钟选择位。为1时时钟为AHB（HCLK），为0时为AHB/8
- **COUNTFLAG**：标志位。当STK_VAL倒计至0时被置1

### 定时器频率计算

定时器计数频率：CK_CNT = CK_INT / (TIMx_PSC + 1)

- CK_INT：内部时钟源频率（APB1或APB2倍频器送出的时钟）
- TIMx_PSC：用户设定的预分频系数，取值范围0～65535

例如：RCC中AHB=72MHz、APB1=36MHz、APB2=72MHz，则CK_INT=72MHz。

1个时钟周期：T = 1 / CK_CNT

系统嘀嗒校准值固定为9000，当SysTick时钟设定为9MHz（HCLK/8的最大值）时，产生1ms时间基准。

### SysTick配置函数

```c
SysTick_Config(系统时钟频率 / 1000);
// 例如72MHz系统：SysTick_Config(72000)
```

参数是1个时钟周期的次数，即重装定时器的值。1秒对应72000000次。

### 使用SysTick实现微秒级延时

```c
void Delay_us(uint32_t xus)
{
    SysTick->LOAD  = 72 * xus;         // 设置定时器重装值（72MHz下，1us = 72个时钟周期）
    SysTick->VAL   = 0x00;             // 清空当前计数值
    SysTick->CTRL  = 0x00000005;       // 时钟源为HCLK，启动定时器（bit0=1使能，bit2=1选HCLK）
    while (!(SysTick->CTRL & 0x00010000)); // 等待COUNTFLAG置1（计数到0）
    SysTick->CTRL  = 0x00000004;       // 关闭定时器（bit0=0关闭）
}
```

工作流程：
1. 设置重装值：72 × xus，即xus微秒对应的时钟周期数
2. 清空当前计数值，确保从重装值开始倒计数
3. 启动定时器，选择HCLK作为时钟源
