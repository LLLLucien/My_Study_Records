# STM32 V3.5 固件库学习笔记

## 一、固件库概述

- **版本**：V3.5
- **使用方式**：源码方式（直接把固件库源码加入工程一起编译）
- **作用**：把对寄存器的操作封装成结构体和函数，开发时直接调用 API，不用手动去记每个寄存器的地址和位定义，简化开发、提高代码可读性和可移植性

## 二、固件库的文件组成

固件库由以下几类文件组成，各司其职：

1. **stm32f10x.h**：核心头文件
   - 定义所有外设寄存器的地址，以及寄存器的结构体封装（如 GPIO_TypeDef、USART_TypeDef）
   - 定义外设的内存映射（各外设的基地址）
   - 定义常用的位操作宏（SET_BIT、CLEAR_BIT 等）
   - 注意：中断向量表不在这个文件里，而是在启动文件（startup 的 .s 文件）中定义，按芯片型号选择

2. **system_stm32f10x.h / .c**：设备外设访问层
   - 主要用来设置系统时钟频率（SystemInit() 函数）

3. **startup/\*.s**：启动代码
   - 定义中断向量表、复位处理、系统初始化入口
   - 根据芯片型号选择合适的启动文件（如 STM32F103C8T6 选中等容量 md 对应的启动文件）

4. **Libraries/STM32F10x_StdPeriph_Driver**：标准外设驱动库
   - 包含所有外设的驱动源码，例如 stm32f10x_gpio.c/.h、stm32f10x_usart.c/.h、stm32f10x_rcc.c/.h 等

## 三、固件库核心机制：寄存器结构体封装

### 3.1 为什么要用结构体封装寄存器

外设的各个寄存器在内存地址上是**连续排列**的，所以可以把一组连续地址的寄存器直接定义成一个结构体。结构体成员按顺序排列，编译器会把每个成员映射到对应的寄存器地址上，于是操作寄存器就变成了操作结构体成员，代码更直观。

### 3.2 GPIO 寄存器结构体 GPIO_TypeDef

```c
typedef struct
{
  __IO uint32_t CRL;    // 端口配置低寄存器，控制 Pin0 ~ Pin7
  __IO uint32_t CRH;    // 端口配置高寄存器，控制 Pin8 ~ Pin15
  __IO uint32_t IDR;    // 输入数据寄存器（只读）
  __IO uint32_t ODR;    // 输出数据寄存器
  __IO uint32_t BSRR;   // 置位/复位寄存器（写 1 置位或复位，原子操作）
  __IO uint32_t BRR;    // 复位寄存器（写 1 清零）
  __IO uint32_t LCKR;   // 配置锁定寄存器
} GPIO_TypeDef;
```

说明：

- `__IO` 表示 volatile（易失性），防止编译器优化掉对寄存器的读写
- 使用固件库操作 GPIO 时，寄存器就对应到结构体变量中的成员，例如 `GPIOA->ODR`

### 3.3 外设内存映射（基地址定义）

```c
#define PERIPH_BB_BASE        ((uint32_t)0x42000000)
#define APB1PERIPH_BASE       PERIPH_BASE
#define APB2PERIPH_BASE       (PERIPH_BASE + 0x10000)

#define AFIO_BASE             (APB2PERIPH_BASE + 0x0000)
#define EXTI_BASE             (APB2PERIPH_BASE + 0x0400)
#define GPIOA_BASE            (APB2PERIPH_BASE + 0x0800)
#define GPIOB_BASE            (APB2PERIPH_BASE + 0x0C00)
#define GPIOC_BASE            (APB2PERIPH_BASE + 0x1000)
#define GPIOD_BASE            (APB2PERIPH_BASE + 0x1400)
#define GPIOE_BASE            (APB2PERIPH_BASE + 0x1800)
#define GPIOF_BASE            (APB2PERIPH_BASE + 0x1C00)
#define GPIOG_BASE            (APB2PERIPH_BASE + 0x2000)
```

说明：GPIOA 到 GPIOB 基地址相差 0x400，即每个 GPIO 外设占 1KB 地址空间；GPIO、USART1、AFIO、EXTI 等外设挂在 APB2 总线上。

### 3.4 GPIO 配置寄存器位定义（GPIO_CRL 为例）

```c
#define GPIO_CRL_MODE     ((uint32_t)0x33333333)  // Pin0~7 的速度位
#define GPIO_CRL_MODE0    ((uint32_t)0x00000003)  // MODE0[1:0]：Pin0 的速度位
#define GPIO_CRL_MODE0_0  ((uint32_t)0x00000001)  // 位 0
#define GPIO_CRL_MODE0_1  ((uint32_t)0x00000002)  // 位 1
```

说明：CRL 中每个引脚占 4 位，其中 MODE[1:0] 配置速度（输出模式下），CNF[1:0] 配置模式（输入/输出/复用等）。

### 3.5 常用位操作宏

```c
#define SET_BIT(REG, BIT)     ((REG) |= (BIT))                    // 置位
#define CLEAR_BIT(REG, BIT)   ((REG) &= ~(BIT))                   // 清位
#define READ_BIT(REG, BIT)    ((REG) & (BIT))                     // 读位
#define CLEAR_REG(REG)        ((REG) = (0x0))                     // 寄存器清零
#define WRITE_REG(REG, VAL)   ((REG) = (VAL))                     // 写寄存器
#define READ_REG(REG)         ((REG))                             // 读寄存器
#define MODIFY_REG(REG, CLEARMASK, SETMASK) \
  WRITE_REG((REG), (((READ_REG(REG)) & (~(CLEARMASK))) | (SETMASK)))  // 先清后置
```

## 四、GPIO 外设驱动（stm32f10x_gpio.h）

### 4.1 速度枚举

```c
typedef enum
{
  GPIO_Speed_10MHz = 1,
  GPIO_Speed_2MHz,
  GPIO_Speed_50MHz
} GPIOSpeed_TypeDef;
```

### 4.2 模式枚举

```c
typedef enum
{
  GPIO_Mode_AIN         = 0x0,   // 模拟输入
  GPIO_Mode_IN_FLOATING = 0x04,  // 浮空输入
  GPIO_Mode_IPD         = 0x28,  // 下拉输入
  GPIO_Mode_IPU         = 0x48,  // 上拉输入
  GPIO_Mode_Out_OD      = 0x14,  // 开漏输出
  GPIO_Mode_Out_PP      = 0x10,  // 推挽输出
  GPIO_Mode_AF_OD       = 0x1C,  // 复用开漏输出
  GPIO_Mode_AF_PP       = 0x18   // 复用推挽输出
} GPIOMode_TypeDef;
```

说明：这些枚举值实际上直接对应 CRL/CRH 寄存器中 CNF[1:0] 和 MODE[1:0] 的配置值，固件库把"配置什么模式"封装成了枚举。

### 4.3 初始化结构体 GPIO_InitTypeDef

```c
typedef struct
{
  uint16_t GPIO_Pin;             // 要配置的引脚，如 GPIO_Pin_0
  GPIOSpeed_TypeDef GPIO_Speed;  // 速度
  GPIOMode_TypeDef GPIO_Mode;    // 模式
} GPIO_InitTypeDef;
```

## 五、GPIO 常用 API 接口

1. **GPIO_DeInit**：将外设 GPIOx 寄存器重设为缺省值

   ```c
   void GPIO_DeInit(GPIO_TypeDef* GPIOx);
   GPIO_DeInit(GPIOA);
   ```

2. **GPIO_Init**：根据 GPIO_InitStruct 中指定的参数初始化外设 GPIOx 寄存器

   ```c
   void GPIO_Init(GPIO_TypeDef* GPIOx, GPIO_InitTypeDef* GPIO_InitStruct);
   ```

   参数可选值：
   - GPIO_Pin_0 ~ GPIO_Pin_15、GPIO_Pin_All
   - GPIO_Speed_10MHz、GPIO_Speed_2MHz、GPIO_Speed_50MHz
   - GPIO_Mode_AIN、GPIO_Mode_Out_PP、GPIO_Mode_IPD、GPIO_Mode_IPU 等

3. **GPIO_ReadInputDataBit**：读取指定端口管脚的输入

   ```c
   u8 GPIO_ReadInputDataBit(GPIO_TypeDef* GPIOx, u16 GPIO_Pin);
   ```

4. **GPIO_ReadInputData**：读取指定 GPIO 端口的全部输入

   ```c
   u16 GPIO_ReadInputData(GPIO_TypeDef* GPIOx);
   ```

5. **GPIO_WriteBit**：设置或清除指定的数据端口位

   ```c
   void GPIO_WriteBit(GPIO_TypeDef* GPIOx, u16 GPIO_Pin, BitAction BitVal);
   ```

   BitVal 取枚举 BitAction 的值：Bit_RESET（清除）、Bit_SET（置位）

6. **GPIO_Write**：向指定 GPIO 数据端口写入数据

   ```c
   void GPIO_Write(GPIO_TypeDef* GPIOx, u16 PortVal);
   ```

7. **GPIO_SetBits**：设置（置 1）指定的数据端口位

   ```c
   void GPIO_SetBits(GPIO_TypeDef* GPIOx, u16 GPIO_Pin);
   ```

   参数可取 GPIO_Pin_x（x 为 0~15）的任意组合

8. **GPIO_ResetBits**：清除（置 0）指定的数据端口位

   ```c
   void GPIO_ResetBits(GPIO_TypeDef* GPIOx, u16 GPIO_Pin);
   ```

## 六、GPIO 初始化流程

标准三步流程：开时钟 → 填结构体 → 调用 GPIO_Init

```c
// 1. 使能 GPIO 时钟（GPIO 挂在 APB2 总线上）
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);

// 2. 定义并填充初始化结构体
GPIO_InitTypeDef GPIO_InitStructure;
GPIO_InitStructure.GPIO_Pin   = GPIO_Pin_All;
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_10MHz;
GPIO_InitStructure.GPIO_Mode  = GPIO_Mode_IN_FLOATING;   // 例：浮空输入

// 3. 调用初始化函数
GPIO_Init(GPIOA, &GPIO_InitStructure);
```

## 七、实例：GPIO 控制 LED 流水灯

```c
#include "stm32f10x.h"                  // Device header
#include "Delay.h"

int main(void)
{
    // 使能 GPIOC 时钟
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC, ENABLE);

    GPIO_InitTypeDef GPIO_InitStructure;
    // 配置 PC0 ~ PC8 共 9 个引脚为推挽输出，50MHz
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0 | GPIO_Pin_1 | GPIO_Pin_2 | GPIO_Pin_3 |
                                  GPIO_Pin_4 | GPIO_Pin_5 | GPIO_Pin_6 | GPIO_Pin_7 | GPIO_Pin_8;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_InitStructure.GPIO_Mode  = GPIO_Mode_Out_PP;

    GPIO_Init(GPIOC, &GPIO_InitStructure);

    GPIOC->BSRR = 0xff;          // 用寄存器方式直接置位低 8 位（点亮）
    GPIO_Write(GPIOC, 0xff);     // 用库函数方式写端口

    while (1)
    {
        GPIO_ResetBits(GPIOC, GPIO_Pin_0 | GPIO_Pin_1);   // 灭 PC0、PC1
        Delay_ms(2500);
        GPIO_SetBits(GPIOC, GPIO_Pin_0 | GPIO_Pin_1);     // 亮 PC0、PC1
        GPIO_ResetBits(GPIOC, GPIO_Pin_2 | GPIO_Pin_3);
        Delay_ms(2500);
        GPIO_SetBits(GPIOC, GPIO_Pin_2 | GPIO_Pin_3);
        GPIO_ResetBits(GPIOC, GPIO_Pin_4 | GPIO_Pin_5);
        Delay_ms(2500);
        GPIO_SetBits(GPIOC, GPIO_Pin_4 | GPIO_Pin_5);
        GPIO_ResetBits(GPIOC, GPIO_Pin_6 | GPIO_Pin_7);
        Delay_ms(2500);
        GPIO_Write(GPIOC, 0xff);   // 全部点亮
    }
}
```

## 八、USART 串行通信

### 8.1 通信方式分类

计算机中 CPU 与外部设备之间的通信方式分为两种：

- **并行通信**：一次同时传输多位数据，速度快，但占用引脚多、成本高，适合短距离传输
- **串行通信**：数据一位一位地顺序传输，占用引脚少、成本低，适合长距离传输

### 8.2 同步通信与异步通信

串行通信按照数据的时钟控制方式分为同步和异步，判断标准是：**接收方和发送方是否使用相同的时钟系统进行控制（数据的发送频率是否一致）**。

- **同步通信**：通信双方先建立同步，以数据帧为单位传输；数据帧中包含数据源、目的、传输长度等信息，一个数据帧可以包含多个字节的有效数据，效率高
- **异步通信**：发送方可以在任意时刻发送，以字符为单位传输，相邻两个字符之间的间隔时间可以任意长；每传输一个字符需要额外增加起始位、停止位等信息（约 20% 以上的额外开销），效率较低但实现简单

### 8.3 异步通信的帧格式

传输一个字符的基本格式：**起始位 → 数据位 → 校验位 → 停止位**

- **起始位**：空闲时线路为高电平，起始位为低电平（用下降沿告诉接收方"开始接收"）
- **数据位**：紧跟在起始位之后，有效数据长度可以是 5/6/7/8 位（可编程）
- **奇偶校验位**：0 或 1 位（可选项）
- **停止位**：高电平，可以是 1/1.5/2 位（表示一帧结束）

### 8.4 波特率

- 定义：每秒传输的位数，单位 BAUD（bits/s）
- 典型值：4800 / 9600 / 115200

### 8.5 STM32F103 的 USART 特点

- USART 采用 **NRZ 异步串行数据格式**（不归零编码），支持**全双工**数据交换（可同时收发）
- STM32F103C8T6 有 **2 个串行口**，每个串口使用两个引脚收发数据：
  - RXD：输入，用于串行数据的接收
  - TXD：输出，用于串行数据的发送
- 串口 1（USART1）：PA10 作为 RX，PA9 作为 TX；还有 SCLK（发送器的时钟输出，用于同步模式）
- 发送和接收共用的可编程波特率，最高可达 4.5Mbits/s

### 8.6 USART 寄存器配置步骤（寄存器级）

1. 在 USART_CR1 寄存器上置位 UE 位来激活 USART
2. 编程 USART_CR1 的 M 位来定义字长
3. 在 USART_CR2 中编程停止位的位数
4. 如果采用多缓冲器通信，配置 USART_CR3 中的 DMA 使能位（DMAT），并按多缓冲器通信的描述配置 DMA 寄存器
5. 利用 USART_BRR 寄存器选择要求的波特率
6. 设置 USART_CR1 中的 TE 位，发送一个空闲帧作为第一次数据发送
7. 把要发送的数据写进 USART_DR 寄存器（此动作清除 TXE 位）；在只有一个缓冲器的情况下，对每个待发送的数据重复步骤 7
8. 在 USART_DR 寄存器中写入最后一个数据字后，要等待 TC=1，它表示最后一个数据帧的传输结束；当需要关闭 USART 或需要进入停机模式之前，需要确认传输结束，避免破坏最后一次传输

### 8.7 USART 固件库结构体

寄存器结构体 USART_TypeDef（与 GPIO_TypeDef 同理，成员按地址顺序对应寄存器）：

```c
typedef struct
{
  __IO uint16_t SR;        // 状态寄存器
  uint16_t  RESERVED0;
  __IO uint16_t DR;        // 数据寄存器
  uint16_t  RESERVED1;
  __IO uint16_t BRR;       // 波特率寄存器
  uint16_t  RESERVED2;
  __IO uint16_t CR1;       // 控制寄存器 1
  uint16_t  RESERVED3;
  __IO uint16_t CR2;       // 控制寄存器 2
  uint16_t  RESERVED4;
  __IO uint16_t CR3;       // 控制寄存器 3
  uint16_t  RESERVED5;
  __IO uint16_t GTPR;      // 保护和超时寄存器
  uint16_t  RESERVED6;
} USART_TypeDef;
```

初始化结构体 USART_InitTypeDef：

```c
typedef struct
{
  uint32_t USART_BaudRate;            // 波特率
  uint16_t USART_WordLength;          // 字长
  uint16_t USART_StopBits;            // 停止位
  uint16_t USART_Parity;              // 校验
  uint16_t USART_Mode;                // 模式（发送/接收）
  uint16_t USART_HardwareFlowControl; // 硬件流控制
} USART_InitTypeDef;
```

### 8.8 实例：USART1 初始化（115200、8 位数据、无校验、1 位停止位）

```c
int main(void)
{
    // 1. 使能 USART1 和 GPIOA 时钟（USART1 挂在 APB2 总线上）
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_USART1 | RCC_APB2Periph_GPIOA, ENABLE);

    GPIO_InitTypeDef GPIO_InitStructure;
    USART_InitTypeDef USART_InitStructure;

    // 2. 配置 TX：PA9 复用推挽输出
    GPIO_InitStructure.GPIO_Pin   = GPIO_Pin_9;
    GPIO_InitStructure.GPIO_Mode  = GPIO_Mode_AF_PP;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStructure);   // 注意：PA9 属于 GPIOA

    // 3. 配置 RX：PA10 浮空输入
    GPIO_InitStructure.GPIO_Pin  = GPIO_Pin_10;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IN_FLOATING;
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    // 4. 填充 USART 初始化结构体
    USART_InitStructure.USART_BaudRate            = 115200;
    USART_InitStructure.USART_WordLength          = USART_WordLength_8b;
    USART_InitStructure.USART_StopBits            = USART_StopBits_1;
    USART_InitStructure.USART_Parity              = USART_Parity_No;
    USART_InitStructure.USART_HardwareFlowControl = USART_HardwareFlowControl_None;
    USART_InitStructure.USART_Mode                = USART_Mode_Rx | USART_Mode_Tx;

    // 5. 初始化并使能 USART1
    USART_Init(USART1, &USART_InitStructure);
    USART_Cmd(USART1, ENABLE);
}
```
