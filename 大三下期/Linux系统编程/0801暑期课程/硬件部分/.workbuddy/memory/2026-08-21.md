## 固件库学习笔记整理（0821库学习.md）

- 根据老师 Day_5 上课记录（固件库 + USART 串行通信）重写并完善了 `0821库学习.md`。
- 重新梳理的逻辑结构：固件库组成（stm32f10x.h / system_stm32f10x / startup .s / StdPeriph_Driver）→ 寄存器结构体封装机制（GPIO_TypeDef、内存映射、位操作宏）→ GPIO 外设驱动（速度/模式枚举、GPIO_InitTypeDef、8 个 API）→ GPIO 初始化三步流程 + LED 流水灯实例 → USART 串行通信（并行/串行、同步/异步、帧格式、波特率、寄存器配置 8 步、USART_TypeDef/USART_InitTypeDef、USART1 初始化实例）→ 课后练习。

- 修正两处：① 中断向量表实际定义在启动文件而非 stm32f10x.h；② 老师笔记 USART 示例中 TX(Pin9) 误写 GPIO_Init(GPIOC,...)，应为 GPIOA。
