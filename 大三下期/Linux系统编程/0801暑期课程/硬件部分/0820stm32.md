# 0820 STM32 学习笔记

## STM32F103C8T6 是什么

**STM32F103C8T6**：基于 ARM Cortex-M3 内核的 32 位单片机，属于意法半导体（ST）的 STM32F1 系列。

**ARM**：一家只设计 CPU 内核、不生产芯片的公司，将内核设计授权给各芯片厂商。

**ARMv7**：ARM 内核架构的第 7 代版本，Cortex-M3 即基于该架构。

### Cortex 三个系列

- **Cortex-A**（Application）：高性能，能跑 Linux / Android，用于手机、多媒体设备。
- **Cortex-R**（Real-time）：高实时性、高可靠性，用于汽车电子、工业控制。
- **Cortex-M**（Microcontroller）：低功耗、低成本，用于单片机、物联网、传感器节点。STM32 属于此类。

## 嵌入式开发的基本内容

- **芯片手册**：芯片"说明书"，包含引脚定义、寄存器、电气特性。
- **电路原理图**：板子上芯片与外部器件的连接关系。
- **SDK**（Software Development Kit，软件开发工具包）：芯片厂商提供的整套软件开发资源，包含固件库、工具链、文档、示例工程。
- **固件库**：SDK 的核心部分，是对底层寄存器操作的封装（HAL 库 / 标准外设库）。

### 工具软件

- `Keil5`：集成开发环境（IDE），负责编写、编译、烧录、调试程序。
- `ST-Link 驱动`：让电脑识别 ST-Link 调试器的 USB 驱动。
- `USB 转串口驱动`：用于串口通信（ISP 下载、串口调试）。

## 最小系统

STM32F103C8T6 最小系统是芯片"能跑起来"的最简电路，由以下部分组成：

- **CPU**：STM32F103C8T6。
- **振荡电路**：晶振 + 2 个 30pF 电容，为系统提供时钟源。
- **电源**：3.3V 稳压电路。
- **复位电路**：RC 复位电路（上电自动复位）+ 复位按钮（手动复位）。
- **接口**：ISP 下载接口。

> 最小系统的意义：芯片本身无法独立工作，必须配合电源、时钟、复位、下载接口，才能运行和烧录程序。

## 时钟系统

### 时钟源

STM32 有 3 种可驱动系统时钟（SYSCLK）的主时钟源：

- **HSI**（高速内部 RC 振荡器）：8MHz。
- **HSE**（高速外部晶体振荡器）：4~16MHz。
- **PLL**（锁相环）：对输入时钟进行倍频 / 分频。

另有 2 种低速二级时钟源：

- **LSI**（低速内部 RC）：40kHz，用于驱动独立看门狗，或供 RTC 在停机 / 待机模式下唤醒系统。
- **LSE**（低速外部晶体）：32.768kHz，用于驱动 RTC。

任一时钟源在不使用时都可被独立开启或关闭，以优化系统功耗。

### 时钟树（信号如何产生与分发）

1. 石英晶振产生 8MHz（或 12MHz、6MHz）振荡脉冲信号，作为整个系统时钟的来源。
2. 通过 HSI / HSE 得到初始时钟信号。
3. 经 PLL 倍频、分频，最高产生 72MHz 的 SYSCLK。
4. 经预分频器产生各设备所需时钟，通过 AHB 总线分发到两个外设时钟总线。

- **APB1**：最高 36MHz，连接低速设备（SPI、I2C、UART、USB、看门狗、定时器）。
- **APB2**：最高 72MHz，连接高速设备（GPIO、SPI1、TIM1/8、USART1）。

### 与 8/16 位单片机的区别

- 8/16 位单片机：只有一个系统时钟频率。
- 基于 ARM Cortex 内核的 MCU：具有多个时钟频率，分别供给内核和不同外设模块。
- 高速时钟供中央处理器等高速设备，低速时钟供外设等低速设备，时钟分开有助于低功耗。

### 时钟使能（重要）

STM32 因低功耗需要，各外设模块需分别独立开启时钟。使用任何外设（GPIO、中断、定时器、ADC、I2C 等）前，**必须先使能对应的时钟**，否则该外设不工作。

```c
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);  // 开启 GPIOA 时钟
```

## 存储器系统

**前提**：STM32 是 32 位处理器（32 根地址线），寻址空间为 2^32 = 4GB。

- **统一编址**：程序存储器（Flash）、数据存储器（SRAM）、寄存器、输入输出设备都被组织在同一个 4GB 线性地址空间中，各自占一段区域。CPU 访问内存与外设使用同一套"给地址"机制。
- **唯一地址**：每个存储单元、每个寄存器都有独立地址，不会冲突。CPU 发出一个地址只会命中一个目标。
- **小端模式**：数据字节以小端格式存放，一个字中最低地址字节为最低有效字节，最高地址字节为最高有效字节（低字节存低地址）。

## 位操作

位操作是寄存器编程的基本功，用于"只动某一位、不碰其他位"。

### 6 个位运算符

- `&` 与：清零用。
- `|` 或：置位用。
- `^` 异或：翻转用。
- `~` 取反。
- `<<` 左移。
- `>>` 右移。

常用宏：

```c
#define BIT(n) (1 << (n))   // 第 n 位为 1，其余为 0
```

### 基本操作

```c
x |= BIT(3);                        // 置位：第 3 位置 1，不碰其他位
x &= ~BIT(3);                       // 清位：第 3 位清 0，不碰其他位
x ^= BIT(3);                        // 翻转：第 3 位取反
if (x & BIT(3)) { ... }             // 读位：判断第 3 位是否为 1
y = (x & 0xF0) >> 4;                // 提取一段位：取第 4~7 位
x = (x & ~0xF0) | (val << 4);       // 设置一段位
data |= (0x1 << 5 | 0x1 << 8 | 0x1 << 15);   // 同时置位 bit5、bit8、bit15
data &= ~(0x1 << 5 | 0x1 << 8 | 0x1 << 15);  // 同时清零 bit5、bit8、bit15
```

### 位带操作（Bit-band，STM32 特色）

- Cortex-M3 把"1 位"映射成"1 个 32 位地址"，改位 = 改地址，无需读-改-写。
- 别名区：SRAM 在 `0x22000000`，外设在 `0x42000000`。
- 正点原子宏：`PAout(2) = 1;` 直接让 PA2 输出高，一行搞定。

## GPIO 端口操作

### 端口结构

- 每个 GPIO 端口（A、B、C、D…）包含 16 个引脚，具体型号不一定全有。
- STM32F103C8T6 有 A/B/C/D 四个端口共 37 个引脚：GPA 16 个、GPB 16 个、GPC 3 个、GPD 2 个。
- 每个端口使用相对独立的硬件电路和寄存器组去控制和操作。
- 几乎所有的 GPIO 口都具有复用功能。

### 8 种模式

- 输入浮空
- 输入上拉
- 输入下拉
- 模拟输入
- 开漏输出
- 推挽式输出
- 推挽式复用功能
- 开漏复用功能

> 注意：I/O 端口寄存器必须按 32 位字访问，不允许半字或字节访问。

### 7 个寄存器一览

每个 GPIO 端口共 7 个寄存器：

- 2 个 32 位配置寄存器：`GPIOx_CRL`（配置 PIN0~7）、`GPIOx_CRH`（配置 PIN8~15）。
- 2 个 32 位数据寄存器：`GPIOx_IDR`（输入，只读）、`GPIOx_ODR`（输出，读写）。
- 1 个 32 位置位/复位寄存器：`GPIOx_BSRR`。
- 1 个 16 位复位寄存器：`GPIOx_BRR`。
- 1 个 32 位锁定寄存器：`GPIOx_LCKR`。

**配置流程**：通过端口配置寄存器设置引脚的**工作方式**，通过数据寄存器读（IDR）或写（ODR）数据。

### 配置寄存器 CRL / CRH

16 个引脚 × 每个 4 位 = 64 位，一个寄存器只有 32 位，故拆为两个：

- `GPIOx_CRL`：配置 PIN0~7，偏移地址 0x00。
- `GPIOx_CRH`：配置 PIN8~15，偏移地址 0x04。

每个引脚 4 位 = `CNF[1:0]` + `MODE[1:0]`（高 2 位 CNF、低 2 位 MODE）。

**MODE[1:0]：端口模式位（输入 or 输出及速度）**

| MODE | 含义                     |
| ---- | ------------------------ |
| 00   | 输入模式（复位后状态）   |
| 01   | 输出模式，最大速度 10MHz |
| 10   | 输出模式，最大速度 2MHz  |
| 11   | 输出模式，最大速度 50MHz |

**CNF[1:0]：端口配置位（输入模式，MODE=00）**

| CNF | 含义                       |
| --- | -------------------------- |
| 00  | 模拟输入模式               |
| 01  | 浮空输入模式（复位后状态） |
| 10  | 上拉/下拉输入模式          |
| 11  | 保留                       |

**CNF[1:0]：端口配置位（输出模式，MODE>00）**

| CNF | 含义                 |
| --- | -------------------- |
| 00  | 通用推挽输出模式     |
| 01  | 通用开漏输出模式     |
| 10  | 复用功能推挽输出模式 |
| 11  | 复用功能开漏输出模式 |

**配置套路**：先清位（`&= ~掩码`）再置位（`|= 值`）。

```c
// 例：把 PA0 配成 50MHz 推挽输出（PA0 是 CRL 的第 0 组，占 bit3:0）
GPIOA->CRL &= ~(0xF << 0);   // 清位：PA0 的 4 位清零
GPIOA->CRL |=  (0x3 << 0);   // 置位：写入 0011（CNF=00 推挽，MODE=11 输出 50MHz）
```

### 数据寄存器 IDR / ODR

- **IDR**（Input Data Register，端口输入数据寄存器）：**只读**，bit0~15 分别对应 pin0~15 的当前输入电平。
- **ODR**（Output Data Register，端口输出数据寄存器）：可读写，bit0~15 分别对应 pin0~15 的输出电平。

```c
if (GPIOA->IDR & (1 << 2)) { ... }   // 读：判断 PA2 当前是否为高电平
GPIOB->ODR |= (1 << 11);             // 写：PB11 输出高电平
```

### 置位/复位寄存器 BSRR / BRR

直接改 ODR 存在"读-改-写"问题（读→改→写三步之间可能被中断打断而覆盖其他位）。BSRR/BRR 由硬件一步完成，推荐使用：

- `GPIOx_BSRR`：某位写 1 → 对应引脚**置高**。
- `GPIOx_BRR`：某位写 1 → 对应引脚**拉低**。

```c
GPIOB->BSRR = (1 << 11);   // 一步置高 PB11，不碰其他位
```

### 锁定寄存器 LCKR

**LCKR**（Lock Register，锁定寄存器）：锁定端口配置，锁定后配置寄存器不可再修改，防止误操作。

## 实战一：库函数点亮 PC13 上的 LED

1. 开启 GPIOC 时钟。
2. 配置 PC13 引脚：PC13 属于高 8 位引脚，用 `GPIOC_CRH` 的 bit[23:20] 配置。
3. 将 `GPIOC_ODR` 的 bit13 清 0，LED 亮。

```c
// ① 使能 GPIOC 时钟
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC, ENABLE);

// ② 配置 PC13 为推挽输出 50MHz（CRH 中 PC13 是第 5 组，4 × 5 = 20）
GPIOC->CRH &= ~(0xF << 20);
GPIOC->CRH |=  (0x3 << 20);

// ③ ODR 的 bit13 清 0，点亮 LED
GPIOC->ODR &= ~(1 << 13);
```

## 实战二：寄存器直接操作（GPA0 + GPC15 双 LED 闪烁）

不调用任何库函数，**直接对内存地址读写寄存器**，是理解硬件本质的必经之路。

### 寄存器地址定义格式

把寄存器真实地址强制转换成指针，再用 `*` 解引用直接操作该地址：

```c
#define RCC_APB2ER  (*(volatile unsigned long *)(0x40021018))
#define GPIOA_CRL   (*(volatile unsigned long *)(0x40010800))
#define GPIOC_CRH   (*(volatile unsigned long *)(0x40011004))
#define GPIOA_ODR   (*(volatile unsigned long *)(0x4001080C))
#define GPIOC_ODR   (*(volatile unsigned long *)(0x4001100C))
```

**格式解析**：

- `unsigned long *`：把整数地址强转为 32 位指针。
- 外层 `*`：解引用，即"读写这个地址"。
- `volatile`：告诉编译器该地址的值可能被硬件随时改变，禁止优化跳过。

### 各寄存器地址来源

| 寄存器        | 地址         | 基址                  | 偏移 |
| ------------- | ------------ | --------------------- | ---- |
| `RCC_APB2ENR` | `0x40021018` | `0x40021000`（RCC）   | 0x18 |
| `GPIOA_CRL`   | `0x40010800` | `0x40010800`（GPIOA） | 0x00 |
| `GPIOA_ODR`   | `0x4001080C` | `0x40010800`（GPIOA） | 0x0C |
| `GPIOC_CRH`   | `0x40011004` | `0x40011000`（GPIOC） | 0x04 |
| `GPIOC_ODR`   | `0x4001100C` | `0x40011000`（GPIOC） | 0x0C |

**时钟使能位**：`RCC_APB2ENR` 中 IOPAEN 为 bit2，IOPCEN 为 bit4。

### 完整流程与代码

**① 使能端口时钟**

```c
RCC_APB2ENR |= (0x1 << 2 | 0x1 << 4);   // 同时开启 GPIOA、GPIOC 时钟
```

**② 设置端口工作模式（先清位、再置位）**

PA0 属于低 8 位，用 `GPIOA_CRL` 的第 0 组（bit3:0）；PC15 属于高 8 位，用 `GPIOC_CRH` 的第 7 组（bit31:28）。

```c
// PA0：MODE=11（输出 50MHz），CNF=00（推挽）
GPIOA_CRL |=  (0x1 << 0 | 0x1 << 1);
GPIOA_CRL &= ~(0x1 << 2 | 0x1 << 3);

// PC15：MODE=11（输出 50MHz），CNF=00（推挽）
GPIOC_CRH |=  (0x1 << 28 | 0x1 << 29);
GPIOC_CRH &= ~(0x1 << 30 | 0x1 << 31);
```

**③ 端口使用（数据寄存器）**

```c
GPIOA_ODR |= (0x1);          // PA0 输出高
GPIOC_ODR |= (0x1 << 15);    // PC15 输出高
```

**④ 主循环（双 LED 交替闪烁）**

```c
while (1)
{
    Delay_ms(2500);
    GPIOA_ODR &= ~(0x1);        // PA0 拉低，LED 亮
    GPIOC_ODR &= ~(0x1 << 15);  // PC15 拉低，LED 亮
    Delay_ms(2500);
    GPIOA_ODR |= (0x1);         // PA0 拉高，LED 灭
    GPIOC_ODR |= (0x1 << 15);   // PC15 拉高，LED 灭
}
```

> 注意：寄存器直接操作没有"防止读-改-写"的硬件保障（BSRR/BRR 才有），学习阶段重点关注地址与位的对应关系即可。

## 练习

- 输出端连接 4 个 LED（A、B、C、D），使用两个按钮进行控制。
- 按钮 A：控制 LED 按 A→B→C→D→A 的顺序快闪。
- 按钮 B：控制 LED 按 CD→AB 的分组慢闪。

> 提示：按钮属于输入，需要把对应引脚配置为输入模式（读 IDR 判断按下）；分组慢闪需要同时操作多个引脚的 ODR 位。
