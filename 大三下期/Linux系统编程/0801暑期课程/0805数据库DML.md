## DML（Data Manipulation Language，数据操作语言）

DML 即 CRUD（Create、Read、Update、Delete），对应四种基本数据操作：

| 分类 | 命令       | 作用             |
| ---- | ---------- | ---------------- |
| 插入 | `INSERT`   | 新增数据行       |
| 删除 | `DELETE`   | 按条件删除数据行 |
| 删除 | `TRUNCATE` | 清空表全部数据   |
| 修改 | `UPDATE`   | 修改已有数据行   |
| 查询 | `SELECT`   | 查询数据         |

### SELECT 语法结构

```sql
SELECT    c1, c2, c3, c4, c5
FROM      t1
INNER JOIN t2
ON        t1.id = t2.id
WHERE     c1 > 100 AND c1 < 200
GROUP BY  c1
HAVING    c4 > 100
ORDER BY  id DESC
LIMIT     10;
```

各子句的执行顺序和作用：

- `SELECT`：选择查询的列
- `FROM`：指定数据来源表
- `JOIN ... ON`：连接其他表，`INNER JOIN` 取交集，`LEFT/RIGHT OUTER JOIN` 取左/右表全部
- `WHERE`：行级过滤，在分组前执行
- `GROUP BY`：按指定列分组
- `HAVING`：分组后过滤，在 `GROUP BY` 之后执行
- `ORDER BY`：排序，`ASC` 升序（默认），`DESC` 降序
- `LIMIT`：限制返回行数

### 列运算与别名

```sql
SELECT `id`, `name`, `salary` sal, `salary` * 2 AS `double_salary`
FROM staff;
```

### IFNULL 空值替换

`IFNULL(列名, 默认值)` 将 NULL 替换为指定值，避免 NULL 参与运算导致结果为 NULL。

```sql
SELECT `bonus`, IFNULL(bonus, 0) FROM staff;

SELECT
    `id`,
    `name`,
    `salary` sal,
    `salary` * 2 AS `double_salary`,
    `salary` + IFNULL(bonus, 0) AS total
FROM staff;
```

### CONCAT 拼接

`CONCAT(str1, str2, ...)` 将多个字符串拼接为一个。

```sql
SELECT `id`, CONCAT(`name`, '-', `level`) AS name_level
FROM staff;
```

### WHERE 过滤

```sql
SELECT `id`, `name` FROM staff WHERE `id` = 1;
SELECT `id`, `name` FROM staff WHERE `id` != 1;
SELECT `id`, `name` FROM staff WHERE `id` <> 1;
SELECT `id`, `name` FROM staff WHERE `id` > 3 AND `id` < 5;
SELECT `id`, `name` FROM staff WHERE `id` BETWEEN 3 AND 5;
```

- `=`：等于
- `!=` 或 `<>`：不等于
- `BETWEEN ... AND ...`：闭区间，包含边界值
- 多个条件用 `AND`、`OR` 连接

### IN 匹配

`IN (...)` 多值匹配，等同于多个 `OR`。

```sql
SELECT `id`, `name`, `level` FROM staff WHERE `level` IN ('L1', 'L2');
SELECT `id`, `name`, `level` FROM staff WHERE `level` NOT IN ('L1', 'L2');
```

### IS NULL 判空

```sql
SELECT `id`, `name`, `level` FROM staff WHERE `bonus` IS NULL;
SELECT `id`, `name`, `level` FROM staff WHERE `bonus` IS NOT NULL;
```

> 注意：不能用 `=` 或 `!=` 判断 NULL，必须用 `IS NULL` 或 `IS NOT NULL`。

### ORDER BY 排序

`ASC` 升序（默认），`DESC` 降序。多列排序按列书写顺序优先。

```sql
SELECT `id`, `name`, `level` FROM staff ORDER BY `id`;
SELECT `id`, `name`, `level` FROM staff ORDER BY `id` DESC;
SELECT `id`, `name`, `level` FROM staff ORDER BY `level`, `salary`;
```

### LIMIT 与 OFFSET

`LIMIT n` 限制返回 n 行，`LIMIT n OFFSET m` 跳过前 m 行后取 n 行。`LIMIT m, n` 是等价简写。

```sql
SELECT `id`, `name`, `level` FROM staff ORDER BY `level`, `salary` LIMIT 10;
SELECT `id`, `name`, `level` FROM staff ORDER BY `level` LIMIT 3 OFFSET 5;
SELECT `id`, `name`, `level` FROM staff ORDER BY `level` LIMIT 5, 3;
```

### DISTINCT 去重

```sql
SELECT DISTINCT `level` FROM staff;
SELECT DISTINCT `dept_id` FROM staff WHERE `dept_id` IS NOT NULL;
```

### 多表查询

| 连接类型 | 效果                              | 关键词                       |
| -------- | --------------------------------- | ---------------------------- |
| 笛卡尔积 | 两表各行两两组合，结果行数 m×n    | 无连接条件                   |
| 内连接   | 只保留两表匹配上的行              | `INNER JOIN`                 |
| 左外连接 | 左表全部保留，右表匹配不上填 NULL | `LEFT JOIN`                  |
| 右外连接 | 右表全部保留，左表匹配不上填 NULL | `RIGHT JOIN`                 |
| 全外连接 | 两表全部保留，匹配不上各自填 NULL | `LEFT JOIN UNION RIGHT JOIN` |

#### 内连接

```sql
SELECT c1, c2
FROM t1
INNER JOIN t2
ON t1.pk = t2.fk;

SELECT * FROM staff, dept WHERE staff.dept_id = dept.id;
SELECT s.id, s.name, d.name, city FROM staff s, dept d WHERE s.dept_id = d.id;
```

#### 左外连接

左表全部保留，右表匹配不上填 NULL。

```sql
SELECT s.id, s.name, d.name, city
FROM staff s
LEFT JOIN dept d
ON s.dept_id = d.id;
```

#### 右外连接

右表全部保留，左表匹配不上填 NULL。

```sql
SELECT s.id, s.name, d.name, city
FROM staff s
RIGHT JOIN dept d
ON s.dept_id = d.id;
```

#### 全外连接

MySQL 不支持 `FULL JOIN`，用 `LEFT JOIN UNION RIGHT JOIN` 模拟。

```sql
SELECT s.id, s.name, d.name, city
FROM staff s
LEFT JOIN dept d
ON s.dept_id = d.id
UNION
SELECT s.id, s.name, d.name, city
FROM staff s
RIGHT JOIN dept d
ON s.dept_id = d.id;
```

### 并集、交集、差集

准备测试数据：

```sql
CREATE TABLE t1 (
    id INT AUTO_INCREMENT PRIMARY KEY,
    val CHAR(4)
);
CREATE TABLE t2 (
    id INT AUTO_INCREMENT PRIMARY KEY,
    val CHAR(4)
);
INSERT INTO t1(val) VALUES ('a'), ('b'), ('c');
INSERT INTO t2(val) VALUES ('c'), ('x'), ('y');
```

#### 交集

```sql
SELECT * FROM t1 INNER JOIN t2 ON t1.val = t2.val;
```

#### 并集

```sql
SELECT val FROM t1
UNION
SELECT val FROM t2;
```

> `UNION` 自动去重，`UNION ALL` 保留重复值。

#### 差集（t1 有但 t2 没有）

`NOT IN` 方案：

```sql
SELECT val FROM t1 WHERE val NOT IN (SELECT val FROM t2);
```

`LEFT JOIN ... IS NULL` 方案（性能更好）：

```sql
SELECT t1.val
FROM t1
LEFT JOIN t2
ON t1.val = t2.val
WHERE t2.val IS NULL;
```

### 练习

查询研发部门的员工信息：

隐式连接（逗号写法）：

```sql
SELECT * FROM staff s, dept d WHERE s.dept_id = d.id AND d.name = '研发';
```

显式连接：

```sql
SELECT * FROM staff s INNER JOIN dept d ON s.dept_id = d.id WHERE d.name = '研发';
```

### 聚合函数

| 函数      | 作用                                                     |
| --------- | -------------------------------------------------------- |
| `COUNT()` | 统计个数，`COUNT(列名)` 跳过 NULL，`COUNT(*)` 统计所有行 |
| `SUM()`   | 求和                                                     |
| `AVG()`   | 平均值                                                   |
| `MAX()`   | 最大值                                                   |
| `MIN()`   | 最小值                                                   |

```sql
SELECT MAX(salary), MIN(salary), AVG(salary) FROM staff;
SELECT COUNT(id) FROM staff WHERE gender = 'male';
```

### 分组

`GROUP BY` 按指定列分组，分组后 SELECT 中只能出现分组列和聚合函数。`HAVING` 用于分组后的过滤，在 `GROUP BY` 之后执行。

#### 基本分组查询

```sql
SELECT * FROM staff GROUP BY gender;

SELECT gender, COUNT(id) FROM staff GROUP BY gender;
SELECT gender, COUNT(id), MAX(salary) FROM staff GROUP BY gender;

SELECT level, COUNT(id), MAX(salary) AS max_s
FROM staff
GROUP BY level
HAVING max_s > 10000
ORDER BY level DESC;
```

#### 分组练习

各个部门的平均工资：

```sql
SELECT d.name, COUNT(s.id), AVG(s.salary)
FROM dept d
LEFT JOIN staff s
ON s.dept_id = d.id
GROUP BY d.name;
```

各个城市、员工人数以及最低最高工资，取员工人数最多的城市：

```sql
SELECT d.city, COUNT(s.id), MAX(s.salary), MIN(s.salary)
FROM dept d
LEFT JOIN staff s
ON s.dept_id = d.id
GROUP BY d.city
ORDER BY COUNT(s.id) DESC
LIMIT 1;
```

一张表可当两张用，找到各个员工 boss 的名字：

```sql
SELECT s.id, s.name, b.id, b.name AS boss
FROM staff s
LEFT JOIN staff b
ON s.boss = b.id;
```

每个员工有几个下属：

```sql
SELECT b.id, b.name, COUNT(s.id) AS n
FROM staff s
RIGHT JOIN staff b
ON b.id = s.boss
GROUP BY b.id, b.name
ORDER BY n DESC;
```

### 模糊查询

使用 `LIKE` 关键字，配合通配符：

| 通配符 | 含义                  |
| ------ | --------------------- |
| `%`    | 任意个字符（含 0 个） |
| `_`    | 一个字符              |

以字母 b 开头的名字：

```sql
SELECT name FROM staff WHERE name LIKE 'b%';
```

包含字母 b 的名字：

```sql
SELECT name FROM staff WHERE name LIKE '%b%';
```

第二个字母是 a 的名字：

```sql
SELECT name FROM staff WHERE name LIKE '_a%';
```

第三个字母是 a 的名字：

```sql
SELECT name FROM staff WHERE name LIKE '__a%';
```

### 子查询

在一个查询中嵌套其他查询语句。

```sql
SELECT * FROM staff
WHERE salary > (SELECT AVG(salary) FROM staff);
```

查询 tom 部门里比他年龄大的人：

```sql
SELECT s.name
FROM staff s
LEFT JOIN dept d
ON s.dept_id = d.id
WHERE d.id = (SELECT s.dept_id FROM staff s WHERE s.name = 'tom')
AND s.birthday > (SELECT s.birthday FROM staff s WHERE s.name = 'tom');
```

> 拆解：先查出 tom 的部门号 `SELECT dept_id FROM staff WHERE name = 'tom'`，再查出 tom 的生日 `SELECT birthday FROM staff WHERE name = 'tom'`，最后在 dept_id 相同的员工中筛出生日大于 tom 的。

### 函数

#### 数值相关

| 函数             | 作用                                                  |
| ---------------- | ----------------------------------------------------- |
| `ROUND()`        | 四舍五入                                              |
| `FLOOR()`        | 向下取整，舍弃小数位                                  |

### 更新

```sql
UPDATE dept SET name = 'test' WHERE id = 9;
UPDATE dept SET name = 'test', city = 'NanJing' WHERE id = 9;
```

> 更新最好加上 `WHERE` 限定条件，否则会修改全表。

### 删除

```sql
DELETE FROM dept WHERE id = 10;
```

> 不能删除某一行的某个字段，需要的话用 `UPDATE ... SET 字段 = NULL` 替代。
