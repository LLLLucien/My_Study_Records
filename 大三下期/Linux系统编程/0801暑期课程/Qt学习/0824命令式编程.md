# 0824 命令式编程：代码知识分类总结

根据老师上课现场写的 MyWidget 代码（main.cpp、mywidget.h、mywidget.cpp）整理的知识分类笔记。代码实现的是一个"自定义控件"：窗口里有一根指针，每 200ms 转 6 度，像秒针一样转圈。

## 一、程序框架（main.cpp）

- QApplication：每个 Qt Widgets 程序必须有一个应用程序对象，负责整个程序的管理
- exec()：进入事件循环，程序在这里一直等待信号和事件，窗口关闭才退出
- 标准流程四步

```cpp
QApplication a(argc, argv);   // 1. 创建应用程序对象
MyWidget w;                   // 2. 创建自定义控件
w.show();                     // 3. 显示窗口
return QApplication::exec();  // 4. 进入事件循环
```

## 二、自定义控件（继承 QWidget）

- class MyWidget : public QWidget，自定义控件 = 继承 Qt 已有的控件类，再重写它的虚函数（paintEvent、mousePressEvent）
- Q_OBJECT 宏：类里必须写，信号槽机制靠它才能工作
- 构造函数做初始化
  - setFixedSize(600, 600)：固定窗口大小，不能拉伸
  - setWindowTitle("自定义控件")：窗口标题
- 类里还能自己加成员变量（timer、angle、hx、hy 等）

## 三、信号与槽（Qt 最核心机制）

- connect() 把信号和槽连起来，4 个参数（老师注释里写的顺序）
  1. 信号发送者（谁发出信号，这里是 timer）
  2. 信号（发什么，&QTimer::timeout 定时器到点）
  3. 信号接收者（谁处理，这里是 this）
  4. 槽函数（怎么处理，&MyWidget::onTimeout；也可以用 lambda 表达式）

```cpp
connect(timer, &QTimer::timeout, this, &MyWidget::onTimeout);
```

- 信号：事件发生时发出的通知
- 槽：收到通知后执行的函数
- 好处：发送者和接收者解耦，不用自己写循环去检测

## 四、QTimer 定时器

- new QTimer(this)：this 做父对象，窗口销毁时自动释放内存，不用手动 delete
- setInterval(200)：每 200 毫秒触发一次 timeout 信号
- start()：启动定时器
- 完整工作链路：每 200ms → 发 timeout 信号 → 槽 onTimeout 执行 → angle 加 6 度 → update() 请求重绘 → 指针位置更新

## 五、绘图体系（QPainter 三件套）

所有绘制都写在 paintEvent() 里，系统需要重绘时自动调用，不能手动直接调用。

- QPainter 画家：painter(this) 表示在哪个控件上画
- QPen 画笔：控制线条
  - setColor(Qt::red) 颜色
  - setWidth(8) 线宽
  - setStyle(Qt::DashDotLine) 线型（点划线）；Qt::SolidLine 是实线
- QBrush 笔刷：控制填充（颜色、图案），本例的 QBrush 代码被注释掉了，没实际用
  - setColor(Qt::blue) 填充色
  - setStyle(Qt::Dense4Pattern) 填充图案（密集点状）

常用绘制函数（对应老师的演示）

- drawLine：画线。演示了 4 种写法（直接两个坐标、QLine、两个 QPoint 等），本质都一样
- drawPoint：画点
- drawPolygon：画多边形。配合 QPolygon 用，poly.append(QPoint) 逐个加顶点
- drawEllipse：画椭圆。传入 QRect 时画该矩形的内切圆
- drawArc：画圆弧。参数是矩形 + 起始角度 + 跨越角度，注意角度单位是 1/16 度，45*16 才是 45 度

## 六、事件处理（鼠标）

- mousePressEvent(QMouseEvent *event)：鼠标按下时系统自动回调
- event->pos()：拿到鼠标点击的坐标（QPoint）
- qDebug() << 坐标：打印到调试输出窗口，方便验证
- 重写事件函数要加 override
- 事件回调函数也是"系统直接调用"的，和槽类似，只是不需要 connect

## 七、坐标系统与三角函数（时钟指针怎么算）

- Qt 坐标系：原点在窗口左上角，x 向右增大，y 向下增大（和数学坐标相反）
- 窗口 600×600，指针转轴在中心 (300, 300)，指针长度 200
- 角度用度数累积（angle += 6），计算时再转弧度
  - rad = angle × M_PI / 180
- 用三角函数算指针终点坐标
  - hx = 300 + 200 × qSin(rad)
  - hy = 300 - 200 × qCos(rad)
- 为什么 hy 是减号：y 轴向下，减 cos 才能让 angle = 0 时指针朝上（12 点方向），然后顺时针转
- 用到的头文件 QtMath，提供 qSin、qCos、M_PI

## 八、重绘机制

- update()：请求重绘，立即返回，系统稍后统一重画；多次调用会合并，效率高，推荐
- repaint()：立即重绘，阻塞到画完
- 本例：定时器槽里用 update()，鼠标事件里用 repaint()

## 九、头文件 include 对应知识点

- QWidget：控件基类
- QPaintEvent：绘制事件
- QPainter：画家类
- QPen：画笔
- QBrush：笔刷
- QPoint、QRect：点、矩形（绘制用几何类型）
- QMouseEvent：鼠标事件
- QTimer：定时器
- QDebug：qDebug() 调试输出
- QtMath：数学函数（qSin、qCos）

## 十、代码里的注释要不要全看

按重要性分三档

- 必须看懂
  - connect 的 4 参数注释：信号槽的核心概念
  - drawArc 的角度注释：1/16 度的单位，不看容易写错
- 扫一眼即可
  - 功能说明类，如"用的时候再转弧度"、"可以得到鼠标的坐标"，看代码就能明白
- 可以先跳过
  - 大段 // 注释掉的代码（drawLine 其他写法、多边形、笔刷、画弧）：这是老师上课演示过的备选写法，知道有这些 API 就行，以后用到再取消注释尝试

### 注释勘误（两处）

- "每秒加6度"不准确：定时器 200ms 触发一次，实际是每次加 6 度、每秒加 30 度
- "画派状"不准确：drawEllipse 画的是椭圆（内切圆）；要画扇形应该用 drawPie
