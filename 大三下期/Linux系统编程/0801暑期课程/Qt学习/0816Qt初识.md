# 0816Qt初识

## 什么是 Qt

**Qt**：基于 C++ 的跨平台开发框架，主要用于图形界面（GUI）开发。

**Q_OBJECT 元对象系统**：Qt 的反射机制。凡是继承 `QObject` 且写了 `Q_OBJECT` 宏的类，Qt 就能在运行时动态地查询和调用它的方法。

**MOC（Meta Object Compiler，元对象编译器）**：Qt 的预处理工具，为带 `Q_OBJECT` 的类自动生成元信息代码，支撑动态属性绑定、信号和槽等机制。

### 功能

- GUI
- 网络、文件、线程、数据库、数据解析、STL
- 多媒体、蓝牙

## 开发方案

- **Qt Widgets（命令式开发）**：用 C++ 代码一步步创建、设置控件，适合传统桌面软件。
- **Qt Quick（声明式开发）**：用 QML + JS + C++ 描述界面，适合动画丰富的现代界面。

## QML

### Qt 程序入口（main.cpp）的执行步骤

1. 创建 `QGuiApplication` 应用对象：程序入口，管理应用生命周期
2. 创建 `QQmlApplicationEngine` 引擎：负责解析并运行 QML 文件
3. 连接 `objectCreationFailed` 信号：QML 加载失败时自动退出程序
4. 调用 `loadFromModule()`：加载名为 `qttest` 模块中的 `Main` 界面
5. 调用 `exec()`：进入事件循环，界面开始响应用户操作

```cpp
#include <QGuiApplication>
#include <QQmlApplicationEngine>

int main(int argc, char *argv[])
{
    QGuiApplication app(argc, argv);   // ① 应用入口

    QQmlApplicationEngine engine;      // ② 创建 QML 引擎
    QObject::connect(
        &engine, &QQmlApplicationEngine::objectCreationFailed, &app, []() { QCoreApplication::exit(-1); },
        Qt::QueuedConnection);         // ③ 加载失败则退出程序
    engine.loadFromModule("qttest", "Main");  // ④ 关键：加载 QML 界面

    return QGuiApplication::exec();    // ⑤ 进入事件循环
}

```

### 布局管理（Layout）

布局思路：外层 `ColumnLayout` 纵向排列，内部用 `RowLayout` 横向排列，形成嵌套布局。

1. `ColumnLayout` 占满整个窗口（`anchors.fill: parent`），纵向排列 3 个 `Rectangle`
2. 前两个 `Rectangle` 用 `Layout.fillWidth` / `Layout.fillHeight` 平均分配空间
3. 第 3 个 `Rectangle` 内部嵌套 `RowLayout`，横向排列 3 个黄色块

```qml
import QtQuick
import QtQuick.Layouts //布局管理
import QtQuick.Controls //控件
Window {
    id: window
    width: 640
    height: 480
    minimumWidth: 200
    minimumHeight: 600
    visible: true
    color: "grey"
    title: qsTr("布局管理")

    ColumnLayout{                 // 外层：纵向排列
        anchors.fill: parent
        spacing: 20
        Rectangle{                 // 第 1 块：蓝色，fillWidth/fillHeight 拉伸占位
            Layout.fillWidth: true
            Layout.fillHeight: true
            Layout.preferredHeight: 1
            width: 100
            height: 100
            color: "blue"
        }
        Rectangle{
            Layout.fillHeight: true
            Layout.fillWidth: true
            Layout.preferredHeight: 1
            width: 100
            height: 100
            color: "red"
         }

        Rectangle{
            Layout.fillHeight: true
            Layout.fillWidth: true
            Layout.preferredHeight: 3
            width: 100
            height: 100
            color: "green"

            RowLayout{            // 内层：横向排列 3 个黄色块
                anchors.fill: parent
                Rectangle{
                    Layout.fillHeight: true
                     Layout.fillWidth: true
                    width: 100
                    color: "yellow"
                }
                Rectangle{
                    Layout.fillHeight: true
                     Layout.fillWidth: true
                    width: 100
                    color: "yellow"
                }
                Rectangle{
                    Layout.fillHeight: true
                     Layout.fillWidth: true
                    width: 100
                    color: "yellow"
                }
            }
        }

    }
}

```

### 控件

控件交互流程：

1. 定义 JS 函数 `add(a, b)`：把两个输入字符串转成数字后相加
2. 两个 `TextField` 输入框：接收用户输入
3. `Button` 按钮的 `onClicked` 事件：调用 `add()` 计算结果
4. `Text` 文本：显示计算结果

```qml
import QtQuick
import QtQuick.Layouts
import QtQuick.Controls

Item {

    anchors.fill: parent

//关键：JS 函数，供 QML 事件调用
    function add(a,b)
    {
        let x=Number(a);
        let y=Number(b);
        return x+y;
    }


    Column {
        // 水平
        anchors.horizontalCenter: parent.horizontalCenter
        spacing: 10
        TextField {
            id: tf_x
            width: 400
            height: 40
            placeholderText: "please enter"
        }
        TextField {
            id: tf_y
            width: 400
            height: 40
            placeholderText: "please enter"
        }
        Button {
            // anchors.left: parent.left
            //  anchors.leftMargin: 100
            anchors.horizontalCenter: parent.horizontalCenter
            text: "加法运算"
            width: 200
            height: 40
            // 关键：点击事件，调用 JS 函数并把结果写入 result
            onClicked: {
                // let x = Number(tf_x.text);
                // let y = Number(tf_y.text);
                result.text = add(tf_x.text,tf_y.text);
            }
        }
        Text {
            id: result
            text: "0"
            // y:40
            width: 10
            height: 40
            color: "white"
            font.pixelSize: 64
            anchors.horizontalCenter: parent.horizontalCenter
        }
    }
}

```

## QML 与 C++ 交互

在 QML 里调用名为 `calc` 的 C++ 对象，完整流程分四步，按开发顺序排列：

1. **C++ 头文件**：声明 `Calc` 类（属性、槽函数、信号）
2. **C++ 源文件**：实现构造函数和槽函数
3. **主函数**：创建 `Calc` 对象并注册进 QML 引擎
4. **QML 文件**：通过注册名 `calc` 调用 C++ 的函数和属性

### 第一步：在 C++ 头文件中声明类

```c++

#ifndef CALC_H
#define CALC_H

#include <QObject>

class Calc : public QObject
{
    Q_OBJECT
    //关键：属性绑定（观察者模式），QML 可读 result、值变化时收到通知
    Q_PROPERTY(int result READ get_result NOTIFY resultChanged FINAL)

  private:
    //成员变量member`
    int m_result;
  public:
    explicit Calc(QObject *parent = nullptr);
    //用来读取成员变量
    int get_result();


    //槽函数
  public slots:
    void add(int x,int y);

  signals:
    //自定义的信号，但是不需要实现
    //看似是函数，实际不需要实现
    void resultChanged();
};

#endif // CALC_H

```

### 第二步：在 C++ 源文件中实现

```c++
#include "calc.h"

Calc::Calc(QObject *parent) : QObject{parent}
{
    m_result=0;
}
 void Calc::add(int x,int y)
{
     m_result=x+y;
    //得到了值不直接return
    //而是进行事件的提交,发一个信号
     emit resultChanged();
}

 int Calc::get_result()
{
     return m_result;
}
```

### 第三步：在主函数中创建对象并注册进引擎

```c++

#include <QGuiApplication>
#include <QQmlApplicationEngine>
#include<QQmlContext> //要注册到引擎里
#include <calc.h>

int main(int argc, char *argv[])
{
    QGuiApplication app(argc, argv);

    QQmlApplicationEngine engine;

    //创建好自己写的对象
    Calc calc;
    //关键：注册到引擎——QML 里通过名字 "calc" 访问这个 C++ 对象
    engine.rootContext()->setContextProperty("calc",&calc);
    QObject::connect(
        &engine, &QQmlApplicationEngine::objectCreationFailed, &app, []() { QCoreApplication::exit(-1); },
        Qt::QueuedConnection);
    engine.loadFromModule("qttest3", "Main");

    return QGuiApplication::exec();
}

```
