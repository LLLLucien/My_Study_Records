# C++ 面向对象编程

## 对象与类

**类**：对象的定义。

## 组合：整体与部分的关系

**组合**：强组合，部分不能脱离整体存在，整体销毁部分也销毁。例如线没了，点也没了。

**聚合**：弱组合，整体销毁了，部分也可以存在。例如班级没了，学生应该独立还在。

**关联**：存在联系，不是整体和部分的关系。

三种关系在代码中的体现：

**强组合**：值成员对象，生命周期绑定：

```c++
class Line
{
    Point s;
    Point e;
};
```

**聚合**：指针成员，生命周期独立：

```c++
class Line
{
    Point *s;
    Point *e;
};
```

**关联**：引用成员，只绑定不拥有：

```c++
class Line
{
    Point &s;
    Point &e;
};
```

## 继承

注意与组合的概念分开。

### 角色

**父类**：又称基类、超类。

**子类**：又称派生类，获得父类中的属性和行为。

### 特征

**代码重用**：多个类公共的成员提取出来放入父类中。

**易于维护和扩展**：子类需要新的功能，可以直接在父类中修改。

### 类型

**单继承**：一个子类只有一个父类。

**多继承**：一个子类有多个父类，存在副作用。

### 属性

子类拥有父类中的所有属性。

- **私有属性**：不能直接访问，可通过构造函数初始化
- **公共属性**：外部可以直接访问
- **受保护属性**：外部无法访问，但子类可访问

### 方法

**方法覆盖**：子类可以覆盖父类中的方法，使用 `override` 重写，父类的方法必须是虚函数。

**析构函数**：父类的析构函数也要是虚函数（仅限指针类型与对象类型不一致时）。

访问修饰符：

```c++
private:
    int pri_a;

protected:
    int pro_a;

public:
    int pub_a;
```

### 继承的基本步骤

```c++
#include <iostream>

using namespace std;

class A
{
  private:
    int pri_a;

  protected:
    int pro_a;

  public:
    int pub_a;

    A() : pri_a(0), pro_a(0), pub_a(0)
    {
        cout << "A()" << endl;
    }
    A(int a, int b, int c) : pri_a(a), pro_a(b), pub_a(c)
    {
        cout << " A(int a,int b,int c)" << endl;
    }

    ~A()
    {
        cout << "~A()" << endl;
    }
    void show()
    {
        cout << "A =" << pri_a << endl;
        cout << "A =" << pro_a << endl;
        cout << "A =" << pub_a << endl;
    }
};

class B : public A
{
  private:
  public:
    B()
    {
        cout << "B()" << endl;
    }
    B(int a, int b, int c, int d)
    {
        cout << "B()" << endl;
    }
    ~B()
    {
        cout << "~B()" << endl;
    }
};

int main()
{
    B b;
    b.show();

    return 0;
}
```

直接使用 A 的 `show`，而且变量也是 A 的。

输出结果：

```text
A()
B()
A =0
A =0
A =0
~B()
~A()
```

**构造顺序**：先父类后子类，先 `A()` 后 `B()`。

**析构顺序**：先子类后父类，先 `~B()` 后 `~A()`。

**构造调用**：B 默认会调用 `A()` 无参构造，也可以通过初始化列表调用 A 的有参构造：

```c++
B(int a, int b, int c, int d) : A(a, b, c), pri_b(b)
{
    cout << "B(int a,int b,int c,int d)" << endl;
}
```

**同名函数**：子类中与父类同名的函数，会进行覆盖，调用的时候就是覆盖后的。

### 常见的指针形式

```c++
A *a;
a = new B();
a->show();
```

- 指针是 A 类型的
- `new B()` 创建的对象是 B 类型的
- 如果子类 B 和父类 A 都有 `show`（非虚函数），那么调用的是 A 里的 `show`
- 原因：`a` 声明成 `A*`，编译器就直接把 `a->show()` 解析为 `A::show()`，不看 `a = new B()`

### 解决方法（虚函数）

在 A 里面添加虚函数：

```c++
virtual void show() { cout << "A" << endl; }
```

A 的析构也加上 `virtual`，这样通过父类指针删除时都会调用子类 B 的析构：

```c++
virtual ~A();
```

**总结**：

- A 里已有的函数，能通过 `A*` 调用（非虚 → 调 A 的，虚 → 调 B 的）
- B 里新增的函数，不能通过 `A*` 调用，编译期就报错；要么向下转型，要么把函数上提到 A

### 重写父类（override）

```c++
void shw() override
{
}
```

**override 的作用**：明确需要重写父类，防止写错函数名。

- 如果父类没有虚函数 `shw`，就会报错
- 所以 `override` 只认虚函数

## 多态

传不同的参数，表现出的形态不同。

方法行为的多态：根据对象类型、参数类型、参数个数选择不同版本的方法执行，呈现不同的行为。

**重载**：一个类的内部，同名方法有多个版本，由参数类型与参数个数不同导致，编译时选择不同的方法执行。

**重写**：在继承关系中，子类覆盖了父类的同名方法，根据对象的类型选择不同的版本。

## 抽象类与接口类

### 纯虚函数与抽象类

**抽象类**：至少有一个纯虚函数的类，不能实例化，用于被继承。

**纯虚函数**：在虚函数后加 `= 0` 声明，只有接口没有实现。

```c++
#include <iostream>

using namespace std;

class Shape
{
  private:
  public:
    Shape()
    {
        cout << "Shape()" << endl;
    }
    virtual ~Shape()
    {
        cout << "~Shape()" << endl;
    }
    virtual double Area() = 0;   // 纯虚函数
};

class Circle : public Shape
{
  private:
  public:
    Circle()
    {
        cout << "Circle()" << endl;
    }
    ~Circle()
    {
        cout << "~Circle()" << endl;
    }
    double Area() override
    {
        return 0;
    }
};

int main()
{
    Circle c1;
    return 0;
}
```

子类必须重写纯虚函数，才能创建实例。

### 初始化列表的规则

初始化列表只能初始化"本类自己声明的成员"。

派生类中给父类成员**赋值**可以，但**初始化**不行：

```c++
Circle() { name = "Circle"; }   // ✅ 赋值，protected 成员派生类能写
Circle() : name("Circle") {}    // ❌ 初始化，name 不是本类成员
```

### `= default` 与 `= 0`

**`= default`**：使用编译器给的默认实现（有实体）。

**`= 0`**：不提供实现（纯虚函数）。

**析构函数的例外**：析构函数即使标 `= 0`，也必须补一个实现，否则链接报错。

### 接口类

**接口类**：一种特殊的抽象类，所有函数都是纯虚函数，且没有数据成员。

```c++
// oop3.cxx
#include <iostream>

class USB
{
  public:
    virtual ~USB() = default;
    virtual void plugIn() = 0;
    virtual void plugOut() = 0;
    virtual void run() = 0;
};

class MP3 : public USB
{
  private:
  public:
    MP3()
    {
        std::cout << "MP3 构造" << std::endl;
    };
    ~MP3()
    {
        std::cout << "MP3 析构" << std::endl;
    };
    void plugIn() override
    {
        std::cout << "MP3 插入" << std::endl;
    };
    void plugOut() override
    {
        std::cout << "MP3 拔出" << std::endl;
    };
    void run() override
    {
        std::cout << "MP3 正在播放" << std::endl;
    };
};

int main()
{
    MP3 mp3;
    mp3.plugIn();
    mp3.run();
    mp3.plugOut();
    return 0;
}
```

接口类的析构函数写 `virtual ~USB() = default;` 即可。
