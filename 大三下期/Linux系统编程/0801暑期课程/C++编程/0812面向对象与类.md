# C++ 面向对象编程

## 对象与类

**类**：对象的定义。

## 组合：整体与部分的关系

**组合**：强组合，部分不能脱离整体存在，整体销毁部分也销毁。例如线没了，点也没了。

**聚合**：弱组合，整体销毁了，部分也可以存在。例如班级没了，学生应该独立还在。

**关联**：存在联系，不是整体和部分的关系。

三种关系在代码中的体现：

**强组合**：值成员对象，生命周期绑定：

```c++
class Line
{
    Point s;
    Point e;
};
```

**聚合**：指针成员，生命周期独立：

```c++
class Line
{
    Point *s;
    Point *e;
};
```

**关联**：引用成员，只绑定不拥有：

```c++
class Line
{
    Point &s;
    Point &e;
};
```
