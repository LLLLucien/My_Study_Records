# STL（标准模板库）

<https://learn.microsoft.com/en-us/cpp/standard-library/stl-containers>
STL 是一组基于泛型编程的模板类和函数，提供了可复用的、通用的算法和数据结构。组件包含容器、迭代器、适配器、算法、函数对象。

> **补充：STL 是什么？为什么要有它？**
>
> 以前写程序要存储一堆数据，得自己写动态数组、链表、排序函数……每一份都要自己实现，麻烦还容易出错。
> STL 就是 C++ 官方提前写好的"通用工具包"：**数据结构（容器）+ 操作（算法）+ 遍历工具（迭代器）** 都封装好了，直接用就行。
>
> - 它是**模板类/模板函数** → 所以存 `int`、`double`、自己定义的类都可以，类型是"传进去"的（这就是泛型编程，见下文）
> - 一共 5 大组件：容器、迭代器、适配器、算法、函数对象
> - 使用前先看这个套路：`容器<类型> 对象名;` → `对象名.begin() / end()` 拿到迭代器 → 配合算法操作

## 容器

**容器**：数据结构的具体实现。

> **补充：什么是容器？**
>
> 容器 = "装数据的东西"，就是现成的数据结构封装。
> 你 0811 学的 `vector` 就是一种容器。STL 里的容器分四类，区别在于**数据的排列方式**和**查找速度**。

### 有序容器

- `vector`：动态数组
- `array`：固定数组
- `list`：双向循环链表
- `forward_list`：单向链表
- `deque`：双端队列，分段存储

> **补充：这几个有序容器怎么理解？怎么选？**
>
> 共同点：元素**按插入顺序**排成一排，用下标/位置访问。
>
> | 容器           | 通俗理解                       | 特点                                                                        | 常用场景                         |
> | -------------- | ------------------------------ | --------------------------------------------------------------------------- | -------------------------------- |
> | `vector`       | 可自动扩容的数组（你已经学过） | 尾部插入/删除快 O(1)，按下标随机访问快 O(1)；中间插入/删除要搬元素，慢 O(n) | **最常用**，存数据首选           |
> | `array`        | 长度固定不变的数组             | 和 C 数组类似，但更安全（知道自己的 size）                                  | 长度确定、性能要求高时           |
> | `list`         | 链表，每个节点存数据和前后指针 | 任意位置插入/删除快 O(1)；但**不能随机访问**（不能 `lst[3]`，要一个个走）   | 频繁在中间增删                   |
> | `forward_list` | 单向链表                       | 只能从前往后走，比 list 省内存                                              | 内存敏感、只单向遍历             |
> | `deque`        | 双端队列，前后都能快速增删     | 头和尾插入/删除都快，也能随机访问（比 vector 稍慢）                         | 需要在**两端**操作数据（如队列） |
>
> **选择口诀**：默认用 `vector`；经常两头操作用 `deque`；经常中间插入删除用 `list`；长度固定用 `array`。

### 有序关联容器

基于**红黑树**（一种自平衡的二叉搜索树）实现，默认按 key 排序。

- `set`：无重复的集合
- `multiset`：有重复值的集合
- `map`：无重复值的键值对
- `multimap`：有重复值的键值对

> **补充：红黑树是什么？set / map 怎么理解？**
>
> - **红黑树** = 一种能**保持平衡**的二叉搜索树（节点分左子树/右子树，左小右大）。因为"自动平衡"，查找、插入、删除都是 O(log n)，数据量大时依然很快。
> - 所以这类容器**不用你管顺序，它自动按 key 从小到大排好**。
>
> | 容器       | 通俗理解                               | 例子                            |
> | ---------- | -------------------------------------- | ------------------------------- |
> | `set`      | 只有一个"值"，且不重复（数学里的集合） | `{1, 3, 5, 7}`，插 3 不会重复   |
> | `multiset` | 集合，但允许重复                       | `{1, 3, 3, 5}`                  |
> | `map`      | 键值对（key → value），key 不重复      | 学号 → 姓名，`map<int, string>` |
> | `multimap` | 键值对，key 允许重复                   | 一个班级号对应多个学生          |
>
> 查找方式：`set` 用 `find()`，`map` 用 `s.find(key)` 或 `s[key]`（注意：`s[key]` 若 key 不存在会**自动插入**一个默认值，这是新手常踩的坑）。

### 无序关联容器

基于**哈希表**实现。

- `unordered_map`：无序键值对
- `unordered_set`：无序集合

> **补充：哈希表是什么？和红黑树比谁快？**
>
> - **哈希表** = 数组 + 散列函数。把 key 经过函数计算得到一个位置，直接放进/取出，理想情况下查找是 **O(1)**，比红黑树的 O(log n) 更快。
> - 代价：**元素乱序存放**（不保证顺序），而且占的内存比红黑树大。
> - **怎么选**：需要按顺序遍历 → 用 `map`/`set`（红黑树）；只在乎查得快、不在乎顺序 → 用 `unordered_map`/`unordered_set`（哈希表）。

### 容器适配器

基于已有的容器封装而成。

- `stack`：栈，基于 `deque`
- `queue`：队列，基于 `deque`
- `priority_queue`：优先队列，基于数组

队列、栈是操作受限的线性表，优先级队列是在队列的基础上在逻辑上进行堆构造。

> **补充：容器适配器是什么意思？**
>
> **适配器** = 给已有容器"加个壳、限制操作"。栈和队列不是新的数据结构，而是**限制**了 deque 的用法：
>
> | 适配器                       | 限制后的规则                            | 通俗理解             |
> | ---------------------------- | --------------------------------------- | -------------------- |
> | `stack`（栈）                | 只能从**栈顶**进、出（后进先出 LIFO）   | 一摞盘子，后放的先拿 |
> | `queue`（队列）              | 只能**队尾进、队头出**（先进先出 FIFO） | 排队打饭，先来的先走 |
> | `priority_queue`（优先队列） | 每次取出的是**最大/最小**的那个         | 医院叫号，病重的先看 |
>
> 用法（stack 为例）：
>
> ```cpp
> #include <stack>
> std::stack<int> s;
> s.push(1);   // 入栈
> s.push(2);
> s.top();     // 看栈顶（不出栈）→ 2
> s.pop();     // 出栈（无返回值）
> s.empty();   // 是否为空
> ```
>
> 注意：priority_queue 默认底层是 `vector`（笔记里"基于数组"就是指它，默认基于 `vector<int>`），内部用**堆**结构保证 `top()` 总是最大元素。

## 迭代器

> **补充：原笔记没展开，这里补上**
>
> **迭代器（iterator）** = 容器和算法之间的"桥梁"，可以理解成**广义的指针**：
>
> - 指针 `*p` 能取数组元素、`p++` 能往后走——迭代器对**所有容器**提供一样的操作
> - 所以算法不用关心你用的是 vector 还是 map，只要给我迭代器就行
>
> 所有容器都提供 `begin()`（指向第一个元素）和 `end()`（指向最后一个元素的**下一个位置**），这个区间叫**左闭右开 `[begin, end)`**，`end()` 位置的元素是拿不到的：
>
> ```cpp
> #include <vector>
> #include <iostream>
>
> int main() {
>     std::vector<int> v = {10, 20, 30};
>     // it 相当于"指针"，*it 取元素，++it 向后走
>     for (auto it = v.begin(); it != v.end(); ++it) {
>         std::cout << *it << " ";   // 输出 10 20 30
>     }
>     return 0;
> }
> ```
>
> **为什么迭代器重要**：你 0811 学 vector 时见过迭代器插入 `v.insert(it, 666)`——正因为迭代器统一了"位置"的概念，`insert`、`erase`、`sort` 这些操作才能对任意容器通用。
>
> 按能力分 5 种（从弱到强）：
>
> | 迭代器          | 能力                                  | 支持它的容器               |
> | --------------- | ------------------------------------- | -------------------------- |
> | 输入/输出迭代器 | 只能读/只能写，单向走                 | 流（cin/cout）             |
> | 前向迭代器      | 可读可写，只能前向 `++`               | `forward_list`             |
> | 双向迭代器      | 可前向也可后向 `--`                   | `list`、`set`、`map`       |
> | 随机访问迭代器  | 支持 `+n`、`-n`、`[]`，和指针几乎一样 | `vector`、`deque`、`array` |
>
> 一句话：`vector` 的迭代器最强（可以 `it + 3` 跳着走），`list`/`set` 的只能一步步走。C++11 起更常用**范围 for**（编译器底层就是帮你用迭代器遍历）：
>
> ```cpp
> for (int x : v) { std::cout << x; }   // 等价于上面那个 for
> ```

## 算法

> **补充：原笔记没展开，这里补上**
>
> **算法（algorithm）** = STL 提供的"通用操作函数"，都通过迭代器操作容器，**与容器类型无关**。使用前 `#include <algorithm>`。
>
> 按用途分类：
>
> | 类别 | 函数                                         | 作用                                     |
> | ---- | -------------------------------------------- | ---------------------------------------- |
> | 遍历 | `for_each(首, 尾, 函数)`                     | 对每个元素做操作                         |
> | 查找 | `find`、`find_if`、`count`、`binary_search`  | 找元素 / 数个数 / 二分查找（要求已排序） |
> | 排序 | `sort`、`stable_sort`、`reverse`             | 排序 / 稳定排序 / 反转                   |
> | 修改 | `copy`、`replace`、`fill`、`remove`          | 拷贝 / 替换 / 填充 / 删除                |
> | 数值 | `max`、`min`、`accumulate`（在 `<numeric>`） | 最大最小 / 求和                          |
>
> ```cpp
> #include <vector>
> #include <algorithm>
> #include <numeric>   // accumulate 在这个头文件
> #include <iostream>
>
> int main() {
>     std::vector<int> v = {5, 2, 8, 1, 9};
>
>     std::sort(v.begin(), v.end());              // 排序 → {1, 2, 5, 8, 9}
>
>     auto it = std::find(v.begin(), v.end(), 8); // 找 8
>     if (it != v.end())                          // 找不到时返回 end()
>         std::cout << "找到：" << *it << std::endl;
>
>     int cnt = std::count(v.begin(), v.end(), 2); // 数 2 的个数
>     int sum = std::accumulate(v.begin(), v.end(), 0); // 求和，初值 0
>
>     // 排序后二分查找（快）
>     bool ok = std::binary_search(v.begin(), v.end(), 5);
>     return 0;
> }
> ```

### Lambda 表达式

**Lambda 表达式**：匿名函数，可当作临时的函数对象使用。

lambda 语法四部分：

| 部分       | 作用                           |
| ---------- | ------------------------------ |
| `[]`       | 捕获列表，决定能否使用外部变量 |
| `(参数)`   | 参数列表                       |
| `-> 类型`  | 返回类型，可省略               |
| `{函数体}` | 逻辑代码                       |

**1. 基本用法**：定义 + 调用。

```cpp
auto add = [](int a, int b) -> int { return a + b; };  // 两数相加
auto f = []() { cout << "hello world" << endl; };      // 无参数、无捕获
f();                                                   // 调用
```

**2. 捕获外部变量**：`[=]` 拷贝值（只读），`[&]` 引用（可修改外部变量）。

```cpp
int a = 10, b = 20;
auto f1 = [=]() { cout << a << "," << b << endl; };    // 只读
auto f3 = [&](int x, int y) -> int                     // 引用，可改
{
    a *= 10;                                           // 外部 a 变成 100
    return x + a;
};
```

**3. 作为 sort 比较器**：第三个参数决定排序规则。

```cpp
vector<int> v = {42, 31, 1, 78, 6};
sort(v.begin(), v.end());                                          // 升序
sort(v.begin(), v.end(), [](int x, int y) { return x > y; });      // 降序
for_each(v.begin(), v.end(), [](int n) { cout << n << endl; });    // 逐个打印
```

**4. find_if 条件查找**：返回第一个满足条件的元素，找不到返回 `end()`。

```cpp
auto it = find_if(v.begin(), v.end(), [](int x) { return x > 30; });
while (it != v.end())                          // 循环找全所有 > 30 的
{
    cout << *it << endl;
    it = find_if(it + 1, v.end(), [](int x) { return x > 30; });
}
```

## 泛型编程

**泛型**：类型参数化，编程过程和数据类型解耦。

**模板编程**：C++ 中实现泛型的一种机制。

> **补充：一句话讲清"泛型"**
>
> 泛型 = 写代码时**不写死类型**，把类型当作"参数"传进去。
> 你以前写交换函数只能写 `swap(int&, int&)`，换 double 就得再写一份。泛型可以一份代码通吃所有类型。

### 泛型的实现方式

- **模板编程（C++）**：编译期生成代码，类型安全，用的最多
- **带参数的宏（C）**：预处理期文本替换，无类型检查
- **类型擦除（Java）**：运行期擦除类型信息
- **动态类型（Python）**：运行期才检查类型

```c
#define SWAP(x, y) do { \
    typeof(x) temp = (x); \
    (x) = (y); \
    (y) = temp; \
} while(0)
```

> **补充：这段宏在干嘛？**
>
> 宏 `SWAP(a, b)` 在编译前把 `x`/`y` 原样替换成 `a`/`b`，效果是交换两个变量的值。
> `typeof(x)` 取变量 x 的类型来声明临时变量 `temp`。`do {...} while(0)` 是惯用法：让宏像一个普通语句一样安全使用（配合 `if` 等时不会出错）。
> **为什么 C++ 不用宏做这个**：宏是纯文本替换、没有类型检查，出错了很难查。C++ 用下面的函数模板代替它。

```c++
#include <iostream>
#include <string>

template <typename T>
T t_max(T a, T b)
{
    return a > b ? a : b;
}

template <typename T>
void t_swap(T *a, T *b)
{
    T tmp = *a;
    *a = *b;
    *b = tmp;
}

template <typename T>
class Box
{
private:
    T name;
public:
    Box(T a):name(a){}
    void setName(T n)
    {
        name = n;
    }
    T getName()
    {
        return name;
    }
};

template <typename T>
T Box<T>::getName()
{
    return name;
}

template <typename T>
void Box<T>::setName(T n)
{
    name = n;
}

int main(int argc, const char** argv)
{
    std::cout << t_max<int>(10, 5) << std::endl;   // 显式指定 T = int
    std::cout << t_max(2.1, 4.3) << std::endl;     // 编译器自动推导 T = double
    std::cout << t_max('a', 'b') << std::endl;     // 自动推导 T = char
    int a = 3, b = 5;
    std::cout << a << b << std::endl;
    t_swap(&a, &b);                                // 传指针，交换 a、b
    std::cout << a << b << std::endl;
    // 类模板必须显式写类型（C++17 起可自动推导：Box b1(2);）
    Box<int> b1(2);
    Box<std::string> b2("abc");

    b1.setName(10);

    std::cout << b1.getName() << std::endl;

    b2.setName("xyz");

    std::cout << b2.getName() << std::endl;

    return 0;
}
```

> **补充：模板代码怎么读？**
>
> 1. `template <typename T>`：声明"接下来是一个模板，T 是类型参数"。`typename` 也可写成 `class`（`template <class T>` 一样）
> 2. 函数模板：`t_max<T>` 里的 `T` 被实际类型替换 → 写一次，生成多份代码
> 3. 类模板：`Box<T>` 中 `T` 是成员类型 → `Box<int>` 是"装 int 的盒子"，`Box<string>` 是"装 string 的盒子"，是两个不同的类
> 4. 类外定义成员函数必须写成 `T Box<T>::getName()`（带上 `<T>`），因为 `Box` 离开模板就是普通类名
> 5. **STL 和模板的关系**：`vector<int>`、`map<string, int>` 中的类型就是模板参数——你现在已经能看懂 STL 容器的用法了
