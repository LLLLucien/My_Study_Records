# C++ 面向对象

## 一、string 字符串

需要头文件 `#include <string>`。

### 初始化

四种初始化方式：

```c++
#include <iostream>
#include <string>

using namespace std;

int main(int argc, char const *argv[])
{
    string s1;           // 长度为0的空字符串
    string s2 = "hello"; // 拷贝字面量
    string s3("hello");  // 直接初始化
    string s4(6, 'a');   // 6个a

    cout << s1 << endl;
    cout << s2 << endl;
    cout << s3 << endl;
    cout << s4 << endl;
}
```

### 输入与读取

`cin >>` 读取到空格或换行就结束：

```c++
cin >> s1;
```

`getline` 读取一整行：

```c++
getline(cin, s1);
```

循环读取直到遇到空行：

```c++
while (getline(cin, s1))
{
    if (s1.empty())
        break;
    cout << s1 << endl;

    auto len = s1.size();
    cout << "size:" << len << endl;
}
```

### 字符串拼接

用 `+` 拼接：

```c++
cout << s2 + " 123" + s3 << endl;
string s5 = s2 + "0 000" + s3;
cout << s5 << endl;
```

用 `append()` 拼接：

```c++
string s7 = "cpp";
s7.append("okok");
```

> 注意：不能直接拼接两个字面量，`string s6 = "hello" + "world";` 是错误的。

### 比较与遍历

字符串可以直接用 `==` 比较：

```c++
string s8 = "abcddd";
string s9 = "dacdds";
if (s8 == s9)
{
    cout << "相同" << endl;
}
```

遍历字符串：

- `[]` 不做越界检查
- `at()` 会做越界检查，更安全

```c++
string s10 = "hello";
for (size_t i = 0; i < s10.size(); i++)
{
    cout << s10[i] << endl;
    cout << s10.at(i) << endl;
}
```

### 范围 for 遍历

四种 `for` 遍历方式：

- **拷贝遍历**：修改 `r` 不影响原字符串
- **引用遍历**：修改 `r` 等同于修改原字符串
- **只读引用**：不可修改，性能好（避免拷贝）
- **万能引用**：可修改临时变量

```c++
// 拷贝
for (auto r : s10)
{
    r++;
}

// 引用
for (auto &r : s10)
{
    r -= 32;
}

// 只读引用
for (const auto &r : s10)
{
}

// 万能引用
for (auto &&r : s10)
{
}
```

引用可以层层传递：

```c++
auto &w = s1;
auto &t = w;
auto &g = t;
```

### 常用函数

- `size()`：返回字符串包含的字符数量
  - `s1.size();`
- `capacity()`：返回分配的数组总大小（容量）
  - `s1.capacity();`
- `at(n)`：访问下标 n 的字符，会做越界检查
  - `s1.at(1);`
- `insert(pos, str)`：在 pos 位置插入字符串
  - `s1.insert(2, "2026");`
- `clear()`：清空内容，但容量不变
  - `s1.clear();`
- `resize(n)`：重新指定字符数量（改的是 size，不是 capacity）
  - `s1.resize(10);`
- `append(str)`：在末尾拼接字符串
  - `s1.append("okok");`
- `shrink_to_fit()`：缩容，使 capacity 与 size 匹配
  - `s1.shrink_to_fit();`
- `replace(pos, len, str)`：从 pos 开始替换 len 个字符为 str
  - `s1.replace(3, 5, str);`
- `replace(pos, len, str, s, n)`：替换 `[pos, len]` 为 str 的 `[s, n]` 子串
  - `s1.replace(3, 5, str, 7, 8);`

参考手册：<https://en.cppreference.com/w/cpp/string/basic_string>

## 二、vector 动态数组

**vector**：动态数组容器（模板类型），需引入 `<vector>` 头文件。

### 初始化

```c++
#include <iostream>
#include <vector>

using namespace std;

int main(int argc, char const *argv[])
{
    vector<int> v1;                 // size=0
    vector<int> v2(10);             // size=10，10个0
    vector<int> v3(10, 1);          // size=10，10个1
    vector<int> v4{10, 1};          // size=2，含有10和1
    vector<string> v5(10, "hello"); // 存了10个hello，size=10

    for (auto &&i : v5)
    {
        cout << i << ",";
    }
    cout << v5.size() << "," << endl;
}
```

五种初始化方式的含义：

- `vector<int> v1;`：空容器，size=0
- `vector<int> v2(10);`：10 个元素，初值 0
- `vector<int> v3(10, 1);`：10 个元素，初值 1
- `vector<int> v4{10, 1};`：2 个元素，分别是 10 和 1
- `vector<string> v5(10, "hello");`：10 个 `"hello"`

### 容量与增长

```c++
v1.reserve(17);
cout << v1.size() << "," << v1.capacity() << endl;

for (int i = 0; i < 17; i++)
{
    v1.push_back(i);
    cout << v1.size() << "," << v1.capacity() << endl;
}
```

- `push_back()`：从末尾插入元素，`size` 随之增加
- 当 `size > capacity` 时，vector 自动扩容（通常是翻倍）
- `reserve(n)`：只预分配容量，不改变 size

### 增删与访问

```c++
v1.pop_back();  // 删除末尾元素（无返回值）
```

```c++
vector<int> v6 = {100, 200, 300};
v6.front();       // 取得第一个元素 → 100
v6.back();        // 取得最后一个元素 → 300
int *p = v6.data(); // 获取底层数组指针
```

### 拷贝

```c++
vector<int> v7;
v7 = v6;   // 深拷贝，v7 是 v6 的独立副本
```

### 迭代器与插入

**迭代器**：相当于指向容器内元素的指针。

```c++
auto it = v6.begin();    // 指向第一个元素
v6.insert(it, 666);      // 在第一个位置插入 666
```

用迭代器遍历：

```c++
for (auto i = v6.begin(); i != v6.end(); i++)
{
    // *i 即当前元素
}
```

## 三、OOP 面向对象编程

### 基本概念

**OOA（Object-Oriented Analysis）**：面向对象分析。

**OOD（Object-Oriented Design）**：面向对象设计。

**OOP（Object-Oriented Programming）**：面向对象编程。

编程范式对比：

- 面向过程：C、Pascal
- 函数式编程：Lisp
- 面向对象：C++、Python

**对象**：实体或概念在程序中的投影，分离出关注点，用一个模型描述。

OOP 三大特性：

- 封装（Encapsulation）
- 继承（Inheritance）
- 多态（Polymorphism）

### 类与对象

**类**：对具有相同属性、行为的一组对象下的定义。

**对象**：具体的存在，是类的实例。

**UML（Unified Modeling Language）**：统一建模语言，用于 OOA/OOD 的一组图像化工具，用于建模、表示设计和沟通。推荐工具：<www.drawio.com>。

### 构造函数与析构函数

访问修饰符：`private`（私有）、`public`（公共）、`protected`（受保护）。

**封装**：保护内部状态以及实现细节，通过 getter/setter 控制访问。

```c++
#include <iostream>
#include <string>

using namespace std;

class Cat
{
  private:
    string name;
    int *age;

  public:
    int getAge()
    {
        return *age;
    }
    void setAge(int n)
    {
        if (n > 0 && n < 20)
        {
            *age = n;
        }
    }

    Cat()
    {
    }

    Cat(string s)
    {
        name = s;
        age = new int(0);
        cout << "Cat()构造函数\n";
    }

    ~Cat()
    {
        delete age;
        cout << "~Cat析构函数\n";
    }
};

int main()
{
    Cat c1;                     // 栈上创建，自动构造和析构
    Cat *c2 = new Cat();       // 堆上创建，需手动释放
    delete c2;
    c2 = nullptr;

    Cat c3("coco");             // 有参构造，需在初始化时传参

    return 0;
}
```

**重载**：同名函数，参数不同。如 `Cat()` 和 `Cat(string s)`。

**构造顺序**：创建对象时自动执行构造函数；栈对象在程序结束时自动执行析构函数，堆对象需手动 `delete`。

> 如果构造函数有参数，初始化时就必须传参；或者多定义一个无参构造函数 `Cat(){}`。

### 模块化编程

头文件声明（`Cat.h`）：

```c++
#include <iostream>
#include <string>

using namespace std;

class Cat
{
  private:
    string name;
    int age;

  public:
    Cat();
    Cat(string name);
    ~Cat();
    string getName();
    int getAge();
    void setAge(int n);
    void show();
};
```

源文件实现（`Cat.cxx`）：

```c++
#include "Cat.h"

Cat::Cat()
{
    cout << "构造函数1\n";
    name = "猫猫";
    age = 1;
}

Cat::Cat(string name)
{
    cout << "构造函数2\n";
    this->name = name;         // name 默认是参数变量，成员变量需用 this
}

int Cat::getAge()
{
    return age;
}

void Cat::setAge(int n)
{
    if (n > 0 && n < 20)
    {
        age = n;
    }
}

string Cat::getName()
{
    return name;
}

void Cat::show()
{
    cout << "name=" << name << endl;
    cout << "age=" << age << endl;
}

Cat::~Cat()
{
    cout << "析构函数\n";
}
```
