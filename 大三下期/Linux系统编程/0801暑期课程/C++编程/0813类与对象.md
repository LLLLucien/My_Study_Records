# C++ 面向对象学习注意点

## 引用（reference）

引用就是"别名"，从出生起必须绑定一个已存在的变量，且终生不能改绑。

- 必须初始化：不能 `int &r;` 空着，必须 `int &r = a;`
- 作为类成员时，必须在构造函数初始化列表里绑定
- `delete` 只能用于指针，不能用于引用
- 形参按值传会悬空：函数结束副本销毁，引用绑到死对象上

```cpp
class Line {
    Point &start;
public:
    Line(Point &s) : start(s) {}   // 初始化列表绑定
};
```

错误写法：成员是引用，却没有构造函数绑定它。

```cpp
class Line {
    Point &start;   // 没有构造函数给它绑定 -> 编译错误
};
```

> 注意：`Line(Point s) : start(s)` 错误——`s` 是副本，函数结束就销毁，`start` 绑定到已死对象上。

## 初始化列表

- 成员初始化必须写在初始化列表里：`Line(Point s) : start(s), end(e) {}`
- 引用成员、const 成员只能通过初始化列表初始化
- 继承时，基类成员只能通过调用基类构造函数初始化

```cpp
Circle() : name("Circle") {}   // 错误：不能直接初始化基类成员 name
Circle() : Shape("Circle") {}  // 正确：调用基类构造函数
```

## 前向声明与循环依赖

两个类互相引用（如 Product <-> Brand）时：

- 声明指针成员 `Brand *brand;`：前向声明 `class Brand;` 就够
- 访问对方成员 `brand->name`：必须看到对方**完整定义**

**解法**：能用指针就用指针 + 前向声明；访问对方成员的函数放到对方完整定义之后（类内声明 + 类外定义）。

```cpp
class Product;  // 前向声明
class Brand { /* ... */ };
void Brand::show() { /* 此时 Product 已完整定义，可访问 */ }
```

## 继承与多态

**多态基类必须有虚析构**：`virtual ~Vehicle() {}`（或 `= default`）。否则 `delete` 基类指针时，派生类析构函数不会执行，造成泄漏。

- `virtual ~USB() = default`（有实现）和 `virtual ~USB() = 0`（纯虚，必须在类外定义）不同
- 纯虚函数让类变成抽象类，不能实例化，只能由派生类实现

```cpp
class Vehicle {
public:
    virtual void run() = 0;        // 纯虚
    virtual ~Vehicle() {}          // 多态基类必须有虚析构
};
```

## 菱形继承

### 非虚继承的菱形问题

继承结构：X、Y 都继承 A，Z 同时继承 X、Y，形成菱形。

非虚继承时，Z 对象里存在**两份 A 子对象**，各带一份 n：

- X 分支初始化 n = 10
- Y 分支初始化 n = 5
- 因此 `A::show()` 在 Z 里会产生二义性，编译报错

**解决**：明确指定调哪一份，如 `X::show()` 与 `Y::show()`，可直观看到"两份独立数据"。

### 虚继承后为什么还要写 A(n)

把 X、Y 改为 `virtual public A` 后，菱形里只剩一份 A，规则随之改变：

- 虚基类由"最派生类"（Z）负责构造，中间层 X、Y 初始化列表里的 `A(...)` 在构造 Z 时全部被忽略
- 由于 A 没有默认构造函数（只有 `A(int)`），所以 Z 必须显式写：

```cpp
Z(int n, int m) : A(n), X(n), Y(m) { ... }
```

> 注意例外：若 A 有默认构造函数，Z 不写也不会报错。

### X、Y 里的 A(...) 并不是白写

- 构造 Z 时：只有 Z 自己的 `A(...)` 生效
- 单独实例化 `X x(...)` 或 `Y y(...)` 时：此时它们自己就是最派生类，自己的 `A(...)` 生效

## 静态属性

- 静态属性：类内定义，类外声明

```c++
class User
{
  public:
    // 静态属性：属于该类，而不是属于该类的对象
    // 这样每次创建对象时，count 都不会被重置
    static int count;
    int id;

    User()
    {
        cout << "User()" << endl;
        id = count++;
    }
    ~User()
    {
    }
};
// 静态属性在类中声明，在类外初始化
int User::count = 0;

```

```c++
    // 静态方法只能访问静态属性，不能访问非静态属性
    static void setCount(int n)
    {
        count = n;
        cout << "setCount" << endl;
    }
```
