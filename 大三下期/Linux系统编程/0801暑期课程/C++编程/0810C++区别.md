# C++

## 区别

- C、C++语法不同
- 面向对象编程：类与对象、封装
- 面向对象编程：继承
- 面向对象编程：多态
- 模板编程：泛型编程
- STL（Standard Template Library，标准模板库）：数据结构与算法
- 智能指针
- 第三方库：boost、openGL、openCV、Qt、MFC、WinForm、WUI、fmpeg

## 概述

**C**：1970 年诞生，编译型静态语言，面向过程编程。数据与操作分离，贴近硬件，性能极高。

**C++**：1983 年诞生，C 的超集，面向对象编程。以对象为核心，对象封装数据和行为，对象之间通过消息交互。

**Python**：解释型语言，动态类型，语法简洁。性能约为 C/C++ 的 1/100，常用于数据分析、AI、自动化脚本。

**Java**：在 C++ 基础上的改良，去除指针和多继承，引入 JVM（Java Virtual Machine）实现跨平台。

**C#**：微软推出的面向对象语言，语法类似 Java，深度绑定 .NET 生态。

**Go**：Google 开发，编译型静态语言，内置并发（goroutine），主打云计算和微服务。

**Rust**：Mozilla 团队开发，内存安全无 GC（Garbage Collection），学习曲线陡峭，用于系统级编程。

**JavaScript（JS）**：动态类型脚本语言，浏览器原生支持。ES6（2015 年）后语法趋于统一。

**Node.js**：基于 Chrome V8 引擎（C++ 编写）的 JS 运行环境，让 JS 可在服务端运行。Deno 是其新一代替代品。

**TypeScript（TS）**：微软对 JS 的改进，加入静态类型检查。可在 Node.js 和浏览器中运行，在大模型前端领域应用广泛。

## 版本

- C++83：最早期版本
- C++98：第一个 ISO 标准（ISO C++）
- C++03：C++98 的修正版
- C++11/14：**现代 C++ 分水岭**，引入 auto、lambda、智能指针等大量新特性
- C++17：进一步改进和简化
- C++20：引入协程、概念（Concepts）、范围库（Ranges）等重大特性
- C++23：当前最新标准

### 面向过程 vs 面向对象

**面向过程**——数据和函数分离：

```c
int data;

void func(int data);
```

**面向对象**——数据和行为封装在类中：

```c++
class A
{
    int data;
    void func(int data);
};
```

## C、C++语法差异

- 命名空间
- 输入输出
- 引用 vs 指针
- 常量表达式替代宏定义
- 动态内存管理： malloc/free，new/delete
- NULL，nullptr
- typedef using
- auto 数据类型
- ...

| 项目         | Windows | Linux  |
| ------------ | ------- | ------ |
| 源文件扩展名 | `.cpp`  | `.cxx` |
| 主流编译器   | MSVC    | g++    |

- `iostream`：Input/Output Stream，输入输出流
- `cout` / `cin`：标准输出 / 标准输入
- 正式工程中推荐使用 `std::cout`、`std::cin`，不推荐 `using namespace std`
- 编译命令：`g++ base.cxx -o base`

```c++
#include <iostream>

int main(int argc, char *argv[])
{
    int a;
    double b;
    std::cin >> a >> b;
    std::cout << "a=" << a << ",b=" << b << std::endl;
    std::cout << "a+b=" << a + b << std::endl;
    return 0;
}
```

### 引用和指针

```c++
#include <iostream>

int main(int argc, char const *argv[])
{
    int a = 42;
    int b = 2;
    int *p;
    p = &a;
    *p = 43;
    p = &b;

    int &r = a;
    std::cout << a << "," << r << std::endl;
}
```

### 指针与引用的对比

| 特性         | 指针                          | 引用                               |
| ------------ | ----------------------------- | ---------------------------------- |
| 声明         | `int *p;`                     | `int &r = a;`                      |
| 初始化       | 可先声明后赋值                | 声明时必须初始化，一旦绑定不可更改 |
| 解引用       | 需要 `*p`                     | 直接使用，无需解引用符号           |
| 本质         | 独立变量，存储地址            | 变量的别名，不占额外空间           |
| 交换函数示例 | `void swap1(int *x, int *y);` | `void swap2(int &x, int &y);`      |

### 命名空间与动态内存管理

#### 命名空间

自定义命名空间，将代码组织到不同作用域中：

```c++
#include <iostream>

namespace xyz
{
    int n = {9};

    void hello()
    {
        std::cout << "hello A\n";
    }
} // namespace xyz
```

相同名称的命名空间会自动合并，且支持嵌套：

```c++
namespace xyz
{
    int m = {9};

    void cout()
    {
        std::cout << "hello A\n";
    }
} // namespace xyz
```

在当前作用域找不到某个名字时，可借助 `using namespace xyz` 自动到对应命名空间中查找：

```c++
int main()
{
    std::cout << "n:" << xyz::n + xyz::m << std::endl;
    xyz::hello();
}
```

#### 动态内存

与 C 语言的对比：

| 操作         | C                                      | C++                     |
| ------------ | -------------------------------------- | ----------------------- |
| 分配内存     | `int *p = (int *)malloc(sizeof(int));` | `int *p = new int;`     |
| 分配并初始化 | 先分配再赋值 `*p = 42;`                | `int *p = new int(42);` |
| 释放内存     | `free(p);`                             | `delete p;`             |
| 置空         | `p = NULL;`                            | `p = nullptr;`          |

```c++
// 先分配再初始化
int *p1 = new int;
std::cout << p1 << "," << *p1 << std::endl;

*p1 = 42;
std::cout << p1 << "," << *p1 << std::endl;

// 分配空间的同时初始化
int *p2 = new int(42);

delete p1;
p1 = nullptr;
```

### 动态数组

静态数组的两种初始化方式：

```c++
// 方法一：逐个赋值
int *p = new int[3];
p[0] = 100;
p[1] = 100;
p[2] = 100;

// 方法二：初始化列表
int *p2 = new int[3]{100, 200, 300};
```

- 动态数组扩容的两种方式：

```c++
// 方法一：手动逐元素拷贝
int *p3 = new int[5];
for (int i = 0; i < 3; i++)
{
    p3[i] = p2[i];
}

// 方法二：memcpy 批量拷贝（需引入 <cstring>）
int *p4 = new int[6];
memcpy(p4, p, sizeof(int) * 3);
```

- 释放动态数组（注意要用 `delete[]` 而非 `delete`）：

```c++
delete[] p;
p = p2;       // 取得更大的地址
p2 = nullptr; // 废除之前的地址
```
