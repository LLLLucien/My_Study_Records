# 套接字编程 - TCP

## 套接字 socket

- 套接字是TCP/IP实现中出现的概念，封装网络底层通信细节，操作方式类似于文件操作

### IP地址

- 接入网络的计算机的逻辑标识，动态分配给计算机的一个标识信息

- IPv4：2^32 个地址 大约42亿个
- IPv6：2^128 个地址 大约340 万亿亿亿个

### Port 端口号

- 一台计算机有唯一的IP标识，但是同时运行上百个进程，端口号标识收、发数据的进程
- 端口号也是虚拟的，2^16 个端口号 65536个，前1024（1014？）个是保留端口号，用于特定服务

## TCP 套接字API

- socket() 创建套接字文件描述符 int
- bind() 绑定套接字到IP地址和端口号
- listen() 监听套接字，初始化一个队列
- accept() 接受连接请求
- read/write() 读写数据
- close() 关闭套接字

### 大小端

0x12345678

空间：0 1 2 3
大端：0x12 0x34 0x56 0x78
小端：0x78 0x56 0x34 0x12

- Little Endian x86架构
- Big Endian 网络通信，嵌入

- 从主机发送数据时，需要转换为网络字节序
- htons() 主机字节序转网络字节序,host to network short
- htonl() 主机字节序转网络字节序,host to network long

- 从网络接收数据时，需要转换为主机字节序
- ntohs() 网络字节序转主机字节序,network to host short
- ntohl() 网络字节序转主机字节序,network to host long

```c
    #include <sys/socket.h>

    int socket(int domain, int type, int protocol);

    第一个参数如果是AF_UNIX（AF_LOCAL），则表示本地通信
    如果是AF_INET，则表示网络通信

    第二个参数如果是SOCK_STREAM，则表示TCP通信,可用1标识
    如果是SOCK_DGRAM，则表示UDP通信

    第三个参数如果是0，则表示使用默认协议
```
