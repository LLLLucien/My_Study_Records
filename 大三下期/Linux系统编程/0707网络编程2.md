# 套接字编程 - UDP

## TCP & UDP

| 特征     | TCP      | UDP                |
| -------- | -------- | ------------------ |
| 可靠     | 是       | 否                 |
| 建立连接 | 是       | 否                 |
| 有序     | 是       | 否                 |
| 丢包     | 丢包重发 | 丢失               |
| 数据大小 | 不受限   | 65535，MTU=1500-28 |

- 应用场景
  - TCP： 文件传输、在线游戏、下载、浏览器、FTP、HTTP
  - UDP：视频、游戏、传感器

| TCP 服务器端开发流程 | 客户端开发流程 |
| -------------------- | -------------- |
| socket               | socket         |
| bind                 | connect        |
| listen               |                |
| accept               |                |
| read/write           | read/write     |
| close                | close          |

- 在**bind**之前可以设置**端口复用**

```c
setsockopt(fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
```

## UDP 开发流程

- **send 发送**
  - socket
  - sendto(data,addr,...)
  - close
- **recv 接收**
  - socket
  - bind
  - recvfrom(data,addr,...)
  - close

### 发送端

```c
    // send.c
#include "my.h"
#include <netinet/in.h>
#include <string.h>
#include <sys/socket.h>

int main()
{
    // SOCK_DGRAM为UDP相关的数据包套接字
    int fd = socket(AF_INET, SOCK_DGRAM, 0);

    // 发送
    char msg[1024];

    struct sockaddr_in addr;
    memset(&addr, 0, sizeof(addr));
    addr.sin_family = AF_INET;
    // inet_pton 把ip地址转换为网络字节序
    inet_pton(AF_INET, "127.0.0.1", &addr.sin_addr); // 接收方ip
    addr.sin_port = htons(9527);                     // 接收方port

    while (1)
    {
        memset(msg, 0, sizeof(msg));
        printf("请输入要发送的信息：");
        fgets(msg, sizeof(msg), stdin);

        // 发送数据，参数：套接字描述符，数据，数据长度，发送标志默认0，目标地址，目标地址长度
        ssize_t len = sendto(fd, msg, strlen(msg), 0, (struct sockaddr *)&addr, sizeof(addr));
        printf("send: %s, len=%ld\n", msg, len);
    }
    // 关闭套接字
    close(fd);
    return 0;
}
```

### 接收端

```c
    // recv.c
#include "my.h"
#include <asm-generic/socket.h>
#include <sys/socket.h>

int main()
{
    // 创建套接字
    int fd = socket(AF_INET, SOCK_DGRAM, 0);

    // 地址复用
    int opt = 1;
    setsockopt(fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
    // bind绑定
    struct sockaddr_in addr;
    memset(&addr, 0, sizeof(addr));
    addr.sin_family = AF_INET;
    addr.sin_port = htons(9527);
    addr.sin_addr.s_addr = htonl(INADDR_ANY);
    int ret = bind(fd, (struct sockaddr *)&addr, sizeof(addr));
    if (ret == -1)
    {
        perror("bind 失败");
        close(fd);
        return EXIT_FAILURE;
    }
    // 接收数据
    // UDP 包头中「长度」字段是 16 位，所以理论上一个 UDP 数据报最大是 2¹⁶ - 1 = 65535 字节
    // IP MTU(MAX TRANSMISSION UNIT最大传输单元)
    // 1500 是以太网的最大长度，28 是以太网的头部长度，
    char buf[1500 - 28];
    memset(buf, 0, sizeof(buf));

    struct sockaddr_in client_addr;
    memset(&client_addr, 0, sizeof(client_addr));
    socklen_t len = sizeof(client_addr);

    while (1)
    {
        ssize_t t = recvfrom(fd, buf, sizeof(buf), 0, (struct sockaddr *)&client_addr, &len);
        if (t == -1)
        {
            perror("recvfrom 失败");
            close(fd);
            return EXIT_FAILURE;
        }
        // 获得端口
        int port = ntohs(client_addr.sin_port);
        char ip[INET_ADDRSTRLEN];
        // ip地址，从网络字节序转换为主机字节序
        inet_ntop(AF_INET, &client_addr.sin_addr, ip, sizeof(ip));
        printf("由%s:%d发送的数据:%s,len=%ld\n", ip, port, buf, t);
    }
    close(fd);
    return 0;
}
```
