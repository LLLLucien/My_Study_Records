# 网络编程

## 网络

- 通过有线/无线的介质，链接计算机设备，进行数据通信或设备控制
- 介质
  - 有线： 同轴电缆、双绞线（150m）、光纤
  - 无线： 无线局域网WIFI、蓝牙、移动网络、卫星

- 网络设备
  - 计算机、手机、终端
  - 集线器：hub 组成广播网
  - 交换机：switch 组成局域网
  - 路由器：router 网络与网络

- 网络拓扑
  - 星形： 局域网 计算机+网线+交换机/集线器
  - 总线形
  - 环形
  - 混合形

- 核心
  - 数据通信
  - 设备控制

## 通信协议

### OSI 开放系统互联参考模型（7层）

- 7层模型：应用层、表示层、会话层、传输层、网络层、数据链路层、物理层

- 是ISO制定的一套参考方案

- 具体实现
  - TCP/IP 文森.瑟夫 Bill.Joy(Sun)
  - appleTalk
  - IPX
  - NetBios

### TCP/IP 协议

- TCP/IP 协议族，一组协议的总称

- 应用层：SSH、FTP、SNMP、HTTP、DNS
- 传输层：TCP、UDP
- 网络层：IP、ICMP、ARP
- 物理层：硬件电气规范与接口、驱动程序等
